# 01. Введение в ML и метрики регрессии

[Шпаргалка (ноутбук)](../../cheatsheet.ipynb) · [Оглавление курса](../../README.md)

**Суть.** ML строит модель $a(x)$, приближающую неизвестную зависимость $y(x)$ по обучающей выборке
$\lbrace (x_i, y_i)\rbrace_{i=1}^{\ell}$, так, чтобы она хорошо работала на **новых** объектах. Обучение —
минимизация **функции потерь** (loss) на выборке; качество измеряют **метриками**. Выбор loss
определяет, что именно предсказывает модель: MSE → среднее, MAE → медиану.

| Термин | Определение |
|---|---|
| Объект / признак / таргет | строка таблицы / столбец таблицы / то, что предсказываем |
| Параметры vs гиперпараметры | настраиваются обучением (веса) vs задаются до обучения ($k$ в kNN, глубина дерева) |
| Классификация / регрессия | $y$ из конечного множества / $y \in \mathbb{R}$ |
| Multiclass / multilabel | ровно один из $K$ классов / любое подмножество меток |
| Loss vs метрика | что оптимизируем vs чем измеряем и отчитываемся |
| ML lifecycle | постановка → данные/EDA → выбор модели, метрики, валидации, признаков → fit → evaluation → deploy/мониторинг → отчёт |
| Data leakage | утечка: признак содержит информацию, недоступную в момент предсказания |

**Ключевые формулы**

$$
\text{MAE}=\frac1\ell\sum|y_i-\hat y_i|,\quad
\text{MSE}=\frac1\ell\sum(y_i-\hat y_i)^2,\quad
\text{RMSE}=\sqrt{\text{MSE}},\quad
R^2=1-\frac{\sum(y_i-\hat y_i)^2}{\sum(y_i-\bar y)^2}
$$

$$
\text{MAPE}=\frac1\ell\sum\Big|\frac{y_i-\hat y_i}{y_i}\Big|,\quad
\text{WAPE}=\frac{\sum|y_i-\hat y_i|}{\sum|y_i|},\quad
\text{RMSLE}=\sqrt{\frac1\ell\sum\big(\ln(1+y_i)-\ln(1+\hat y_i)\big)^2}
$$

<summary><b>1. Что такое машинное обучение</b></summary>

**Машинное обучение (Machine Learning, ML)** — построение алгоритмов, которые не программируются
явными правилами, а **настраиваются по данным**: по примерам «объект → ответ» восстанавливается
неизвестная зависимость.

Есть неизвестная **целевая зависимость** $y: \mathbb{X} \to \mathbb{Y}$, известная только на конечном
наборе объектов. Нужно построить **алгоритм (модель)** $a: \mathbb{X} \to \mathbb{Y}$, который
хорошо приближает $y$ на **новых** объектах.

Цели решения ML-задачи (по лекции):
1. **Восстановление зависимости** — уметь предсказывать метки новых объектов;
2. **Интерпретация** — понять, как устроена $y(x)$, от чего зависит ответ;
3. **Оценка качества** — понимать, насколько в среднем ошибаемся и чего ждать на практике.

**1.1. Основные термины**

| Термин | Англ. | Смысл |
|---|---|---|
| Объект | observation, example, instance, sample | то, для чего делаем предсказание: клиент, пациент, квартира |
| Пространство объектов $\mathbb{X}$ | input space | множество всех возможных объектов |
| Признак | feature, attribute, covariate, variable | измеримая характеристика объекта: возраст, площадь |
| Признаковое описание | feature vector | $x = (x^1, \dots, x^n) \in \mathbb{R}^n$ |
| Целевая переменная, ответ, метка | target, label, response, dependent variable | то, что предсказываем |
| Обучающая выборка | training set | $X^\ell = \lbrace (x_i, y_i) \rbrace_{i=1}^{\ell}$ |
| Матрица «объект — признак» | design / data matrix | $F \in \mathbb{R}^{\ell \times n}$: строки — объекты, столбцы — признаки |
| Модель, алгоритм | model, hypothesis | функция $a(x)$ из семейства $\mathcal{A}$ |
| Параметры | parameters, weights | настраиваются при обучении (веса линейной модели) |
| Гиперпараметры | hyperparameters | задаются **до** обучения (число соседей $k$, глубина дерева) |
| Обучение | fit, training | подбор параметров по выборке |
| Предсказание, инференс | predict, inference | применение модели к новым объектам |
| Функция потерь | loss function | то, что **оптимизируется** при обучении |
| Метрика | metric | то, чем **измеряем** качество модели |

**1.2. Типы задач**

**Обучение с учителем (supervised)** — есть ответы $y_i$:

| Задача | $\mathbb{Y}$ | Пример |
|---|---|---|
| Бинарная классификация | $\lbrace 0, 1\rbrace$ или $\lbrace -1, +1\rbrace$ | мошенник / честный |
| Скоринговая бинарная | $[0, 1]$ — вероятность класса | кредитный скоринг |
| Многоклассовая (multiclass) | $\lbrace 1, \dots, K\rbrace$, классы не пересекаются | диагноз: грипп / ангина / ковид |
| Многометочная (multilabel) | $\lbrace 0, 1\rbrace^K$, классы пересекаются | теги статьи |
| Регрессия | $\mathbb{R}$ | цена квартиры |
| Многомерная регрессия | $\mathbb{R}^m$ | координаты объекта |
| Прогнозирование (forecasting) | значения временного ряда в будущем | продажи на следующую неделю |
| Ранжирование | порядок на объектах | поисковая выдача, рекомендации |

**Обучение без учителя (unsupervised)** — ответов нет: кластеризация, снижение размерности,
поиск аномалий, оценка плотности (темы [10](../10_anomaly_detection/README.md),
[11](../11_clustering_dim_reduction/README.md)).

> Целевой признак «условен»: часто просто дана таблица, и таргет приходится **формировать самому**
> (например, «клиент ушёл» = «не было покупок 90 дней»). Целевой признак может быть любым — даже графом.

**1.3. Типы признаков**

| Тип | Значения | Пример | Как подавать в модель |
|---|---|---|---|
| Бинарный | $\lbrace 0, 1\rbrace$ | пол, наличие балкона | как есть |
| Вещественный (числовой) | $\mathbb{R}$ | доход, площадь | масштабировать для линейных/метрических моделей |
| Категориальный (номинальный) | конечное множество без порядка | город, марка авто | one-hot, target/count encoding, CatBoost |
| Порядковый | конечное упорядоченное множество | образование, рейтинг 1–5 | номер категории или one-hot |
| Множествозначный | подмножество | список купленных товаров | мешок слов |
| Сложный | текст, изображение, граф, ряд | отзыв, фото | эмбеддинги, нейросети (часть II курса) |

<summary><b>2. ML Lifecycle: как решают задачу на практике</b></summary>

Классика — **CRISP-DM** (Cross-Industry Standard Process for Data Mining): бизнес-понимание →
понимание данных → подготовка данных → моделирование → оценка → внедрение. Процесс
**итеративный**: постоянно возвращаемся к данным, признакам и постановке.

Современный ML lifecycle из лекции — 7 этапов:

| # | Этап | Результат этапа |
|---|---|---|
| 01 | **Постановка задачи** (Problem Definition) | Поняли бизнес-проблему и нужен ли вообще ML; выбрали бизнес-метрику и связали её с технической; формализовали задачу (классификация / регрессия / ранжирование); учли ограничения (время, интерпретируемость); продумали, как оценивать успех: офлайн-метрики, A/B-тест |
| 02 | **Сбор, подготовка и анализ данных** (Data Mining) | Данных достаточно и они будут доступны в проде; учли дисбаланс, пропуски, выбросы, шум — и осмыслили их, а не просто удалили; продумали разметку; сделали EDA и сформулировали гипотезы |
| 03 | **Выбор модели, метрики, валидации, признаков** | Модель выбрана осознанно (часто бустинг, но не всегда); ясно, какой **loss** оптимизируем и какую **метрику** считаем; выбрана схема валидации (train/test split, k-fold, time series split); сгенерированы и отобраны признаки; проверено отсутствие **утечек (data leakage)** |
| 04 | **Обучение** (Fit) | Используем только признаки, доступные в проде; следим за train/valid-метриками и переобучением; сравниваем с простыми моделями |
| 05 | **Предсказание и оценка** (Predict & Evaluation) | Честная оценка на новых данных; метрики выбраны **заранее**; сравнение с бейзлайном; связь ML-метрик с деньгами; проверка устойчивости; постобработка (калибровка, правила) |
| 06 | **Внедрение и поддержка** (Deploy / Monitoring) | Перенос из ноутбука в систему (API, пайплайн); **переобучение на всех данных** перед релизом; мониторинг качества и дрейфа; план регулярного переобучения |
| 07 | **Отчётность и коммуникация** | Презентация результата бизнесу, документация решений и гипотез, визуализации, обсуждение следующих шагов |

Главные мысли лекции:
- **Качество решения = данные + метрики + бизнес-ограничения**, а не «подобрать модель».
- ML без связи с бизнесом бесполезен, даже если метрики отличные.
- Нет лучшей метрики для всех случаев.

</details>

<summary><b>3. Метрика vs функция потерь</b></summary>

| | Функция потерь (Loss) | Метрика (Metric) |
|---|---|---|
| Зачем | **оптимизируется** при обучении: сообщает алгоритму, насколько плохо текущее предсказание и как обновить веса | **измеряет** качество: валидация, тест, сравнение моделей, мониторинг в проде |
| Требования | дифференцируемость / удобство оптимизации | интерпретируемость, связь с бизнесом |
| Примеры | MSE, MAE, Huber, Quantile, MSLE | MAE, RMSE, R², MAPE, WAPE |

**Метрика ≠ Loss.** Часто обучаем на одном (MSE — удобно), а отчитываемся другим (MAPE — понятно бизнесу).
Некоторые функции (MAE, MSE) играют обе роли.

</details>

<summary><b>4. Метрики и функции потерь регрессии</b></summary>

Обозначения: $y_i$ — истинное значение, $\hat y_i$ — предсказание, $\ell$ — число объектов,
$\bar y$ — среднее таргета.

**4.1. MAE — Mean Absolute Error**

$$
\text{MAE} = \frac{1}{\ell}\sum_{i=1}^{\ell} |y_i - \hat y_i|
$$

- В единицах таргета: MAE = 5 ₽ — «в среднем ошибаемся на 5 ₽».
- **Устойчива к выбросам**: ошибка 100 весит в 100 раз больше ошибки 1 (а не в 10 000, как в MSE).
- Не показывает направление ошибки (занижаем или завышаем).
- Неудобна для градиентной оптимизации: производная модуля не определена в 0 и всегда равна ±1.
- Оптимальная константа — **медиана** (вывод (см. раздел «2. Оптимальная константа для каждой функции потерь»)).

**4.2. MSE — Mean Squared Error**

$$
\text{MSE} = \frac{1}{\ell}\sum_{i=1}^{\ell} (y_i - \hat y_i)^2
$$

- Большие ошибки штрафуются **квадратично** — важно, где крупные промахи критичны (медицина, ценообразование).
- Гладкая, выпуклая, дифференцируемая — идеальна для градиентных методов.
- **Чувствительна к выбросам**: одна большая ошибка может доминировать.
- Единицы — квадрат единиц таргета (₽²), интерпретировать неудобно.
- Оптимальная константа — **среднее**; MSE = MLE при гауссовском шуме (вывод (см. раздел «3. Вероятностный смысл MSE и MAE»)).

**4.3. RMSE — Root Mean Squared Error**

$$
\text{RMSE} = \sqrt{\text{MSE}}
$$

- В единицах таргета — поэтому чаще используется в отчётах, чем MSE.
- Минимизация RMSE и MSE эквивалентна (корень монотонен).
- Всё ещё менее устойчива к выбросам, чем MAE. Всегда $\text{MAE} \le \text{RMSE} \le \sqrt{\ell}\cdot\text{MAE}$.
- Не показывает распределение ошибок: RMSE = 100 может быть «много мелких» или «одна огромная».

**4.4. R² — коэффициент детерминации**

$$
R^2 = 1 - \frac{\sum_{i}(y_i - \hat y_i)^2}{\sum_{i}(y_i - \bar y)^2} = 1 - \frac{\text{MSE(модели)}}{\text{MSE(константы } \bar y)}
$$

- Числитель — ошибка модели, знаменатель — ошибка лучшей константы (бейзлайна-среднего).
- $R^2 = 1$ — идеально; $R^2 = 0$ — не лучше среднего; $R^2 < 0$ — **хуже среднего** (бывает на тесте!).
- Не устойчив к выбросам (основан на MSE).
- Высокий $R^2$ не гарантирует хорошую модель (может быть систематическое смещение).
- **Зависит от дисперсии таргета**: на выборке с малым разбросом $y$ даже хорошая модель даст низкий $R^2$.
- Подробнее, включая $R^2 = \text{corr}^2$ и adjusted $R^2$: см. раздел «5. Свойства R²».

**4.5. MAPE — Mean Absolute Percentage Error**

$$
\text{MAPE} = \frac{1}{\ell}\sum_{i=1}^{\ell} \left| \frac{y_i - \hat y_i}{y_i} \right|
$$

- Интуитивна: «ошибка в пределах 7–10%» — любимая метрика в докладах бизнесу.
- Не зависит от масштаба — можно сравнивать разные задачи.
- **Не определена при $y_i = 0$**; около нуля взрывается (ошибка 1 при $y = 1$ — это 100%, при $y = 100$ — 1%).
- **Несимметрична**: недопрогноз ограничен 100%, перепрогноз — нет. Модель на MAPE **занижает** прогнозы.

**4.6. Другие метрики и функции потерь**

| Название | Формула | Особенности |
|---|---|---|
| **sMAPE** | $\frac{1}{\ell}\sum \frac{2\,\lvert y_i - \hat y_i\rvert}{\lvert y_i\rvert + \lvert\hat y_i\rvert}$ | «симметричная» MAPE, значения в $[0, 2]$; асимметрия всё равно остаётся |
| **WAPE** | $\frac{\sum \lvert y_i - \hat y_i\rvert}{\sum \lvert y_i\rvert}$ | MAE / средний модуль таргета; стабильна, популярна в ритейле |
| **MdAPE** | медиана $\lvert (y_i - \hat y_i)/y_i\rvert$ | робастный вариант MAPE |
| **MedAE** | медиана $\lvert y_i - \hat y_i\rvert$ | очень устойчива к выбросам |
| **MSLE / RMSLE** | $\sqrt{\frac{1}{\ell}\sum (\ln(1+y_i) - \ln(1+\hat y_i))^2}$ | важны **относительные** отклонения; штрафует недопрогноз сильнее; для $y \ge 0$ с большим разбросом (цены, продажи) |
| **Huber** | $\frac12 r^2$ при $\lvert r\rvert\le\delta$, иначе $\delta(\lvert r\rvert - \frac{\delta}{2})$ | MSE около нуля + MAE на хвостах: гладкая и робастная |
| **Quantile (pinball)** | $\tau(y - \hat y)$ при $y \ge \hat y$, иначе $(1-\tau)(\hat y - y)$ | предсказывает $\tau$-квантиль; предсказательные интервалы |
| **Log-cosh** | $\ln\cosh(\hat y - y)$ | гладкий аналог Huber |

**4.7. Как выбрать (таблица из лекции, дополненная)**

| Метрика | Когда использовать |
|---|---|
| MAE | важна равномерная оценка всех ошибок и устойчивость к выбросам |
| MSE | нужно сильнее штрафовать крупные ошибки; удобный loss для обучения |
| RMSE | то же, что MSE, но в масштабе таргета (отчёты) |
| R² | понять, насколько модель лучше константы; сравнить модели на **одном** датасете |
| MAPE | отчёт бизнесу в процентах; в таргете нет значений около нуля |
| WAPE | процентная метрика для рядов с нулями / разным масштабом |
| RMSLE | таргет ≥ 0 с большим разбросом, важны относительные ошибки, недопрогноз хуже перепрогноза |
| Quantile | нужен не точечный прогноз, а интервал / консервативная оценка (склад, SLA) |

</details>

<summary><b>5. Пример из лекции: выбираем одну из четырёх моделей</b></summary>

Цены квартир (млн): факт $y = (1.2,\ 2.8,\ 4.5,\ 6.6)$ — коммуналка, студия, «однушка», «двушка».

| Модель | Прогноз | MAE | MSE | RMSE | R² | MAPE | RMSLE |
|---|---|---|---|---|---|---|---|
| A | 1.5, 2.5, 3.5, 4.5 | 0.925 | 1.397 | 1.182 | 0.653 | 22.4% | 0.205 |
| B | 1.1, 3.1, 5.0, 6.4 | 0.275 | 0.097 | 0.312 | 0.976 | 8.3% | 0.064 |
| C | 1.4, 3.0, 4.3, 6.8 | 0.200 | 0.040 | 0.200 | 0.990 | 7.8% | **0.055** |
| D | 1.0, 2.6, 4.4, 6.6 | **0.125** | **0.022** | **0.150** | **0.994** | **6.5%** | 0.056 |

Модель D лучшая почти по всем метрикам, но по **RMSLE** чуть выигрывает C: D ошибается на
дешёвой коммуналке (1.0 вместо 1.2 — это −17%), а RMSLE чувствителен к относительным ошибкам
на малых значениях. **Выбор метрики может менять победителя.**

</details>

<summary><b>6. Код</b></summary>

```python
import numpy as np
from sklearn.metrics import (mean_absolute_error, mean_squared_error, r2_score,
                             mean_absolute_percentage_error, mean_squared_log_error,
                             median_absolute_error)

y = np.array([1.2, 2.8, 4.5, 6.6])
a = np.array([1.0, 2.6, 4.4, 6.6])

print("MAE  ", mean_absolute_error(y, a),  np.mean(np.abs(y - a)))
print("MSE  ", mean_squared_error(y, a),   np.mean((y - a) ** 2))
print("RMSE ", np.sqrt(mean_squared_error(y, a)))      # в sklearn>=1.4: root_mean_squared_error
print("R2   ", r2_score(y, a),  1 - np.mean((y - a) ** 2) / np.mean((y - y.mean()) ** 2))
print("MAPE ", mean_absolute_percentage_error(y, a))   # доля, не проценты!
print("MSLE ", mean_squared_log_error(y, a), np.mean((np.log1p(y) - np.log1p(a)) ** 2))
print("MedAE", median_absolute_error(y, a), np.median(np.abs(y - a)))
print("WAPE ", np.abs(y - a).sum() / np.abs(y).sum())
```

Обучение на разных функциях потерь в sklearn:

```python
from sklearn.linear_model import LinearRegression, HuberRegressor, QuantileRegressor, SGDRegressor
from sklearn.ensemble import GradientBoostingRegressor
from sklearn.compose import TransformedTargetRegressor

LinearRegression()                                 # MSE
HuberRegressor(epsilon=1.35)                       # Huber
QuantileRegressor(quantile=0.5, alpha=0)           # MAE (медианная регрессия)
SGDRegressor(loss="epsilon_insensitive")           # SVR-подобный loss
GradientBoostingRegressor(loss="absolute_error")   # 'squared_error', 'huber', 'quantile'
# MSLE = MSE по log1p(y):
TransformedTargetRegressor(regressor=LinearRegression(), func=np.log1p, inverse_func=np.expm1)
```

<details>
<summary><b>7. Типичные ошибки</b></summary>

- Оптимизировать одно, а отчитываться другим, не понимая разницы оптимумов (MSE → среднее, MAE → медиана, MAPE → занижение).
- Сравнивать $R^2$ между разными датасетами.
- Считать MAPE на таргете с нулями.
- Подбирать метрику **после** эксперимента под «красивый» результат.
- Использовать признаки, которые недоступны в момент предсказания (утечка из будущего).
- Забыть сравнить модель с бейзлайном (константа, «как вчера», простая линейная модель).

</details>

**Математика и выводы**

<details>
<summary><b>1. Формальная постановка: риск и эмпирический риск</b></summary>

Пусть объекты $x \in \mathbb{X}$ и ответы $y \in \mathbb{Y}$ порождаются неизвестным совместным
распределением $p(x, y)$. Модель — функция $a: \mathbb{X} \to \mathbb{Y}$ из некоторого семейства
$\mathcal{A}$ (например, все линейные функции). Функция потерь $L(y, a(x)) \ge 0$ штрафует
за отличие предсказания от ответа.

**Ожидаемый риск** (то, что мы на самом деле хотим минимизировать):

$$
R(a) = \mathbb{E}_{(x,y)\sim p}\, L\big(y, a(x)\big).
$$

Распределение $p$ неизвестно, у нас есть только обучающая выборка
$X^\ell = \lbrace (x_i, y_i) \rbrace_{i=1}^{\ell}$, поэтому минимизируют **эмпирический риск**
(принцип ERM — Empirical Risk Minimization):

$$
Q(a, X^\ell) = \frac{1}{\ell} \sum_{i=1}^{\ell} L\big(y_i, a(x_i)\big) \to \min_{a \in \mathcal{A}}.
$$

По закону больших чисел $Q(a, X^\ell) \to R(a)$ при $\ell \to \infty$ **для фиксированной** $a$.
Но модель $\hat a$ подбирается по той же выборке, поэтому $Q(\hat a, X^\ell)$ — смещённая
(оптимистичная) оценка $R(\hat a)$. Отсюда необходимость отложенной выборки и кросс-валидации
(тема [05](../05_validation/README.md)) и разговор о переобучении (тема [06](../06_bias_variance/README.md)).

**Байесовский (оптимальный) алгоритм** для данной функции потерь минимизирует риск поточечно:

$$
a^*(x) = \arg\min_{c} \; \mathbb{E}\big[ L(y, c) \mid x \big].
$$

То есть задача сводится к поиску «оптимальной константы» для условного распределения $p(y \mid x)$.
Именно поэтому следующий раздел так важен: **выбор функции потерь определяет, какую
статистику распределения $y \mid x$ модель пытается предсказать.**

</details>

<details>
<summary><b>2. Оптимальная константа для каждой функции потерь</b></summary>

Рассмотрим простейшую модель $a(x) \equiv c$ и найдём $c^*$, минимизирующую потери на выборке
$y_1, \dots, y_\ell$.

**2.1. MSE → среднее**

$$
Q(c) = \frac{1}{\ell}\sum_{i=1}^{\ell}(y_i - c)^2, \qquad
Q'(c) = -\frac{2}{\ell}\sum_{i=1}^{\ell}(y_i - c) = 0
\;\Rightarrow\; c^* = \frac{1}{\ell}\sum_{i=1}^{\ell} y_i = \bar y.
$$

$Q''(c) = 2 > 0$, значит это минимум. Вывод: **модель, обученная на MSE, предсказывает условное
среднее** $\mathbb{E}[y \mid x]$.

Полезное разложение (теорема Пифагора для MSE): для любого $c$

$$
\frac{1}{\ell}\sum_i (y_i - c)^2 = \underbrace{\frac{1}{\ell}\sum_i (y_i - \bar y)^2}_{\text{дисперсия}} + (\bar y - c)^2 ,
$$

так как перекрёстный член $\frac{2}{\ell}(\bar y - c)\sum_i (y_i - \bar y) = 0$.

**2.2. MAE → медиана**

$$
Q(c) = \frac{1}{\ell}\sum_{i=1}^{\ell}|y_i - c|.
$$

Функция выпуклая, кусочно-линейная. Там, где она дифференцируема ($c \ne y_i$):

$$
Q'(c) = \frac{1}{\ell}\sum_{i=1}^{\ell} \operatorname{sign}(c - y_i) = \frac{N_{<}(c) - N_{>}(c)}{\ell},
$$

где $N_{<}(c)$ и $N_{>}(c)$ — число точек $y_i$ левее и правее $c$.

Производная отрицательна, пока слева от $c$ меньше половины точек, и положительна, когда больше.
Минимум достигается там, где субградиент содержит 0, т.е. слева и справа от $c$ одинаковое число
точек — это **медиана**. (При чётном $\ell$ любая точка между двумя средними элементами — минимум.)

Следствие: модель на MAE предсказывает **условную медиану**, поэтому MAE устойчива к выбросам —
выброс сдвигает медиану максимум на одну позицию в вариационном ряду, а среднее — на величину
$\text{выброс}/\ell$, сколь угодно сильно.

**2.3. Квантильная (pinball) потеря → $\tau$-квантиль**

$$
L_\tau(y, a) = \begin{cases} \tau\,(y - a), & y \ge a,\\ (1-\tau)\,(a - y), & y < a. \end{cases}
$$

Производная по $c$ для суммы: $Q'(c) = \frac{1}{\ell}\big[(1-\tau)\,N_{<}(c) - \tau\,N_{>}(c)\big]$.
Обнуляется, когда доля точек слева от $c$ равна $\tau$: $c^*$ — **$\tau$-квантиль** выборки.
При $\tau = 0.5$ получаем MAE/2 и медиану.

**2.4. MAPE → взвешенная медиана**

$$
Q(c) = \frac{1}{\ell}\sum_i \frac{|y_i - c|}{|y_i|} = \frac{1}{\ell}\sum_i w_i\,|y_i - c|, \quad w_i = \frac{1}{|y_i|}.
$$

Аналогично 2.2, минимум там, где **суммарный вес** точек слева равен суммарному весу справа —
взвешенная медиана с весами $1/|y_i|$. Маленькие $y_i$ получают огромные веса, поэтому
оптимум MAPE **смещён вниз**: модель на MAPE систематически занижает прогноз.

**2.5. MSLE / RMSLE → «геометрическое» среднее**

$$
Q(c) = \frac{1}{\ell}\sum_i \big(\ln(1 + y_i) - \ln(1 + c)\big)^2 .
$$

Замена $z = \ln(1+c)$ сводит задачу к MSE по $z_i = \ln(1+y_i)$, значит
$z^* = \frac{1}{\ell}\sum_i \ln(1 + y_i)$ и

$$
c^* = \exp\Big(\frac{1}{\ell}\sum_i \ln(1+y_i)\Big) - 1 = \Big(\prod_i (1+y_i)\Big)^{1/\ell} - 1 .
$$

Это геометрическое среднее величин $1+y_i$ минус 1; оно не больше арифметического
(неравенство о средних), поэтому оптимум MSLE тоже меньше среднего.

> **Практический вывод.** Обучение на MSLE эквивалентно обучению на MSE по таргету
> $\tilde y = \ln(1+y)$ с последующим обратным преобразованием $\hat y = e^{\hat{\tilde y}} - 1$.

**Сводная таблица**

| Функция потерь | Оптимальная константа | Что предсказывает модель |
|---|---|---|
| MSE | $\bar y$ — среднее | $\mathbb{E}[y\mid x]$ |
| MAE | медиана | $\operatorname{med}(y\mid x)$ |
| Quantile $\tau$ | $\tau$-квантиль | $q_\tau(y\mid x)$ |
| MAPE | взвешенная медиана с весами $1/\lvert y\rvert$ | смещённая вниз медиана |
| MSLE | $\exp(\overline{\ln(1+y)}) - 1$ | «геометрическое» среднее |

</details>

<details>
<summary><b>3. Вероятностный смысл MSE и MAE</b></summary>

Предположим модель данных $y = a(x) + \varepsilon$.

**3.1. Гауссовский шум → MSE**

Пусть $\varepsilon \sim \mathcal{N}(0, \sigma^2)$ независимо. Тогда
$p(y_i \mid x_i) = \frac{1}{\sqrt{2\pi}\sigma}\exp\big(-\frac{(y_i - a(x_i))^2}{2\sigma^2}\big)$, и
логарифм правдоподобия выборки

$$
\ln \prod_{i=1}^{\ell} p(y_i \mid x_i) = -\ell \ln(\sqrt{2\pi}\sigma) - \frac{1}{2\sigma^2}\sum_{i=1}^{\ell}\big(y_i - a(x_i)\big)^2 .
$$

Первое слагаемое от $a$ не зависит, поэтому

$$
\arg\max_a \text{ правдоподобие} = \arg\min_a \sum_i \big(y_i - a(x_i)\big)^2 .
$$

**Минимизация MSE = метод максимального правдоподобия при нормальном шуме.**

**3.2. Лапласовский шум → MAE**

Пусть $\varepsilon \sim \text{Laplace}(0, b)$: $p(\varepsilon) = \frac{1}{2b}e^{-|\varepsilon|/b}$. Тогда

$$
\ln \prod_i p(y_i \mid x_i) = -\ell\ln(2b) - \frac{1}{b}\sum_i |y_i - a(x_i)| ,
$$

и MLE эквивалентен минимизации MAE. У распределения Лапласа «тяжёлые хвосты» (по сравнению
с гауссовским) — модель заранее «ожидает» выбросы и меньше на них реагирует.

**3.3. Лог-нормальный шум → MSLE**

Если $\ln(1+y) = \ln(1+a(x)) + \varepsilon$, $\varepsilon \sim \mathcal{N}(0,\sigma^2)$, т.е. ошибка
**мультипликативна** ($1+y = (1+a)\,e^{\varepsilon}$), то MLE эквивалентен минимизации MSLE.
Это хорошая модель для цен, доходов, продаж — величин, у которых разброс растёт с уровнем.

</details>

<details>
<summary><b>4. Градиенты функций потерь по предсказанию</b></summary>

Обозначим $r = a - y$ (остаток). Градиенты по предсказанию $a$ нужны для градиентного спуска и,
особенно, для градиентного бустинга (тема [09](../09_gradient_boosting/README.md)), где
каждое следующее дерево обучается на антиградиент $-\partial L/\partial a$.

| $L(y, a)$ | $\partial L / \partial a$ | $\partial^2 L/\partial a^2$ | Комментарий |
|---|---|---|---|
| $\frac12 (a-y)^2$ | $r$ | $1$ | Градиент растёт с ошибкой — выбросы доминируют |
| $\lvert a - y\rvert$ | $\operatorname{sign}(r)$ | $0$ (п.в.) | Градиент ограничен, но не определён в 0 |
| Huber$_\delta$ | $r$ при $\lvert r\rvert\le\delta$, иначе $\delta\operatorname{sign}(r)$ | $1$ или $0$ | «Обрезанный» градиент MSE |
| $\ln\cosh(r)$ | $\tanh(r)$ | $1 - \tanh^2(r)$ | Гладкий аналог Huber |
| $L_\tau$ | $1-\tau$ при $a>y$, $-\tau$ при $a<y$ | $0$ | Асимметричный |
| $\frac12(\ln(1+a) - \ln(1+y))^2$ | $\dfrac{\ln(1+a)-\ln(1+y)}{1+a}$ | — | |

Почему MAE «хуже оптимизируется» градиентными методами (тезис лекции):
- в точке $r = 0$ производная не определена (используют субградиент);
- модуль градиента всегда равен 1 — даже вблизи оптимума шаг не уменьшается, и градиентный спуск
  с постоянным шагом «прыгает» вокруг минимума; приходится уменьшать шаг;
- вторая производная равна 0, поэтому методы второго порядка (Ньютон, XGBoost) неприменимы напрямую.

</details>

<details>
<summary><b>5. Свойства R²</b></summary>

$$
R^2 = 1 - \frac{\sum_i (y_i - \hat y_i)^2}{\sum_i (y_i - \bar y)^2} = 1 - \frac{\text{MSE}(a)}{\text{MSE}(\bar y)} .
$$

**(а) $R^2 \le 1$**, равенство — только при идеальных предсказаниях.

**(б) $R^2$ может быть отрицательным.** Знаменатель — MSE лучшей константы (раздел 2.1). Если
модель хуже константы, $\text{MSE}(a) > \text{MSE}(\bar y)$ и $R^2 < 0$. На **обучающей** выборке
у линейной регрессии с intercept $R^2 \in [0, 1]$ (константа входит в семейство моделей,
а МНК находит лучшую модель в семействе), но на **тесте** — легко отрицательный.

**(в) Для линейной регрессии с intercept на обучающей выборке $R^2 = \operatorname{corr}^2(y, \hat y)$.**

Набросок доказательства. Для МНК с intercept остатки $e = y - \hat y$ ортогональны всем столбцам
матрицы признаков, включая столбец единиц, поэтому $\sum_i e_i = 0$ и $\sum_i e_i \hat y_i = 0$.
Отсюда $\bar{\hat y} = \bar y$ и

$$
\sum_i (y_i-\bar y)^2 = \sum_i (\hat y_i - \bar y)^2 + \sum_i e_i^2
$$

(TSS = ESS + RSS). Тогда $R^2 = \text{ESS}/\text{TSS}$. С другой стороны,
$\operatorname{cov}(y,\hat y) = \operatorname{cov}(\hat y + e, \hat y) = \operatorname{var}(\hat y)$, значит
$\operatorname{corr}^2(y,\hat y) = \frac{\operatorname{var}(\hat y)^2}{\operatorname{var}(y)\operatorname{var}(\hat y)} = \frac{\operatorname{var}(\hat y)}{\operatorname{var}(y)} = \frac{\text{ESS}}{\text{TSS}}$. ∎

**(г) Зависимость от дисперсии таргета.** При фиксированном MSE модели $R^2$ тем меньше, чем
меньше разброс $y$ в выборке. Поэтому $R^2$ нельзя сравнивать между датасетами с разным
разбросом таргета (например, между городами с разным диапазоном цен).

**(д) Adjusted $R^2$.** Добавление любого признака не уменьшает $R^2$ на обучении. Поправка:

$$
R^2_{adj} = 1 - (1 - R^2)\frac{\ell - 1}{\ell - d - 1},
$$

где $d$ — число признаков. Она растёт, только если новый признак уменьшает RSS сильнее,
чем «ожидается» от случайного признака.

</details>

<details>
<summary><b>6. Асимметрия MAPE и RMSLE</b></summary>

**MAPE.** Пусть $y > 0$ и прогноз $a \ge 0$.
- Недопрогноз ($a < y$): ошибка $\frac{y - a}{y} \le 1$, т.е. **не больше 100%**.
- Перепрогноз ($a > y$): ошибка $\frac{a - y}{y}$ **не ограничена**.

Модель «выгоднее» занижать — это и есть смещение вниз из раздела 2.4.

**sMAPE** пытается симметризовать: $\text{sMAPE} = \frac{1}{\ell}\sum_i \frac{2|y_i - a_i|}{|y_i| + |a_i|} \in [0, 2]$,
но асимметрия остаётся: при $y = 100$ прогнозы $a = 50$ и $a = 150$ дают $0.67$ и $0.4$ соответственно.

**WAPE** $= \frac{\sum_i |y_i - a_i|}{\sum_i |y_i|}$ — это MAE, нормированная на средний модуль таргета;
не взрывается на отдельных малых $y_i$ (если сумма в знаменателе не мала).

**RMSLE.** $\ln(1+a) - \ln(1+y) = \ln\frac{1+a}{1+y}$ — штрафуется **отношение**, а не разность. Для
$y = 100$: $a = 50$ даёт $|\ln(51/101)| \approx 0.683$, $a = 150$ даёт $\ln(151/101) \approx 0.402$.
**Недопрогноз штрафуется сильнее перепрогноза** на ту же абсолютную величину.

</details>

<details>
<summary><b>7. Huber, log-cosh и квантильная регрессия</b></summary>

**Huber loss** склеивает MSE около нуля и MAE на хвостах:

$$
L_\delta(r) = \begin{cases} \frac12 r^2, & |r| \le \delta,\\ \delta\big(|r| - \frac12\delta\big), & |r| > \delta. \end{cases}
$$

Проверка гладкости в точке $r = \delta$: значения $\frac12\delta^2$ и $\delta(\delta - \frac12\delta) = \frac12\delta^2$
совпадают; производные $\delta$ и $\delta$ совпадают. Значит $L_\delta \in C^1$. Вторая производная
разрывна (1 → 0). Параметр $\delta$ — порог, начиная с которого ошибку считают выбросом;
разумная эвристика — порядка медианы $|r|$ или 1.35·σ (тогда эффективность при гауссовском шуме ≈ 95%).

**Log-cosh**: $L(r) = \ln\cosh r$. Разложение: при малых $r$ $\ln\cosh r \approx \frac{r^2}{2}$, при больших
$\ln\cosh r \approx |r| - \ln 2$. Ведёт себя как Huber с $\delta = 1$, но дважды дифференцируема
всюду, поэтому подходит для методов второго порядка.

**Квантильная регрессия.** Обучив модели на $L_{0.05}$ и $L_{0.95}$, получаем 90%-ный
**предсказательный интервал**. Проверка: доля объектов теста, у которых $y$ ниже прогноза
$\tau$-модели, должна быть ≈ $\tau$ (калибровка квантилей).

```python
import numpy as np
from sklearn.ensemble import GradientBoostingRegressor

rng = np.random.default_rng(0)
X = rng.uniform(0, 10, (2000, 1))
y = np.sin(X[:, 0]) * 3 + rng.normal(0, 0.3 + 0.2 * X[:, 0])   # гетероскедастичный шум

models = {tau: GradientBoostingRegressor(loss="quantile", alpha=tau, n_estimators=200).fit(X, y)
          for tau in (0.05, 0.5, 0.95)}
lo, hi = models[0.05].predict(X), models[0.95].predict(X)
print("Покрытие 90%-интервала:", np.mean((y >= lo) & (y <= hi)))   # ≈ 0.9
```

<summary><b>Дополнительно: детали</b></summary>

- **MSE = MLE при гауссовском шуме**, MAE = MLE при шуме Лапласа (тяжёлые хвосты → устойчивость к выбросам).
- **Huber loss** — MSE около нуля + MAE на хвостах: гладкий и робастный. **Quantile loss** с $\tau=0.05/0.95$ даёт предсказательный интервал.
- **RMSLE** = RMSE по $\log(1+y)$: штрафует отношение $\frac{1+\hat y}{1+y}$, недопрогноз сильнее перепрогноза.
- $R^2$ зависит от дисперсии таргета — нельзя сравнивать между датасетами.
- Процесс итеративный (CRISP-DM): качество = данные + метрики + бизнес-ограничения.

```text
D: MAE=0.125  RMSE=0.150  R2=0.994  MAPE=6.5%  RMSLE=0.0556
```

```python
# Оптимальная константа: MSE -> среднее, MAE -> медиана (поэтому MAE устойчива к выбросам)
y_out = np.array([1, 2, 3, 4, 100])
cs = np.linspace(0, 100, 10001)
best_mse = cs[np.argmin([np.mean((y_out - c) ** 2) for c in cs])]
best_mae = cs[np.argmin([np.mean(np.abs(y_out - c)) for c in cs])]
print(f"argmin MSE = {best_mse:.2f} (mean = {y_out.mean()}),  argmin MAE = {best_mae:.2f} (median = {np.median(y_out)})")
```
