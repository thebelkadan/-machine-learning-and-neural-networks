# 33. Временные ряды: прогнозирование, валидация, модели

[Шпаргалка (ноутбук)](../../cheatsheet.ipynb) · [Оглавление курса](../../README.md)

**Суть.** Временной ряд — наблюдения, упорядоченные во времени; соседние значения зависимы, а будущее недоступно при
обучении. Ряд обычно раскладывают на **тренд**, **сезонность** и **остаток**. Прогноз всегда начинают с **наивных
бейзлайнов** (последнее значение, значение год назад) и честной **валидации по времени** — случайное перемешивание даёт
утечку будущего. Классические модели — **экспоненциальное сглаживание** (ETS, Holt-Winters) и **ARIMA**; ML-подход —
бустинг или линейная модель на **лаговых признаках** (с оговоркой: деревья не экстраполируют тренд); для тысяч рядов —
**глобальные** модели и нейросети (N-BEATS, TFT, PatchTST, предобученные модели вроде Chronos). Качество меряют
масштабно-независимыми метриками (**MASE**) и квантильными потерями для интервалов.

| Термин | Определение |
|---|---|
| Тренд / сезонность / остаток | долгосрочное изменение / повторяющийся цикл (неделя, год) / нерегулярная часть |
| Аддитивная / мультипликативная модель | $y=T+S+R$ / $y=T\cdot S\cdot R$ (амплитуда сезонности растёт с уровнем) |
| Стационарность | статистические свойства не меняются во времени; добиваются логарифмом и разностями |
| Лаг | значение ряда $k$ шагов назад $y_{t-k}$ — основной признак |
| Горизонт $H$ | на сколько шагов вперёд прогноз |
| Рекурсивный / прямой прогноз | одна модель на шаг вперёд, прогнозы подставляются как лаги / отдельная модель на каждый шаг горизонта |
| Скользящая валидация | обучение на прошлом, проверка на следующем отрезке, окно сдвигается |
| MASE | MAE прогноза / MAE сезонного наивного прогноза на обучении; <1 — лучше наивного |

**Ключевые формулы**

$$
\hat y_{t+1}=\alpha y_t+(1-\alpha)\hat y_t,\qquad
y_t=c+\sum_{i=1}^{p}\varphi_iy_{t-i}+\sum_{j=1}^{q}\theta_j\varepsilon_{t-j}+\varepsilon_t,\qquad
\mathrm{MASE}=\frac{\frac1H\sum_h\lvert y_{T+h}-\hat y_{T+h}\rvert}{\frac{1}{T-m}\sum_{t=m+1}^{T}\lvert y_t-y_{t-m}\rvert}
$$

<details>
<summary><b>1. Чем временные ряды особенные</b></summary>

- **Порядок важен**, наблюдения **зависимы** (автокорреляция) — нарушено предположение i.i.d. обычного ML (тема 01).
- Распределение **меняется** со временем: тренды, структурные сдвиги (пандемия, смена цен), новые сезонности.
- Прогноз нужен на несколько шагов вперёд, часто с **неопределённостью** (интервалы, квантили — для запасов, мощностей).
- Задачи: прогнозирование (спрос, нагрузка, продажи, финансы), обнаружение аномалий (тема 10), классификация рядов (датчики,
  ЭКГ), заполнение пропусков.

**Сначала смотреть на график:** уровень, тренд, сезонность (какой период?), выбросы, пропуски, изменения режима; график
автокорреляции (ACF) — пики на лагах 7, 12, 52 выдают сезонность.

</details>

<details>
<summary><b>2. Валидация: только по времени</b></summary>

- Сплит **по времени**: обучение — прошлое, тест — последний отрезок длины горизонта. Никакого `shuffle=True`.
- **Скользящая (expanding/rolling) валидация:** несколько разрезов, каждый раз обучение на всём (или последнем окне) до момента,
  проверка на следующих $H$ шагах; `TimeSeriesSplit` в sklearn (тема 05).
- **Зазор (gap)** между обучением и проверкой, если признаки используют окна или есть задержка получения данных.
- **Утечки:** нормировка или заполнение пропусков по всему ряду, признаки, считающиеся с будущими значениями (центрированное
  скользящее среднее), целевые статистики без сдвига. Пример кода этой темы: та же модель на лаговых признаках при случайном KFold
  показывает ошибку вдвое ниже, чем при честном `TimeSeriesSplit`.
- Валидировать на том же **горизонте**, что и в работе: качество на шаге 1 и на шаге 24 сильно различается.

</details>

<details>
<summary><b>3. Метрики</b></summary>

| Метрика | Плюсы | Минусы |
|---|---|---|
| MAE, RMSE | понятные, в единицах ряда | нельзя сравнивать между рядами разного масштаба |
| MAPE | в процентах | не определена при нуле, асимметрична, взрывается около нуля (тема 01) |
| sMAPE | ограничена | тоже нестабильна при малых значениях |
| **MASE** | масштабно-независима, сравнение с наивным | нужен сезонный период |
| WAPE ($\sum\lvert e\rvert/\sum\lvert y\rvert$) | устойчива к нулям, популярна в ритейле | доминируют крупные ряды |
| **Pinball (квантильная) loss** | для прогноза квантилей и интервалов | по одной на каждый квантиль |

</details>

<details>
<summary><b>4. Бейзлайны</b></summary>

| Прогноз | Формула | Когда хорош |
|---|---|---|
| Наивный | $\hat y_{T+h}=y_T$ | случайное блуждание (курсы валют) |
| Сезонный наивный | $\hat y_{T+h}=y_{T+h-m}$ | сильная стабильная сезонность |
| Среднее | $\hat y=\bar y$ | стационарный шум |
| Дрейф | $y_T+h\frac{y_T-y_1}{T-1}$ | устойчивый линейный тренд |
| Сезонный наивный × рост | значение год назад × средний годовой рост | тренд + мультипликативная сезонность |

Пример кода этой темы (авиапассажиры 1949–1960, прогноз на 24 месяца): наивный — MASE 4.03, сезонный наивный — 2.49, сезонный × рост —
0.46. Простая формула с правильной структурой ряда обыгрывает «умные» модели, которые её не учитывают.

</details>

<details>
<summary><b>5. Декомпозиция и стационарность</b></summary>

- **Логарифм** превращает мультипликативную сезонность в аддитивную и стабилизирует дисперсию (преобразование Бокса–Кокса — обобщение).
- **Разности:** $y_t-y_{t-1}$ убирает тренд, сезонная разность $y_t-y_{t-m}$ — сезонность (тема 20).
- **Декомпозиция** (классическая скользящим средним, **STL** — устойчивая на основе LOESS): тренд + сезонность + остаток; анализ
  остатка, прогноз частей по отдельности.
- **Стационарность** проверяют глазами и тестами (ADF — нулевая гипотеза о единичном корне, KPSS — о стационарности).
- **ACF / PACF:** автокорреляции и частные автокорреляции по лагам — подсказывают порядки ARIMA и важные лаги для признаков.

</details>

<details>
<summary><b>6. Экспоненциальное сглаживание (ETS)</b></summary>

- **Простое (SES):** прогноз — экспоненциально взвешенное среднее прошлого, $\hat y_{t+1}=\alpha y_t+(1-\alpha)\hat y_t$.
- **Holt:** + сглаженный тренд (уровень и наклон), можно с затуханием тренда (damped) — обычно точнее на длинном горизонте.
- **Holt-Winters:** + сезонная компонента, аддитивная или мультипликативная.
- **ETS** — общая статистическая рамка (Error, Trend, Seasonal, каждая — нет/аддитивная/мультипликативная) с правдоподобием,
  выбором модели по AIC и интервалами прогноза.

Сильный, быстрый, интерпретируемый метод для одиночных рядов; в соревнованиях M3/M4 комбинации ETS-подобных моделей долго
были трудно обыгрываемы.

</details>

<details>
<summary><b>7. ARIMA</b></summary>

- **AR(p):** значение — линейная комбинация $p$ предыдущих + шум. **MA(q):** линейная комбинация $q$ прошлых ошибок.
- **I(d):** модель для ряда после $d$ разностей. **SARIMA** $(p,d,q)(P,D,Q)_m$ — плюс сезонные компоненты.
- **ARIMAX:** с внешними регрессорами (праздники, цены, погода).
- Подбор: стационаризовать, по ACF/PACF выбрать порядки или auto-ARIMA перебором по AIC; проверить остатки (белый шум, тест
  Льюнга–Бокса).

Хорошо для коротких рядов с понятной структурой; плохо масштабируется на тысячи рядов и нелинейные зависимости.

</details>

<details>
<summary><b>8. ML-подход: признаки и бустинг</b></summary>

Задача превращается в регрессию: строка — момент времени, признаки — из прошлого:
- лаги $y_{t-1},\dots,y_{t-k}$, сезонные лаги $y_{t-m}$;
- скользящие статистики по прошлому окну (среднее, std, min, max) — сдвинутые, чтобы не видеть текущее значение;
- календарь: день недели, месяц, праздники, конец месяца; внешние признаки (цены, промо, погода);
- для многих рядов — идентификатор и характеристики ряда (магазин, товар, категория).

**Многошаговый прогноз:** **рекурсивный** (одна модель на $h=1$, прогнозы подставляются как лаги — ошибки накапливаются),
**прямой** (отдельная модель на каждый $h$ — без накопления, но больше моделей и меньше данных на каждую), **MIMO** (одна
модель выдаёт весь горизонт).

**Важная ловушка:** деревья и бустинг **не экстраполируют** — прогноз не выходит за диапазон таргетов обучения. При растущем тренде
бустинг на уровне ряда систематически занижает прогноз (в примере кода этой темы: MASE 1.74 у бустинга против 0.46 у Ridge на тех
же признаках в логарифмах). Решение — предсказывать **изменение** (разность, отношение к прошлому году) или убирать тренд
перед моделью.

</details>

<details>
<summary><b>9. Глобальные модели и нейросети</b></summary>

- **Глобальная модель** — одна на тысячи рядов (бустинг по всем рядам с признаками ряда, нейросеть) — учится на общих
  закономерностях; победители M5 (продажи Walmart) — LightGBM на лаговых признаках по всем рядам.
- **DeepAR** — авторегрессионная RNN (тема 20), выдающая параметры распределения (вероятностный прогноз).
- **N-BEATS / N-HiTS** — полносвязные блоки с остаточными связями, интерпретируемые тренд/сезонность; победители M4 среди
  чистых нейросетей.
- **Temporal Fusion Transformer** — внимание + отбор признаков + известные будущие ковариаты (праздники, промо).
- **PatchTST** — трансформер на «патчах» ряда (как ViT, тема 28); канально-независимая обработка.
- **Foundation-модели** (Chronos, TimesFM, Moirai, TimeGPT): предобучены на огромном числе рядов, дают zero-shot прогноз — сильный
  бейзлайн, когда истории мало.

Когда нейросети оправданы: много связанных рядов, богатые ковариаты, длинная история. Для одного короткого ряда (как
авиапассажиры, тема 20) статистические модели и бейзлайны обычно не хуже.

</details>

**Математика и выводы**

<details>
<summary><b>1. Простое экспоненциальное сглаживание как взвешенное среднее</b></summary>

Раскрывая рекурсию $\hat y_{t+1}=\alpha y_t+(1-\alpha)\hat y_t$:

$$
\hat y_{t+1}=\alpha\sum_{k=0}^{t-1}(1-\alpha)^ky_{t-k}+(1-\alpha)^t\hat y_1 .
$$

Веса убывают геометрически, их сумма стремится к 1. $\alpha\to1$ — наивный прогноз, $\alpha\to0$ — среднее всей истории; эффективная
«память» $\approx1/\alpha$ наблюдений. Эквивалентная форма коррекции ошибки: $\hat y_{t+1}=\hat y_t+\alpha(y_t-\hat y_t)$ — сдвигаемся к факту на долю
$\alpha$ ошибки (как шаг SGD для оценки среднего). SES оптимален (в смысле MSE) для модели «случайное блуждание + шум» — модели
ARIMA(0,1,1).

</details>

<details>
<summary><b>2. AR(1): стационарность и автокорреляция</b></summary>

$y_t=\varphi y_{t-1}+\varepsilon_t$, $\varepsilon_t\sim(0,\sigma^2)$. Если $\lvert\varphi\rvert<1$, ряд стационарен: $\operatorname{Var}y=\varphi^2\operatorname{Var}y+\sigma^2\Rightarrow\operatorname{Var}y=\frac{\sigma^2}{1-\varphi^2}$,
автокорреляция $\rho_k=\varphi^k$ — затухает экспоненциально; PACF обрывается после лага 1 (отсюда правило выбора порядка AR по PACF,
MA — по ACF). При $\varphi=1$ — **случайное блуждание**: дисперсия растёт как $t\sigma^2$, ряд нестационарен, первая разность
стационарна (единичный корень, $d=1$). Прогноз AR(1) на $h$ шагов: $\hat y_{T+h}=\varphi^hy_T$ → сходится к среднему, дисперсия ошибки
$\sigma^2\frac{1-\varphi^{2h}}{1-\varphi^2}$ растёт с горизонтом — интервалы расширяются.

</details>

<details>
<summary><b>3. MASE</b></summary>

$$
\mathrm{MASE}=\frac{\frac1H\sum_{h=1}^{H}\lvert y_{T+h}-\hat y_{T+h}\rvert}{\frac{1}{T-m}\sum_{t=m+1}^{T}\lvert y_t-y_{t-m}\rvert}.
$$

Знаменатель — средняя ошибка **одношагового** сезонного наивного прогноза на **обучающем** отрезке; он не зависит от тестового
окна, всегда положителен (если ряд не постоянен) — нет проблем MAPE с нулями. Масштабно-независима: можно усреднять по рядам
разного размера. $\mathrm{MASE}<1$ — прогноз лучше, чем одношаговый сезонный наивный в среднем на истории. Так как знаменатель —
одношаговая ошибка, а числитель — ошибка на горизонте $H$, на длинных горизонтах MASE > 1 бывает и у хороших моделей.

</details>

<details>
<summary><b>4. Рекурсивная стратегия: накопление ошибки</b></summary>

Для AR(1) с оценкой $\hat\varphi=\varphi+\delta$ рекурсивный прогноз $\hat y_{T+h}=\hat\varphi^hy_T$; ошибка из-за неточности параметра
$\approx h\varphi^{h-1}\delta\,y_T$ — растёт с горизонтом (при $\lvert\varphi\rvert\approx1$ почти линейно). В нелинейных моделях ошибки ещё и попадают
на вход: модель на шагах $h>1$ видит свои прогнозы, распределение которых отличается от реальных лагов при обучении (как
exposure bias в seq2seq, тема 22). Прямая стратегия обучает модель $f_h$ сразу на цели $y_{t+h}$ — нет накопления, но каждая модель
видит меньше данных и прогнозы на разных шагах могут быть несогласованы. Компромиссы: DirRec, MIMO, обучение рекурсивной модели
на собственных прогнозах.

</details>

<details>
<summary><b>5. Pinball loss даёт квантиль</b></summary>

$L_\tau(y,q)=\tau(y-q)$ при $y\ge q$ и $(1-\tau)(q-y)$ при $y<q$. Ожидаемый лосс $\mathbb E L_\tau(Y,q)$ по $q$:
производная $-\tau P(Y>q)+(1-\tau)P(Y<q)=F(q)-\tau$, ноль при $F(q)=\tau$ — минимум в $\tau$-квантиле (тема 01). Поэтому модель, обученная на
pinball loss с $\tau=0.9$, выдаёт 90-й перцентиль; пара $\tau=0.05$ и $0.95$ — 90-процентный интервал. Проверка — эмпирическое покрытие
на отложенном отрезке.

</details>

<details>
<summary>Почему нельзя перемешивать данные при валидации временного ряда?</summary>

модель увидит будущее (соседние по времени точки сильно похожи), оценка будет завышена (в примере ошибка при KFold вдвое ниже честной).

</details>

<details>
<summary>С чего начинать прогноз?</summary>

с графика и наивных бейзлайнов: последнее значение и значение сезон назад; без них непонятно, хороша ли модель.

</details>

<details>
<summary>Почему бустинг плохо прогнозирует ряд с трендом?</summary>

деревья не выходят за диапазон обучающих таргетов; нужно прогнозировать изменение или убрать тренд.

</details>

<details>
<summary>Чем MASE лучше MAPE?</summary>

не ломается на нулях, масштабно-независима, сравнивает с наивным прогнозом.

</details>

<details>
<summary>Рекурсивный или прямой многошаговый прогноз?</summary>

рекурсивный проще, но копит ошибки; прямой без накопления, но нужна модель на каждый шаг.

</details>

<details>
<summary>Зачем логарифм?</summary>

мультипликативная сезонность и рост дисперсии с уровнем становятся аддитивными и постоянными.

</details>

<details>
<summary>Когда нужны нейросети для рядов?</summary>

много связанных рядов и ковариат; для одного короткого ряда статистические модели обычно не хуже.

<summary><b>Примеры кода (с результатами запуска)</b></summary>

Запустить их можно в ноутбуке [`cheatsheet.ipynb`](../../cheatsheet.ipynb).

```python
# Авиапассажиры: бейзлайны против моделей на лаговых признаках, прогноз на 24 месяца, метрика MASE
import os, numpy as np, pandas as pd
from sklearn.ensemble import HistGradientBoostingRegressor
from sklearn.linear_model import Ridge
from sklearn.model_selection import KFold, TimeSeriesSplit, cross_val_score
path = "materials/data/international-airline-passengers.csv"
y = pd.read_csv(path, skipfooter=2, engine="python").iloc[:, 1].astype(float).to_numpy()   # 144 месяца
H, m = 24, 12
train, test = y[:-H], y[-H:]
mae = lambda a, b: np.mean(np.abs(a - b))
scale = mae(train[m:], train[:-m])                       # MAE сезонного наивного на train — знаменатель MASE
mase = lambda forecast: mae(forecast, test) / scale

naive = np.repeat(train[-1], H)
seasonal = np.tile(train[-m:], H // m)
drift = train[-1] + (train[-1] - train[0]) / (len(train) - 1) * np.arange(1, H + 1)
growth = np.mean(np.log(train[m:]) - np.log(train[:-m]))                         # средний годовой рост в логарифмах
seasonal_growth = np.tile(train[-m:], H // m) * np.exp(growth * np.repeat(np.arange(1, H // m + 1), m))

def features(series, t):                                 # признаки момента t только из прошлого
    s = np.log(series)
    return [s[t - 1], s[t - 12], s[t - 1] - s[t - 13], s[t - 12:t].mean(), t % 12, t]
def recursive_forecast(make_model):                      # одна модель на шаг вперёд, прогнозы подставляются как лаги
    hist = list(train)
    model = make_model().fit([features(np.array(hist), t) for t in range(13, len(hist))], np.log(hist[13:]))
    for t in range(len(train), len(train) + H):
        hist.append(float(np.exp(model.predict([features(np.array(hist), t)])[0])))
    return np.array(hist[-H:])
ridge = recursive_forecast(lambda: Ridge(1e-3))
boost = recursive_forecast(lambda: HistGradientBoostingRegressor(max_iter=300, learning_rate=0.05, min_samples_leaf=5))
for name, f in [("наивный", naive), ("сезонный наивный", seasonal), ("дрейф", drift), ("сезонный наивный × рост", seasonal_growth),
                ("Ridge на лагах (log)", ridge), ("бустинг на лагах (log)", boost)]:
    print(f"{name:25s} MAE {mae(f, test):6.1f}   MASE {mase(f):.2f}")
print(f"максимум train {train.max():.0f}, максимум прогноза бустинга {boost.max():.0f}, максимум теста {test.max():.0f}  ← деревья не экстраполируют")
```

Результат запуска:

```text

сезонный наивный          MAE   71.2   MASE 2.49
дрейф                     MAE   91.6   MASE 3.21
сезонный наивный × рост   MAE   13.3   MASE 0.46
Ridge на лагах (log)      MAE   13.2   MASE 0.46
бустинг на лагах (log)    MAE   49.7   MASE 1.74
максимум train 505, максимум прогноза бустинга 491, максимум теста 622  ← деревья не экстраполируют
```

```python
# Утечка при валидации: случайный KFold против честного TimeSeriesSplit для той же модели
X_all = np.array([features(y, t) for t in range(13, len(y))]); y_all = np.log(y[13:])
model = HistGradientBoostingRegressor(max_iter=300, learning_rate=0.05, min_samples_leaf=5)
for cv in (KFold(5, shuffle=True, random_state=0), TimeSeriesSplit(5)):
    err = -cross_val_score(model, X_all, y_all, cv=cv, scoring="neg_mean_absolute_error").mean()
    print(f"{type(cv).__name__:16s} MAE в логарифмах = {err:.3f}")
```
