## 1. Дерево как кусочно-постоянная функция

Дерево с листьями $R_1, \dots, R_J$ (области — непересекающиеся «параллелепипеды», покрывающие пространство) задаёт

$$
a(x) = \sum_{j=1}^{J} c_j\,[x \in R_j] .
$$

Идеальная задача — минимизировать RSS по всем разбиениям на области и всем значениям $c_j$:

$$
\sum_{j=1}^{J}\sum_{x_i \in R_j}(y_i - c_j)^2 \to \min_{\lbrace R_j\rbrace,\lbrace c_j\rbrace} .
$$

Построение оптимального бинарного дерева — **NP-полная** задача (Hyafil & Rivest, 1976), поэтому строят
**жадно сверху вниз** (top-down greedy): на каждом шаге лучший сплит текущей вершины.

**Значения в листьях при фиксированных областях** — оптимальная константа функции потерь на объектах листа
(тема [01](../01_intro_regression_metrics/deep.md#2-оптимальная-константа-для-каждой-функции-потерь)):
MSE → среднее, MAE → медиана, accuracy → самый частый класс, log loss → доли классов.

## 2. Критерий расщепления из функции потерь

Определим **неоднородность (impurity)** вершины $R$ как наименьшую среднюю потерю константного прогноза:

$$
H(R) = \min_{c}\;\frac{1}{|R|}\sum_{(x_i, y_i)\in R} L(y_i, c),
$$

а качество сплита $R \to (R_\ell, R_r)$ — как её уменьшение:

$$
Q(R, j, t) = H(R) - \frac{|R_\ell|}{|R|}H(R_\ell) - \frac{|R_r|}{|R|}H(R_r) \;\to\; \max_{j, t} .
$$

Взвешенная сумма — это ровно суммарная потеря дерева после сплита, делённая на $|R|$, так что максимизация $Q$
= жадная минимизация эмпирического риска. Посмотрим, какие $H$ получаются из разных $L$.

### 2.1. MSE → дисперсия

$c^* = \bar y_R$, $H(R) = \frac{1}{|R|}\sum_{i \in R}(y_i - \bar y_R)^2$ — **выборочная дисперсия** таргета в вершине.

### 2.2. Brier score (MSE на one-hot) → критерий Джини

Классификация с $K$ классами, ответ — one-hot вектор $e_{y_i}$, прогноз — вектор $c \in \mathbb{R}^K$, потеря $\|e_{y_i} - c\|^2$.
Оптимум — среднее one-hot векторов, т.е. вектор долей классов $p = (p_1, \dots, p_K)$. Значение:

$$
H(R) = \frac{1}{|R|}\sum_i\|e_{y_i} - p\|^2 = \sum_{k=1}^{K}\big(p_k(1-p_k)^2 + (1-p_k)p_k^2\big) = \sum_{k=1}^{K}p_k(1 - p_k) = 1 - \sum_k p_k^2 .
$$

Это **индекс Джини**. Интерпретация: вероятность ошибки, если класс случайного объекта угадывать случайно
по распределению $p$. Для двух классов $2p(1-p)$, т.е. удвоенная дисперсия бинарной величины — поэтому
слайд «для бинарной случайной величины дисперсия ~ Джини».

### 2.3. Log loss → энтропия

Потеря $-\ln c_{y_i}$, прогноз — распределение $c$ на классах. $\frac{1}{|R|}\sum_i -\ln c_{y_i} = -\sum_k p_k\ln c_k$ — это
кросс-энтропия $H(p, c) = H(p) + \mathrm{KL}(p\|c)$, минимум при $c = p$:

$$
H(R) = -\sum_{k=1}^{K} p_k \ln p_k .
$$

Это **энтропия**. Уменьшение энтропии при сплите — **information gain**.

### 2.4. 0–1 loss → ошибка классификации

$H(R) = 1 - \max_k p_k$ (misclassification criterion).

| Потеря в листе | Оптимальный прогноз | Impurity $H(R)$ |
|---|---|---|
| MSE | $\bar y$ | дисперсия |
| MAE | медиана | среднее абсолютное отклонение от медианы |
| Brier (MSE на one-hot) | доли классов $p$ | Джини $1 - \sum p_k^2$ |
| Log loss | доли классов $p$ | энтропия $-\sum p_k\ln p_k$ |
| 0–1 | мода | $1 - \max_k p_k$ |

## 3. Information gain = взаимная информация

Энтропия случайной величины $Y$: $H(Y) = -\sum_y P(y)\log P(y)$ — мера неопределённости
(в битах при $\log_2$: честная монета — 1 бит; основание логарифма меняет только единицы измерения).
Условная энтропия: $H(Y \mid X) = \sum_x P(x)H(Y \mid X = x)$. Тогда

$$
\text{IG} = H(Y) - H(Y \mid X) = I(X; Y) \ge 0 .
$$

Для сплита $X = [x^j > t]$ с $P(X = \text{лево}) = |R_\ell|/|R|$ это в точности $Q(R, j, t)$ с энтропийным $H$:
«насколько знание ответа на вопрос $x^j > t$ уменьшило неопределённость класса». Пример со слайда:
$X$ = {дождь, сухо}, $Y$ = {облачно, ясно} — знание о дожде уменьшает неопределённость об облачности.

$\text{IG} \ge 0$ (вогнутость энтропии / неравенство Йенсена), равенство — когда распределение классов в
обоих потомках совпадает с родительским.

## 4. Почему ошибка классификации — плохой критерий

Узел: 400 объектов класса A и 400 класса B. Два варианта сплита:
- **S1**: (300 A, 100 B) и (100 A, 300 B);
- **S2**: (200 A, 400 B) и (200 A, 0 B).

| Критерий | Родитель | S1 (взвешенно) | S2 (взвешенно) |
|---|---|---|---|
| Ошибка классификации | 0.5 | $\frac12\cdot0.25 + \frac12\cdot0.25 = 0.25$ | $\frac34\cdot\frac13 + \frac14\cdot 0 = 0.25$ |
| Джини | 0.5 | $2\cdot\frac34\cdot\frac14 = 0.375$ | $\frac34\cdot\frac49 + 0 \approx 0.333$ |
| Энтропия (биты) | 1.0 | $\approx 0.811$ | $\frac34\cdot 0.918 \approx 0.689$ |

Ошибка классификации не различает сплиты, а Джини и энтропия предпочитают **S2**, создающий
**чистый** лист — это полезно для дальнейшего роста дерева. Причина: ошибка классификации
**кусочно-линейна** по $p$, а Джини и энтропия **строго вогнуты**; для строго вогнутой $H$ любое
«перераспределение» классов между потомками даёт строго положительный выигрыш.

## 5. Быстрый поиск лучшего порога

Для признака $j$ сортируем объекты вершины по $x^j$ ($O(n\log n)$). Пороги имеет смысл ставить только между
соседними различными значениями («средние точки»); для классификации — достаточно на **границах
смены класса**. Для MSE используем префиксные суммы: если слева $n_\ell$ объектов с суммами $S_\ell = \sum y_i$,
$S^{(2)}_\ell = \sum y_i^2$, то

$$
n_\ell H(R_\ell) = \sum_{i \in R_\ell}(y_i - \bar y_\ell)^2 = S^{(2)}_\ell - \frac{S_\ell^2}{n_\ell},
$$

и при сдвиге порога на один объект суммы обновляются за $O(1)$. Итого лучший сплит вершины —
$O(d\,n\log n)$, а всё дерево глубины $D$ — $O(D\,d\,\ell\log\ell)$ (на каждом уровне суммарно $\ell$ объектов).
Гистограммные методы (LightGBM, тема [09](../09_gradient_boosting/README.md)) заменяют сортировку
разбиением на $\le 255$ бинов: $O(d\,\ell)$ на уровень.

«Подвох» со слайда: признаки, константные в вершине, сплита не дают; а при множестве уникальных значений
дерево может найти «случайно хороший» порог (переобучение на шумных признаках с высокой кардинальностью).

## 6. Категориальные признаки: теорема о сортировке по среднему

У категориального признака с $q$ значениями $2^{q-1} - 1$ способов разбить категории на две группы. Перебор
экспоненциален. **Теорема (Breiman et al., 1984; Fisher, 1958):** для бинарной классификации (критерии Джини
и энтропия) и для регрессии с MSE оптимальное разбиение находится среди $q - 1$ разбиений, полученных так:
упорядочить категории по доле класса 1 (по среднему таргета) и резать как числовой признак.

*Идея доказательства для MSE.* Разбиение на группы $A$, $B$ с суммами весов $n_A, n_B$ и средними
$\bar y_A, \bar y_B$ уменьшает RSS на $\frac{n_A n_B}{n_A + n_B}(\bar y_A - \bar y_B)^2$ — выигрыш тем больше, чем сильнее
отличаются средние групп. Если в оптимальном разбиении нашлись категории $u \in A$, $v \in B$ с
$\bar y_u > \bar y_v$, при $\bar y_A < \bar y_B$, то обмен $u$ и $v$ (или перенос одной из них) не уменьшает выигрыш;
повторяя обмены, приходим к разбиению, «монотонному» по средним категорий. ∎

Это и есть приём со слайда: «упорядочиваем по вероятности класса 1, каждая категория → номер по порядку».
Опасность — **переобучение на мелких категориях** (среднее по 2–3 объектам шумное). Для многоклассового
случая теорема не работает (используют эвристики; LightGBM и CatBoost — свои схемы).

## 7. Важность признаков (MDI)

**Mean Decrease in Impurity**: важность признака $j$ — суммарное уменьшение неоднородности по всем
вершинам $t$, где разбиение шло по $j$, с весом доли объектов в вершине:

$$
\text{Imp}(j) = \sum_{t:\,j(t) = j}\frac{N_t}{N}\Big(H(t) - \frac{N_{t_\ell}}{N_t}H(t_\ell) - \frac{N_{t_r}}{N_t}H(t_r)\Big),
$$

затем нормируется на сумму по всем признакам (так в sklearn, `feature_importances_`).

Недостатки MDI:
- считается по **обучающей** выборке → переоценивает признаки, на которых дерево переобучилось;
- **смещена в пользу признаков с большим числом уникальных значений** (больше порогов — больше шансов
  найти случайно хороший);
- при коррелированных признаках важность делится между ними произвольно.

Альтернатива — **permutation importance** на валидации: насколько падает качество, если перемешать значения
признака. Ещё — SHAP-значения (TreeSHAP).

---

## 8. Пропуски: суррогатные расщепления

Для сплита $s^* = [x^j \le t]$ ищем по другим признакам сплиты $s$, которые **лучше всего имитируют** $s^*$ на
объектах, где $x^j$ известен (максимизируем долю совпадений направлений «влево/вправо»). Объект с
пропуском в $x^j$ направляется по первому суррогату, для которого его значение известно. Пример со слайда:
«A > 2.5» на известных объектах совпадает с «B > 6», и B определён у объектов, где A пропущен.

Другие стратегии: отдельная категория «пропуск»; отправлять пропуски в ту ветвь, где выигрыш больше
(XGBoost, LightGBM — «default direction»); C4.5 — проносить объект в обе ветви с весами пропорционально
размерам потомков.

## 9. Классические алгоритмы и их критерии

- **ID3** (Quinlan, 1986): information gain, только категориальные признаки, небинарные сплиты, без подрезки.
- **C4.5** (Quinlan, 1993): **gain ratio** $= \frac{\text{IG}}{\text{SplitInfo}}$, $\text{SplitInfo} = -\sum_v \frac{|R_v|}{|R|}\log\frac{|R_v|}{|R|}$ —
  штраф за сплиты на много ветвей (IG смещён в их пользу: сплит по ID объекта даёт максимальный IG);
  числовые признаки, пропуски, error-based pruning.
- **CART** (Breiman, Friedman, Olshen, Stone, 1984): бинарные деревья, Джини (или twoing) для классификации,
  MSE для регрессии, cost-complexity pruning, суррогатные сплиты. Именно CART реализован в sklearn.
- **CHAID** (Kass, 1980): статистический тест χ² для выбора сплита, небинарные ветвления.
