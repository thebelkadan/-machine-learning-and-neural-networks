# 07. Решающие деревья

[Шпаргалка (ноутбук)](../../cheatsheet.ipynb) · [Оглавление курса](../../README.md)

**Суть.** Дерево задаёт кусочно-постоянную функцию: последовательность вопросов вида $x^j\le t$ ведёт в лист
с ответом. Строится **жадно сверху вниз**: в каждой вершине выбирается сплит, сильнее всего уменьшающий
неоднородность (Джини / энтропия / дисперсия). Без ограничений переобучается; на практике — pre-/post-pruning
и, главное, **ансамбли деревьев**.

| Термин | Определение |
|---|---|
| Внутренняя вершина / лист | предикат $[x^j\le t]$ / ответ (класс, вероятности, число) |
| CART | бинарные деревья для классификации и регрессии (реализация sklearn) |
| Impurity $H(R)$ | неоднородность вершины: Джини, энтропия, дисперсия |
| Information gain | уменьшение энтропии при сплите = взаимная информация |
| Pre-pruning | `max_depth`, `min_samples_leaf`, `min_samples_split`, `max_leaf_nodes`, `min_impurity_decrease` |
| Post-pruning | стрижка выращенного дерева: $R_\alpha(T)=R(T)+\alpha\lvert T\rvert$ (`ccp_alpha`) |
| MDI | важность признака = суммарное уменьшение impurity по его сплитам |
| Суррогатный сплит | замена сплита для объектов с пропуском в признаке |

$$
Q(R,j,t)=H(R)-\frac{|R_\ell|}{|R|}H(R_\ell)-\frac{|R_r|}{|R|}H(R_r)\to\max_{j,t},\qquad
\text{Gini}=1-\sum_k p_k^2,\quad \text{Entropy}=-\sum_k p_k\log p_k,\quad H_{\text{reg}}=\frac{1}{|R|}\sum(y_i-\bar y)^2
$$

## Конспект

Разделы раскрываются по клику.

<details>
<summary><b>1. Что такое решающее дерево</b></summary>

```
            доход > 30 000 ?
              /        \
           нет          да
            | |
      не выдавать   просрочек > 1 ?
                      /       \
                    да         нет
                    | |
              не выдавать   выдать кредит
```

- **Внутренняя вершина** (internal node) — ветвление по **предикату** (признак + порог);
- **дуга** — значение предиката (да / нет);
- **лист** (leaf, terminal node) — ответ: метка класса, вероятности классов или число.

**CART** (Classification And Regression Trees) — **бинарные** деревья: у каждой внутренней вершины два потомка.
Дальше рассматриваем их.

**Предикаты:**
- вещественный признак: $[x^j \le t]$ — самый частый вариант;
- категориальный: $[x^j \in S]$, $S$ — подмножество категорий;
- экзотика: «косые» деревья (oblique / BSP trees) с $[\langle w, x\rangle \le t]$, «сферические» (sphere trees) с $[\lVert x - c\rVert \le r]$.

Дерево разбивает пространство признаков на **области** (регионы) — прямоугольные «коробки» со сторонами,
параллельными осям, и в каждой предсказывает константу. То есть дерево — **кусочно-постоянная функция**.
В соседних регионах ответы могут совпадать. Дерево глубины 1 называют **решающим пнём** (decision stump).

</details>

<details>
<summary><b>2. Как строится дерево</b></summary>

Идеальная задача — разбить пространство на области так, чтобы минимизировать RSS — **NP-полная**. Поэтому
строят **жадно сверху вниз** (top-down greedy), рекурсивно:

```
build(R):
    если выполнен критерий останова → лист с оптимальной константой
    иначе найти (j, t) = argmax Q(R, j, t)                  # лучший признак и порог
          R_l = {x ∈ R: x^j ≤ t},  R_r = {x ∈ R: x^j > t}
          build(R_l); build(R_r)
```

**2.1. Ответ в листе**

Если область фиксирована, оптимальное значение находится просто (минимизация эмпирического риска):
- **регрессия (MSE)** — среднее таргета в листе;
- **классификация (accuracy)** — самый частый класс; для вероятностей — доли классов.

**2.2. Критерий расщепления**

Вводим меру **неоднородности (impurity)** $H(R)$ — насколько в области «почти все объекты одного класса».
Сплит выбираем, максимизируя уменьшение неоднородности:

$$
Q(R, j, t) = H(R) - \frac{|R_\ell|}{|R|}H(R_\ell) - \frac{|R_r|}{|R|}H(R_r) \to \max_{j, t} .
$$

Для классификации ($p_k$ — доля класса $k$ в области):

| Критерий | $H(R)$ | Два класса ($p$ — доля класса 1) |
|---|---|---|
| **Джини** (Gini) | $\sum_k p_k(1 - p_k) = 1 - \sum_k p_k^2$ | $2p(1-p)$ |
| **Энтропийный** (Entropy) | $-\sum_k p_k\log p_k$ | $-p\log p - (1-p)\log(1-p)$ |
| Ошибка классификации (misclassification) | $1 - \max_k p_k$ | $\min(p, 1-p)$ |

- Все равны 0 **только** если в области объекты одного класса, максимальны при равных долях.
- Джини и энтропия ведут себя почти одинаково; ошибку классификации как критерий роста не используют —
  она не различает многие сплиты (пример — см. раздел «4. Почему ошибка классификации — плохой критерий»).
- Уменьшение энтропии = **information gain** = взаимная информация признака-сплита и класса (теория информации — см. раздел «3. Information gain = взаимная информация»).
- Есть и экзотические критерии: AUC-ROC, Twoing (для двух классов ~ Джини).

Для **регрессии** неоднородность — **дисперсия** (MSE относительно среднего):

$$
H(R) = \frac{1}{|R|}\sum_{(x_i, y_i) \in R}(y_i - \bar y_R)^2 .
$$

Для бинарной величины дисперсия $p(1-p)$ — это Джини с точностью до множителя. Общий принцип:
$H(R) = \min_c \frac{1}{|R|}\sum L(y_i, c)$ — **Джини и энтропия выводятся из Brier score и log loss**
(вывод — см. раздел «2. Критерий расщепления из функции потерь»).

**2.3. Тонкости выбора порога**

- Значения признака сначала **сортируют**; пороги достаточно ставить в «средних точках» между соседними
  значениями (для классификации — только на границах смены класса).
- Константные признаки не дают сплитов.
- С префиксными суммами лучший порог по признаку ищется за один проход (как — см. раздел «5. Быстрый поиск лучшего порога»).

**2.4. Критерии останова**

- ограничение глубины / числа листьев (`max_depth`, `max_leaf_nodes`);
- минимум объектов в листе / для деления (`min_samples_leaf`, `min_samples_split`);
- «естественное» ограничение — все (почти все) объекты листа одного класса;
- слишком маленькое изменение impurity (`min_impurity_decrease`).

</details>

<details>
<summary><b>3. Переобучение деревьев</b></summary>

Глубокие деревья склонны к переобучению — «затачиваются» на отдельные объекты (неограниченное дерево
способно выучить любую непротиворечивую выборку). Что делают:
- **останавливают рост рано** (pre-pruning, критерии останова выше); точку останова можно выбрать на отложенной выборке;
- **подрезают** выращенное дерево (post-pruning): cost-complexity pruning $R_\alpha(T) = R(T) + \alpha|T|$,
  раньше — удаление листьев по отложенной выборке, MDL. Сейчас используется редко — когда задачу надо решить
  **одним** деревом;
- используют деревья **в ансамблях** (случайный лес, бустинг) — основной способ на практике.

Подробно pre/post-pruning — в теме [06](../06_bias_variance/README.md).

> Неограниченное дерево не **всегда** переобучается. На датасете Mushrooms (семинар) полное дерево
> глубины 5–7 с 11–14 листьями дало **100%** точности на тесте: данные почти идеально делятся по
> нескольким признакам (главный — запах `odor`). Но это редкость.

</details>

<details>
<summary><b>4. Важность признаков</b></summary>

Идея: чем сильнее признак уменьшает неоднородность, тем он важнее. **Важность** = сумма уменьшений
неоднородности по всем сплитам с этим признаком (в sklearn — с весом доли объектов в вершине, затем нормировка):

```python
model.feature_importances_       # MDI (mean decrease in impurity)
```

Минусы MDI: считается на обучении, завышает признаки с большим числом уникальных значений
(подробнее — см. раздел «7. Важность признаков (MDI)»). Другие способы: коэффициенты моделей, OOB-оценки,
permutation importance, корреляции.

```python
from sklearn.inspection import permutation_importance
r = permutation_importance(model, X_val, y_val, n_repeats=10, random_state=0)
```

<details>
<summary><b>5. Пропуски и категориальные признаки</b></summary>

**Пропуски (missing values):** удалить; заменить (средним); отдельная категория; пронести объект в обе
ветви; выбрать наиболее подходящую ветвь; **суррогатные расщепления** — для объектов с пропуском в
признаке сплита подбирается другой сплит, имитирующий исходный (как — см. раздел «8. Пропуски: суррогатные расщепления»).
В sklearn ≥ 1.3 деревья поддерживают `NaN` нативно (пропуски уходят в ту ветвь, где выигрыш больше).

**Категориальные признаки:** формально нужно перебрать все подмножества категорий ($2^{q-1} - 1$).
Реально (бинарная классификация): **упорядочиваем категории по доле класса 1**, заменяем категорию номером
и ищем сплит как для числового признака — это даёт оптимум (теорема — см. раздел «6. Категориальные признаки: теорема о сортировке по среднему»).
Опасность — переобучение на мелких категориях; признаки с огромным числом категорий «перетягивают» сплиты на себя.
В sklearn категории обычно кодируют one-hot (`pd.get_dummies`): на Mushrooms 21 признак → 115.

</details>

**Своё дерево регрессии (по мотивам ДЗ)**

```python
import numpy as np

class MyDecisionTreeRegressor:
    def __init__(self, max_depth=5, min_samples_leaf=1):
        self.max_depth, self.min_samples_leaf = max_depth, min_samples_leaf

    def _best_split(self, X, y):
        best = (None, None, np.sum((y - y.mean()) ** 2))       # (признак, порог, RSS)
        n = len(y)
        for j in range(X.shape[1]):
            order = np.argsort(X[:, j]); xs, ys = X[order, j], y[order]
            csum, csum2 = np.cumsum(ys), np.cumsum(ys ** 2)      # префиксные суммы
            for i in range(self.min_samples_leaf, n - self.min_samples_leaf + 1):
                if xs[i - 1] == xs[i]:
                    continue                                       # порог только между разными значениями
                nl, nr = i, n - i
                rss_l = csum2[i - 1] - csum[i - 1] ** 2 / nl
                rss_r = (csum2[-1] - csum2[i - 1]) - (csum[-1] - csum[i - 1]) ** 2 / nr
                if rss_l + rss_r < best[2]:
                    best = (j, (xs[i - 1] + xs[i]) / 2, rss_l + rss_r)
        return best[:2]

    def _fit_node(self, X, y, depth):
        if depth >= self.max_depth or len(y) < 2 * self.min_samples_leaf or np.all(y == y[0]):
            return {"value": y.mean()}
        j, t = self._best_split(X, y)
        if j is None:
            return {"value": y.mean()}
        m = X[:, j] <= t
        return {"feat": j, "thr": t,
                "left": self._fit_node(X[m], y[m], depth + 1),
                "right": self._fit_node(X[~m], y[~m], depth + 1)}

    def fit(self, X, y):
        self.root = self._fit_node(np.asarray(X, float), np.asarray(y, float), 0)
        return self

    def _predict_one(self, x, node):
        while "value" not in node:
            node = node["left"] if x[node["feat"]] <= node["thr"] else node["right"]
        return node["value"]

    def predict(self, X):
        return np.array([self._predict_one(x, self.root) for x in np.asarray(X, float)])
```

```python
def entropy(probs):
    return -sum(p * np.log2(p) for p in probs if p > 0)     # 0·log 0 = 0

def gini(probs):
    return 1 - sum(p ** 2 for p in probs)
```

**Математика и выводы**

<details>
<summary><b>1. Дерево как кусочно-постоянная функция</b></summary>

Дерево с листьями $R_1, \dots, R_J$ (области — непересекающиеся «параллелепипеды», покрывающие пространство) задаёт

$$
a(x) = \sum_{j=1}^{J} c_j\,[x \in R_j] .
$$

Идеальная задача — минимизировать RSS по всем разбиениям на области и всем значениям $c_j$:

$$
\sum_{j=1}^{J}\sum_{x_i \in R_j}(y_i - c_j)^2 \to \min_{\lbrace R_j\rbrace,\lbrace c_j\rbrace} .
$$

Построение оптимального бинарного дерева — **NP-полная** задача (Hyafil & Rivest, 1976), поэтому строят
**жадно сверху вниз** (top-down greedy): на каждом шаге лучший сплит текущей вершины.

**Значения в листьях при фиксированных областях** — оптимальная константа функции потерь на объектах листа
(тема [01](../01_intro_regression_metrics/README.md)):
MSE → среднее, MAE → медиана, accuracy → самый частый класс, log loss → доли классов.

</details>

<details>
<summary><b>2. Критерий расщепления из функции потерь</b></summary>

Определим **неоднородность (impurity)** вершины $R$ как наименьшую среднюю потерю константного прогноза:

$$
H(R) = \min_{c}\;\frac{1}{|R|}\sum_{(x_i, y_i)\in R} L(y_i, c),
$$

а качество сплита $R \to (R_\ell, R_r)$ — как её уменьшение:

$$
Q(R, j, t) = H(R) - \frac{|R_\ell|}{|R|}H(R_\ell) - \frac{|R_r|}{|R|}H(R_r) \;\to\; \max_{j, t} .
$$

Взвешенная сумма — это ровно суммарная потеря дерева после сплита, делённая на $|R|$, так что максимизация $Q$
= жадная минимизация эмпирического риска. Посмотрим, какие $H$ получаются из разных $L$.

**2.1. MSE → дисперсия**

$c^* = \bar y_R$, $H(R) = \frac{1}{|R|}\sum_{i \in R}(y_i - \bar y_R)^2$ — **выборочная дисперсия** таргета в вершине.

**2.2. Brier score (MSE на one-hot) → критерий Джини**

Классификация с $K$ классами, ответ — one-hot вектор $e_{y_i}$, прогноз — вектор $c \in \mathbb{R}^K$, потеря $\|e_{y_i} - c\|^2$.
Оптимум — среднее one-hot векторов, т.е. вектор долей классов $p = (p_1, \dots, p_K)$. Значение:

$$
H(R) = \frac{1}{|R|}\sum_i\|e_{y_i} - p\|^2 = \sum_{k=1}^{K}\big(p_k(1-p_k)^2 + (1-p_k)p_k^2\big) = \sum_{k=1}^{K}p_k(1 - p_k) = 1 - \sum_k p_k^2 .
$$

Это **индекс Джини**. Интерпретация: вероятность ошибки, если класс случайного объекта угадывать случайно
по распределению $p$. Для двух классов $2p(1-p)$, т.е. удвоенная дисперсия бинарной величины — поэтому
слайд «для бинарной случайной величины дисперсия ~ Джини».

**2.3. Log loss → энтропия**

Потеря $-\ln c_{y_i}$, прогноз — распределение $c$ на классах. $\frac{1}{|R|}\sum_i -\ln c_{y_i} = -\sum_k p_k\ln c_k$ — это
кросс-энтропия $H(p, c) = H(p) + \mathrm{KL}(p\|c)$, минимум при $c = p$:

$$
H(R) = -\sum_{k=1}^{K} p_k \ln p_k .
$$

Это **энтропия**. Уменьшение энтропии при сплите — **information gain**.

**2.4. 0–1 loss → ошибка классификации**

$H(R) = 1 - \max_k p_k$ (misclassification criterion).

| Потеря в листе | Оптимальный прогноз | Impurity $H(R)$ |
|---|---|---|
| MSE | $\bar y$ | дисперсия |
| MAE | медиана | среднее абсолютное отклонение от медианы |
| Brier (MSE на one-hot) | доли классов $p$ | Джини $1 - \sum p_k^2$ |
| Log loss | доли классов $p$ | энтропия $-\sum p_k\ln p_k$ |
| 0–1 | мода | $1 - \max_k p_k$ |

</details>

<details>
<summary><b>3. Information gain = взаимная информация</b></summary>

Энтропия случайной величины $Y$: $H(Y) = -\sum_y P(y)\log P(y)$ — мера неопределённости
(в битах при $\log_2$: честная монета — 1 бит; основание логарифма меняет только единицы измерения).
Условная энтропия: $H(Y \mid X) = \sum_x P(x)H(Y \mid X = x)$. Тогда

$$
\text{IG} = H(Y) - H(Y \mid X) = I(X; Y) \ge 0 .
$$

Для сплита $X = [x^j > t]$ с $P(X = \text{лево}) = |R_\ell|/|R|$ это в точности $Q(R, j, t)$ с энтропийным $H$:
«насколько знание ответа на вопрос $x^j > t$ уменьшило неопределённость класса». Пример со слайда:
$X$ = {дождь, сухо}, $Y$ = {облачно, ясно} — знание о дожде уменьшает неопределённость об облачности.

$\text{IG} \ge 0$ (вогнутость энтропии / неравенство Йенсена), равенство — когда распределение классов в
обоих потомках совпадает с родительским.

</details>

<details>
<summary><b>4. Почему ошибка классификации — плохой критерий</b></summary>

Узел: 400 объектов класса A и 400 класса B. Два варианта сплита:
- **S1**: (300 A, 100 B) и (100 A, 300 B);
- **S2**: (200 A, 400 B) и (200 A, 0 B).

| Критерий | Родитель | S1 (взвешенно) | S2 (взвешенно) |
|---|---|---|---|
| Ошибка классификации | 0.5 | $\frac12\cdot0.25 + \frac12\cdot0.25 = 0.25$ | $\frac34\cdot\frac13 + \frac14\cdot 0 = 0.25$ |
| Джини | 0.5 | $2\cdot\frac34\cdot\frac14 = 0.375$ | $\frac34\cdot\frac49 + 0 \approx 0.333$ |
| Энтропия (биты) | 1.0 | $\approx 0.811$ | $\frac34\cdot 0.918 \approx 0.689$ |

Ошибка классификации не различает сплиты, а Джини и энтропия предпочитают **S2**, создающий
**чистый** лист — это полезно для дальнейшего роста дерева. Причина: ошибка классификации
**кусочно-линейна** по $p$, а Джини и энтропия **строго вогнуты**; для строго вогнутой $H$ любое
«перераспределение» классов между потомками даёт строго положительный выигрыш.

</details>

<details>
<summary><b>5. Быстрый поиск лучшего порога</b></summary>

Для признака $j$ сортируем объекты вершины по $x^j$ ($O(n\log n)$). Пороги имеет смысл ставить только между
соседними различными значениями («средние точки»); для классификации — достаточно на **границах
смены класса**. Для MSE используем префиксные суммы: если слева $n_\ell$ объектов с суммами $S_\ell = \sum y_i$,
$S^{(2)}_\ell = \sum y_i^2$, то

$$
n_\ell H(R_\ell) = \sum_{i \in R_\ell}(y_i - \bar y_\ell)^2 = S^{(2)}_\ell - \frac{S_\ell^2}{n_\ell},
$$

и при сдвиге порога на один объект суммы обновляются за $O(1)$. Итого лучший сплит вершины —
$O(d\,n\log n)$, а всё дерево глубины $D$ — $O(D\,d\,\ell\log\ell)$ (на каждом уровне суммарно $\ell$ объектов).
Гистограммные методы (LightGBM, тема [09](../09_gradient_boosting/README.md)) заменяют сортировку
разбиением на $\le 255$ бинов: $O(d\,\ell)$ на уровень.

«Подвох» со слайда: признаки, константные в вершине, сплита не дают; а при множестве уникальных значений
дерево может найти «случайно хороший» порог (переобучение на шумных признаках с высокой кардинальностью).

</details>

<details>
<summary><b>6. Категориальные признаки: теорема о сортировке по среднему</b></summary>

У категориального признака с $q$ значениями $2^{q-1} - 1$ способов разбить категории на две группы. Перебор
экспоненциален. **Теорема (Breiman et al., 1984; Fisher, 1958):** для бинарной классификации (критерии Джини
и энтропия) и для регрессии с MSE оптимальное разбиение находится среди $q - 1$ разбиений, полученных так:
упорядочить категории по доле класса 1 (по среднему таргета) и резать как числовой признак.

*Идея доказательства для MSE.* Разбиение на группы $A$, $B$ с суммами весов $n_A, n_B$ и средними
$\bar y_A, \bar y_B$ уменьшает RSS на $\frac{n_A n_B}{n_A + n_B}(\bar y_A - \bar y_B)^2$ — выигрыш тем больше, чем сильнее
отличаются средние групп. Если в оптимальном разбиении нашлись категории $u \in A$, $v \in B$ с
$\bar y_u > \bar y_v$, при $\bar y_A < \bar y_B$, то обмен $u$ и $v$ (или перенос одной из них) не уменьшает выигрыш;
повторяя обмены, приходим к разбиению, «монотонному» по средним категорий. ∎

Это и есть приём со слайда: «упорядочиваем по вероятности класса 1, каждая категория → номер по порядку».
Опасность — **переобучение на мелких категориях** (среднее по 2–3 объектам шумное). Для многоклассового
случая теорема не работает (используют эвристики; LightGBM и CatBoost — свои схемы).

</details>

<details>
<summary><b>7. Важность признаков (MDI)</b></summary>

**Mean Decrease in Impurity**: важность признака $j$ — суммарное уменьшение неоднородности по всем
вершинам $t$, где разбиение шло по $j$, с весом доли объектов в вершине:

$$
\text{Imp}(j) = \sum_{t:\,j(t) = j}\frac{N_t}{N}\Big(H(t) - \frac{N_{t_\ell}}{N_t}H(t_\ell) - \frac{N_{t_r}}{N_t}H(t_r)\Big),
$$

затем нормируется на сумму по всем признакам (так в sklearn, `feature_importances_`).

Недостатки MDI:
- считается по **обучающей** выборке → переоценивает признаки, на которых дерево переобучилось;
- **смещена в пользу признаков с большим числом уникальных значений** (больше порогов — больше шансов
  найти случайно хороший);
- при коррелированных признаках важность делится между ними произвольно.

Альтернатива — **permutation importance** на валидации: насколько падает качество, если перемешать значения
признака. Ещё — SHAP-значения (TreeSHAP).

</details>

<details>
<summary><b>8. Пропуски: суррогатные расщепления</b></summary>

Для сплита $s^* = [x^j \le t]$ ищем по другим признакам сплиты $s$, которые **лучше всего имитируют** $s^*$ на
объектах, где $x^j$ известен (максимизируем долю совпадений направлений «влево/вправо»). Объект с
пропуском в $x^j$ направляется по первому суррогату, для которого его значение известно. Пример со слайда:
«A > 2.5» на известных объектах совпадает с «B > 6», и B определён у объектов, где A пропущен.

Другие стратегии: отдельная категория «пропуск»; отправлять пропуски в ту ветвь, где выигрыш больше
(XGBoost, LightGBM — «default direction»); C4.5 — проносить объект в обе ветви с весами пропорционально
размерам потомков.

</details>

<details>
<summary><b>9. Классические алгоритмы и их критерии</b></summary>

- **ID3** (Quinlan, 1986): information gain, только категориальные признаки, небинарные сплиты, без подрезки.
- **C4.5** (Quinlan, 1993): **gain ratio** $= \frac{\text{IG}}{\text{SplitInfo}}$, $\text{SplitInfo} = -\sum_v \frac{|R_v|}{|R|}\log\frac{|R_v|}{|R|}$ —
  штраф за сплиты на много ветвей (IG смещён в их пользу: сплит по ID объекта даёт максимальный IG);
  числовые признаки, пропуски, error-based pruning.
- **CART** (Breiman, Friedman, Olshen, Stone, 1984): бинарные деревья, Джини (или twoing) для классификации,
  MSE для регрессии, cost-complexity pruning, суррогатные сплиты. Именно CART реализован в sklearn.
- **CHAID** (Kass, 1980): статистический тест χ² для выбора сплита, небинарные ветвления.

</details>

<summary><b>Дополнительно: детали</b></summary>

- $H(R)=\min_c\frac1{|R|}\sum L(y_i,c)$: MSE → дисперсия, Brier → **Джини**, log loss → **энтропия**.
- Лучший порог по признаку — сортировка + префиксные суммы: $O(n\log n)$.
- Категориальный признак (бинарная классификация / MSE): сортировка категорий по среднему таргета даёт оптимальное разбиение из $2^{q-1}-1$.
- C4.5 использует gain ratio = IG / SplitInfo — штраф за сплиты на много ветвей.

```python
import numpy as np

X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=0, stratify=y)
```

```python
# Джини и энтропия: почему не ошибка классификации. Узел 400/400, два сплита
def H(counts, kind):
    p = np.array(counts) / sum(counts)
    return {"gini": 1 - (p**2).sum(), "entropy": -(p[p > 0] * np.log2(p[p > 0])).sum(), "error": 1 - p.max()}[kind]
def split_score(children, kind):
    n = sum(map(sum, children))
    return sum(sum(c) / n * H(c, kind) for c in children)
for kind in ("error", "gini", "entropy"):
    print(f"{kind:8} S1={split_score([[300, 100], [100, 300]], kind):.3f}  S2={split_score([[200, 400], [200, 0]], kind):.3f}")
# ошибка классификации не различает сплиты, Джини и энтропия предпочитают S2 с чистым листом
```
