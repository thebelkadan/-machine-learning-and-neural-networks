## 1. Что такое решающее дерево

```
            доход > 30 000 ?
              /        \
           нет          да
            |            |
      не выдавать   просрочек > 1 ?
                      /       \
                    да         нет
                    |           |
              не выдавать   выдать кредит
```

- **Внутренняя вершина** (internal node) — ветвление по **предикату** (признак + порог);
- **дуга** — значение предиката (да / нет);
- **лист** (leaf, terminal node) — ответ: метка класса, вероятности классов или число.

**CART** (Classification And Regression Trees) — **бинарные** деревья: у каждой внутренней вершины два потомка.
Дальше рассматриваем их.

**Предикаты:**
- вещественный признак: $[x^j \le t]$ — самый частый вариант;
- категориальный: $[x^j \in S]$, $S$ — подмножество категорий;
- экзотика: «косые» деревья (oblique / BSP trees) с $[\langle w, x\rangle \le t]$, «сферические» (sphere trees) с $[\lVert x - c\rVert \le r]$.

Дерево разбивает пространство признаков на **области** (регионы) — прямоугольные «коробки» со сторонами,
параллельными осям, и в каждой предсказывает константу. То есть дерево — **кусочно-постоянная функция**.
В соседних регионах ответы могут совпадать. Дерево глубины 1 называют **решающим пнём** (decision stump).

---

## 2. Как строится дерево

Идеальная задача — разбить пространство на области так, чтобы минимизировать RSS — **NP-полная**. Поэтому
строят **жадно сверху вниз** (top-down greedy), рекурсивно:

```
build(R):
    если выполнен критерий останова → лист с оптимальной константой
    иначе найти (j, t) = argmax Q(R, j, t)                  # лучший признак и порог
          R_l = {x ∈ R: x^j ≤ t},  R_r = {x ∈ R: x^j > t}
          build(R_l); build(R_r)
```

### 2.1. Ответ в листе

Если область фиксирована, оптимальное значение находится просто (минимизация эмпирического риска):
- **регрессия (MSE)** — среднее таргета в листе;
- **классификация (accuracy)** — самый частый класс; для вероятностей — доли классов.

### 2.2. Критерий расщепления

Вводим меру **неоднородности (impurity)** $H(R)$ — насколько в области «почти все объекты одного класса».
Сплит выбираем, максимизируя уменьшение неоднородности:

$$
Q(R, j, t) = H(R) - \frac{|R_\ell|}{|R|}H(R_\ell) - \frac{|R_r|}{|R|}H(R_r) \to \max_{j, t} .
$$

Для классификации ($p_k$ — доля класса $k$ в области):

| Критерий | $H(R)$ | Два класса ($p$ — доля класса 1) |
|---|---|---|
| **Джини** (Gini) | $\sum_k p_k(1 - p_k) = 1 - \sum_k p_k^2$ | $2p(1-p)$ |
| **Энтропийный** (Entropy) | $-\sum_k p_k\log p_k$ | $-p\log p - (1-p)\log(1-p)$ |
| Ошибка классификации (misclassification) | $1 - \max_k p_k$ | $\min(p, 1-p)$ |

- Все равны 0 **только** если в области объекты одного класса, максимальны при равных долях.
- Джини и энтропия ведут себя почти одинаково; ошибку классификации как критерий роста не используют —
  она не различает многие сплиты ([пример](deep.md#4-почему-ошибка-классификации--плохой-критерий)).
- Уменьшение энтропии = **information gain** = взаимная информация признака-сплита и класса ([теория информации](deep.md#3-information-gain--взаимная-информация)).
- Есть и экзотические критерии: AUC-ROC, Twoing (для двух классов ~ Джини).

Для **регрессии** неоднородность — **дисперсия** (MSE относительно среднего):

$$
H(R) = \frac{1}{|R|}\sum_{(x_i, y_i) \in R}(y_i - \bar y_R)^2 .
$$

Для бинарной величины дисперсия $p(1-p)$ — это Джини с точностью до множителя. Общий принцип:
$H(R) = \min_c \frac{1}{|R|}\sum L(y_i, c)$ — **Джини и энтропия выводятся из Brier score и log loss**
([вывод](deep.md#2-критерий-расщепления-из-функции-потерь)).

### 2.3. Тонкости выбора порога

- Значения признака сначала **сортируют**; пороги достаточно ставить в «средних точках» между соседними
  значениями (для классификации — только на границах смены класса).
- Константные признаки не дают сплитов.
- С префиксными суммами лучший порог по признаку ищется за один проход ([как](deep.md#5-быстрый-поиск-лучшего-порога)).

### 2.4. Критерии останова

- ограничение глубины / числа листьев (`max_depth`, `max_leaf_nodes`);
- минимум объектов в листе / для деления (`min_samples_leaf`, `min_samples_split`);
- «естественное» ограничение — все (почти все) объекты листа одного класса;
- слишком маленькое изменение impurity (`min_impurity_decrease`).

## 3. Переобучение деревьев

Глубокие деревья склонны к переобучению — «затачиваются» на отдельные объекты (неограниченное дерево
способно выучить любую непротиворечивую выборку). Что делают:
- **останавливают рост рано** (pre-pruning, критерии останова выше); точку останова можно выбрать на отложенной выборке;
- **подрезают** выращенное дерево (post-pruning): cost-complexity pruning $R_\alpha(T) = R(T) + \alpha|T|$,
  раньше — удаление листьев по отложенной выборке, MDL. Сейчас используется редко — когда задачу надо решить
  **одним** деревом;
- используют деревья **в ансамблях** (случайный лес, бустинг) — основной способ на практике.

Подробно pre/post-pruning — в теме [06](../06_bias_variance/README.md#6-борьба-с-переобучением-в-решающих-деревьях).

> Неограниченное дерево не **всегда** переобучается. На датасете Mushrooms (семинар) полное дерево
> глубины 5–7 с 11–14 листьями дало **100%** точности на тесте: данные почти идеально делятся по
> нескольким признакам (главный — запах `odor`). Но это редкость.

## 4. Важность признаков

Идея: чем сильнее признак уменьшает неоднородность, тем он важнее. **Важность** = сумма уменьшений
неоднородности по всем сплитам с этим признаком (в sklearn — с весом доли объектов в вершине, затем нормировка):

```python
model.feature_importances_       # MDI (mean decrease in impurity)
```

Минусы MDI: считается на обучении, завышает признаки с большим числом уникальных значений
([подробнее](deep.md#7-важность-признаков-mdi)). Другие способы: коэффициенты моделей, OOB-оценки,
permutation importance, корреляции.

```python
from sklearn.inspection import permutation_importance
r = permutation_importance(model, X_val, y_val, n_repeats=10, random_state=0)
```

## 5. Пропуски и категориальные признаки

**Пропуски (missing values):** удалить; заменить (средним); отдельная категория; пронести объект в обе
ветви; выбрать наиболее подходящую ветвь; **суррогатные расщепления** — для объектов с пропуском в
признаке сплита подбирается другой сплит, имитирующий исходный ([как](deep.md#8-пропуски-суррогатные-расщепления)).
В sklearn ≥ 1.3 деревья поддерживают `NaN` нативно (пропуски уходят в ту ветвь, где выигрыш больше).

**Категориальные признаки:** формально нужно перебрать все подмножества категорий ($2^{q-1} - 1$).
Реально (бинарная классификация): **упорядочиваем категории по доле класса 1**, заменяем категорию номером
и ищем сплит как для числового признака — это даёт оптимум ([теорема](deep.md#6-категориальные-признаки-теорема-о-сортировке-по-среднему)).
Опасность — переобучение на мелких категориях; признаки с огромным числом категорий «перетягивают» сплиты на себя.
В sklearn категории обычно кодируют one-hot (`pd.get_dummies`): на Mushrooms 21 признак → 115.

## 6. Деревья vs линейные модели

| | Дерево | Линейная модель |
|---|---|---|
| Граница | ступенчатая, оси-параллельная | гиперплоскость |
| Нелинейности, взаимодействия признаков | ловит сама | только через генерацию признаков |
| Линейная зависимость | аппроксимирует «лесенкой», нужно много сплитов | идеально |
| Экстраполяция | **нет** (константа за пределами данных) | есть |
| Масштабирование | не нужно | нужно |

**Генерация признаков деревьями:** номер листа дерева (или путь) — нелинейный признак для линейной модели
(классика: GBDT + LR в рекламе Facebook).

## 7. Классические алгоритмы

| Алгоритм | Критерий | Ветвление | Признаки | Таргет | Пропуски | Подрезка |
|---|---|---|---|---|---|---|
| **ID3** (Quinlan, 1986) | Information Gain | небинарное | категориальные | категориальный | нет | нет |
| **C4.5** (Quinlan, 1993) | Gain ratio, IG | небинарное | вещ. и кат. | категориальный | да | error-based pruning |
| **CART** (Breiman et al., 1984) | Gini (Twoing), MSE | бинарное | вещ. и кат. | вещ. и кат. | да (суррогаты) | cost-complexity |
| **CHAID** (Kass, 1980) | χ² | небинарное | вещ. и кат. | категориальный | | ограничения на размер |
| **QUEST** (Loh, Shih, 1997) | χ² (кат.), ANOVA (вещ.) | бинарное | вещ. и кат. | категориальный | | post-pruning |

### Своё дерево регрессии (по мотивам ДЗ)

```python
import numpy as np

class MyDecisionTreeRegressor:
    def __init__(self, max_depth=5, min_samples_leaf=1):
        self.max_depth, self.min_samples_leaf = max_depth, min_samples_leaf

    def _best_split(self, X, y):
        best = (None, None, np.sum((y - y.mean()) ** 2))       # (признак, порог, RSS)
        n = len(y)
        for j in range(X.shape[1]):
            order = np.argsort(X[:, j]); xs, ys = X[order, j], y[order]
            csum, csum2 = np.cumsum(ys), np.cumsum(ys ** 2)      # префиксные суммы
            for i in range(self.min_samples_leaf, n - self.min_samples_leaf + 1):
                if xs[i - 1] == xs[i]:
                    continue                                       # порог только между разными значениями
                nl, nr = i, n - i
                rss_l = csum2[i - 1] - csum[i - 1] ** 2 / nl
                rss_r = (csum2[-1] - csum2[i - 1]) - (csum[-1] - csum[i - 1]) ** 2 / nr
                if rss_l + rss_r < best[2]:
                    best = (j, (xs[i - 1] + xs[i]) / 2, rss_l + rss_r)
        return best[:2]

    def _fit_node(self, X, y, depth):
        if depth >= self.max_depth or len(y) < 2 * self.min_samples_leaf or np.all(y == y[0]):
            return {"value": y.mean()}
        j, t = self._best_split(X, y)
        if j is None:
            return {"value": y.mean()}
        m = X[:, j] <= t
        return {"feat": j, "thr": t,
                "left": self._fit_node(X[m], y[m], depth + 1),
                "right": self._fit_node(X[~m], y[~m], depth + 1)}

    def fit(self, X, y):
        self.root = self._fit_node(np.asarray(X, float), np.asarray(y, float), 0)
        return self

    def _predict_one(self, x, node):
        while "value" not in node:
            node = node["left"] if x[node["feat"]] <= node["thr"] else node["right"]
        return node["value"]

    def predict(self, X):
        return np.array([self._predict_one(x, self.root) for x in np.asarray(X, float)])
```

### Критерии вручную (семинар)

```python
def entropy(probs):
    return -sum(p * np.log2(p) for p in probs if p > 0)     # 0·log 0 = 0

def gini(probs):
    return 1 - sum(p ** 2 for p in probs)

entropy([0.5, 0.5]), gini([0.5, 0.5])   # (1.0, 0.5) — максимум неопределённости
```

## 9. Итог: плюсы и минусы

| Возможности | Ограничения |
|---|---|
| обучается на любой непротиворечивой выборке | невысокое качество одиночного дерева, переобучение |
| признаки разных типов + пропуски | **неустойчивый** алгоритм: меняется при небольшом изменении выборки |
| можно сделать устойчивым к выбросам | плох для больших / изменяющихся данных |
| универсален: классификация, регрессия, ранжирование… | нет аналитической формулы модели |
| встроенный отбор признаков, использует мало признаков | **не экстраполирует** |
| нелинейный метод | жадное (эвристическое) обучение — не оптимальное дерево |
| быстро строится, нет требований к распределениям | признаки с большим числом категорий «перетягивают» сплиты |
| неметрический: **не нужно масштабирование**, устойчив к дубликатам и зависимостям признаков | |
| легко объяснить неспециалисту, можно нарисовать | |
| **отлично работает в ансамблях** | |
