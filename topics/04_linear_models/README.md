# 04. Линейные модели: регрессия, регуляризация, логрег, SVM

[Шпаргалка (ноутбук)](../../cheatsheet.ipynb) · [Оглавление курса](../../README.md)

**Суть.** Прогноз — взвешенная сумма признаков $a(x)=\langle w,x\rangle+w_0$. Регрессия учится МНК
(есть формула), классификация — логистической регрессией (log loss) или SVM (hinge loss).
**Регуляризация** (L2 / L1) борется с мультиколлинеарностью и переобучением; L1 ещё и отбирает признаки.
Нелинейность — через генерацию признаков (полиномы, OHE, бининг) или ядра (SVM).

| Термин | Определение |
|---|---|
| OLS / МНК | минимизация $\lVert Xw-y\rVert^2$; решение $w=(X^\top X)^{-1}X^\top y$ |
| Мультиколлинеарность | почти линейно зависимые признаки → $X^\top X$ плохо обусловлена → огромные неустойчивые веса |
| Ridge / LASSO / Elastic Net | штраф $\lambda\lVert w\rVert_2^2$ / $\lambda\lVert w\rVert_1$ (зануляет веса) / их сумма |
| GD / SGD | шаг по антиградиенту всей выборки / одного объекта (мини-батча) |
| Логистическая регрессия | $P(y=1\mid x)=\sigma(\langle w,x\rangle)$, обучение — log loss |
| SVM | максимизация зазора $2/\lVert w\rVert$ = hinge loss + L2; kernel trick |
| Калибровка (Платт, изотоническая) | исправление вероятностей так, чтобы «0.8» значило 80% |

**Ключевые формулы**

$$
w^*_{\text{OLS}}=(X^\top X)^{-1}X^\top y,\qquad
w^*_{\text{Ridge}}=(X^\top X+\lambda I)^{-1}X^\top y,\qquad
\nabla_w\text{MSE}=\tfrac{2}{\ell}X^\top(Xw-y)
$$

$$
\sigma(z)=\frac{1}{1+e^{-z}},\quad \nabla_w\text{LogLoss}=\tfrac1\ell X^\top(\sigma(Xw)-y),\qquad
\text{SVM}: \sum_i\max\big(0,1-y_i\langle w,x_i\rangle\big)+\tfrac{1}{2C}\lVert w\rVert^2
$$

<summary><b>1. Линейная регрессия</b></summary>

**Гипотеза:** целевая переменная — линейная комбинация признаков:

$$
a(x) = w_0 + w_1x^1 + \dots + w_n x^n = \langle w, x\rangle + w_0 .
$$

Удобно ввести **фиктивный признак** $x^0 \equiv 1$, тогда $a(x) = \langle w, x\rangle$.

Где применяется: зависимости монотонны; много однородных признаков (тексты, счётчики); нужна
интерпретируемость. Пример из лекции — прогноз спроса:
`спрос = 1000 + 0.01·просмотры + 0.3·корзина + 0.05·поисковые_запросы + …`

**1.1. Обучение: метод наименьших квадратов (МНК, OLS)**

Минимизируем сумму квадратов невязок (residuals) — **RSS** (Residual Sum of Squares), это минимизация
эмпирического риска с квадратичной функцией потерь:

$$
\text{RSS}(w) = \sum_{i=1}^{\ell}\big(y_i - \langle w, x_i\rangle\big)^2 = \|Xw - y\|^2 \to \min_w .
$$

**Аналитическое решение** (нормальное уравнение, вывод (см. раздел «1. МНК: нормальное уравнение»)):

$$
w^* = (X^\top X)^{-1}X^\top y = X^+ y ,
$$

$X^+$ — псевдообратная Мура–Пенроуза. Решение существует и единственно, если столбцы $X$ линейно независимы.
Задача выпукла — глобальный минимум один.

**Геометрически** МНК опускает перпендикуляр из вектора $y$ на подпространство, натянутое на признаки
(ищем перпендикуляр к проекции, а не расстояние до поверхности). Прямая парной регрессии проходит
через «центр масс» $(\bar x, \bar y)$, а $w_1 = \operatorname{cov}(x, y)/\operatorname{var}(x)$.

Исторически «регрессия» — от работы Гальтона (1877) о «регрессии к посредственности при наследовании роста».

**1.2. Теорема Гаусса–Маркова**

Если модель правильно специфицирована (самая сложная, непроверяемая предпосылка), признаки неслучайны,
$\mathbb{E}e_i = 0$ (в среднем не ошибаемся), $\operatorname{Var}e_i = \sigma^2$ (гомоскедастичность),
$\operatorname{cov}(e_i, e_j) = 0$ (ошибки некоррелированы), то оценка МНК — **BLUE** (Best Linear Unbiased
Estimator): наилучшая среди линейных несмещённых (доказательство (см. раздел «2. Теорема Гаусса–Маркова»)).

**1.3. Другие способы найти веса**

| Метод | Идея | Плюсы |
|---|---|---|
| Нормальное уравнение | $w = (X^\top X)^{-1}X^\top y$ | просто; $O(\ell d^2 + d^3)$ |
| **QR-разложение** | $X = QR$ ⇒ $Rw = Q^\top y$, обратная подстановка | численно устойчивее |
| **SVD-разложение** | $X = U\Sigma V^\top$ ⇒ $w = V\Sigma^+U^\top y$ | самое устойчивое, работает при вырожденной $X$ |
| **Градиентный спуск** | $w \leftarrow w - \eta\nabla Q(w)$ | огромные данные, любая дифференцируемая функция потерь |
| **SGD** | градиент по одному случайному объекту (или мини-батчу) | дешёвые шаги, online-обучение |

<summary><b>2. Проблема вырожденности и мультиколлинеарность</b></summary>

Если признаки линейно зависимы (или почти зависимы), матрица $X^\top X$ вырождена или **плохо обусловлена**:
веса получаются огромными и неустойчивыми, дисперсия оценок $\sigma^2(X^\top X)^{-1}$ взрывается.

Пример из лекции: признаки $x_1$ и $x_2 \approx x_1$. Если $y = x_1$, подходит и $a = x_1$, и
$a = 1001x_1 - 1000x_2$ — ответы на обучении почти одинаковы, но второй вариант неустойчив: при
небольшом расхождении $x_1$ и $x_2$ на новых данных прогноз «улетает».

**Решения:**
1. **Регуляризация** — штраф за величину коэффициентов;
2. **Отбор признаков** — убрать избыточные, шумные, сильно зависимые (тема [12](../12_feature_engineering_selection/README.md));
3. **Снижение размерности** (PCA, тема [11](../11_clustering_dim_reduction/README.md));
4. **Увеличение выборки** — сбор данных, синтетика, псевдообъекты: зависимости между столбцами могут исчезнуть.

</details>

<details>
<summary><b>3. Регуляризация: Ridge, LASSO, Elastic Net</b></summary>

**Смысл:** похожие объекты должны получать похожие ответы. Если объекты отличаются в $j$-м признаке на
$\delta$, ответы отличаются на $w_j\delta$ — значит, веса не должны быть огромными. Добавляем к
функции потерь штраф:

| Метод | Функционал | Особенности |
|---|---|---|
| **Ridge** (L2, Тихонова) | $\lVert Xw - y\rVert^2 + \lambda\lVert w\rVert_2^2$ | решение $w = (X^\top X + \lambda I)^{-1}X^\top y$ всегда существует; веса уменьшаются, но не зануляются |
| **LASSO** (L1) | $\lVert Xw - y\rVert^2 + \lambda\lVert w\rVert_1$ | **зануляет** веса → автоматический отбор признаков; нет аналитического решения |
| **Elastic Net** | $\lVert Xw - y\rVert^2 + \lambda_1\lVert w\rVert_1 + \lambda_2\lVert w\rVert_2^2$ | отбор + устойчивость при коррелированных признаках |

- $\lambda = 0$ — классическое решение OLS; $\lambda \to \infty$ — веса → 0, сильная регуляризация.
- $\lambda$ подбирают на **скользящем контроле** (`RidgeCV`, `LassoCV`, `GridSearchCV`).
- Формы **Иванова** ($\min$ ошибки при $\|w\| \le t$) и **Тихонова** (штраф в функционале) эквивалентны;
  Тихонова удобнее — безусловная оптимизация.
- **Свободный член $w_0$ не регуляризуют**: он отвечает за средний уровень таргета, а не за сложность
  (почему (см. раздел «4. Lasso (L1): почему зануляет веса»)).

**Почему L1 даёт разреженность** (геометрия): линии уровня ошибки чаще касаются «ромба» $\|w\|_1 \le t$
в вершине, где часть координат равна нулю; $L_1$ ближе к $L_0$-«норме» (числу ненулевых весов), чем $L_2$.
Аналитически Lasso — это **мягкий порог** $\operatorname{sign}(z)(|z| - \lambda)_+$ (вывод (см. раздел «4. Lasso (L1): почему зануляет веса»)).

**Нормировка обязательна**: регуляризация не инвариантна к умножению признака на число
(в отличие от обычной линейной регрессии).

| Скейлер | Преобразование | Когда |
|---|---|---|
| `StandardScaler` | $(x - \mu)/\sigma$ | по умолчанию |
| `MinMaxScaler` | $(x - \min)/(\max - \min)$ | нужен диапазон $[0, 1]$; чувствителен к выбросам |
| `RobustScaler` | $(x - \text{медиана})/\text{IQR}$ | есть выбросы |

```python
from sklearn.linear_model import Ridge, Lasso, ElasticNet, RidgeCV
Ridge(alpha=1.0, fit_intercept=True, solver="auto", positive=False)   # solver: 'svd','cholesky','lsqr','sag','saga','lbfgs'
Lasso(alpha=0.1)
ElasticNet(alpha=0.1, l1_ratio=0.5)        # l1_ratio — доля L1 в штрафе
RidgeCV(alphas=np.logspace(-3, 3, 13))     # подбор alpha на CV
```

<summary><b>4. Градиентный спуск для линейной регрессии</b></summary>

$$
\nabla_w Q = \frac{2}{\ell}X^\top(Xw - y), \qquad w^{(t+1)} = w^{(t)} - \eta\,\nabla_w Q\big(w^{(t)}\big).
$$

- **GD** — градиент по всей выборке: стабильно, но каждый шаг $O(\ell d)$.
- **SGD** — по одному случайному объекту: $w \leftarrow w - \eta\cdot 2(\langle w, x_i\rangle - y_i)x_i$.
  Быстро, можно учиться **онлайн**, но траектория шумная; темп сходимости смотрят по графику ошибки.
- **Mini-batch** — компромисс (стандарт в нейросетях).
- Шаг $\eta$ слишком большой → расходимость; слишком маленький → медленно. Масштабирование признаков
  ускоряет сходимость (почему (см. раздел «5. Градиентный спуск и SGD»)).

```python
import numpy as np

def fit_gd(X, y, lr=0.1, n_iter=1000, l2=0.0):
    X = np.c_[np.ones(len(X)), X]                       # фиктивный признак для w0
    w = np.zeros(X.shape[1])
    for _ in range(n_iter):
        grad = 2 / len(X) * X.T @ (X @ w - y)
        grad[1:] += 2 * l2 * w[1:]                      # L2 без свободного члена
        w -= lr * grad
    return w
```

<summary><b>5. Устойчивость к выбросам и интерпретация</b></summary>

**Выбросы** сильно тянут МНК (квадратичный штраф). Что делать:
- чистить данные (удалять выбросы);
- **устойчивая (робастная) регрессия** — по-разному штрафовать наблюдения: `HuberRegressor`, `RANSACRegressor`,
  `TheilSenRegressor`, `QuantileRegressor` (см. функции потерь в теме [01](../01_intro_regression_metrics/README.md)).

**Эконометрика:** линейная регрессия — основной инструмент, когда нужно не предсказать $y$, а **оценить
влияние** фактора при прочих равных. Коэффициент $\beta_j$ — изменение $y$ при росте $x_j$ на единицу
при фиксированных остальных. Значимость — t-тесты, p-value, доверительные интервалы.
Пример: $\text{earnings} = \beta_0 + \beta_1\,\text{education} + \beta_2\,\text{experience} + \beta_3\,\text{gender} + \varepsilon$
(«+1 год обучения ≈ +1.5 тыс. ₽»). Исследование *Moved to Opportunity* (влияние переезда из гетто на
судьбу детей) сделано на линейной регрессии.

```python
import statsmodels.api as sm
model = sm.OLS(y, sm.add_constant(X)).fit()
print(model.summary())      # коэффициенты, SE, t, p-value, R², AIC/BIC
```

> Осторожно: интерпретировать веса можно только при отсутствии мультиколлинеарности и при сравнимых
> масштабах признаков; корреляция ≠ причинность.

<summary><b>6. Предобработка признаков для линейных моделей</b></summary>

| Преобразование | Зачем | Как |
|---|---|---|
| **One-Hot Encoding** | категории → бинарные признаки; простая интерпретация | `OneHotEncoder(handle_unknown="ignore")`; одну категорию можно выкинуть (`drop="first"`), чтобы избежать точной коллинеарности со свободным членом |
| **Label Encoding** | категория → целое число | только если у категорий есть **порядок**, иначе портит линейную модель |
| **Target Encoding** | очень много категорий (OHE раздует размерность) | среднее таргета по категории; **только на кросс-валидации** (out-of-fold), иначе утечка |
| **Полиномы признаков** | нелинейные зависимости | `PolynomialFeatures(degree=2, include_bias=False)`; не перебарщивать — переобучение |
| **Бинаризация / дискретизация** | «точки перелома» — разные тренды до и после порога | `KBinsDiscretizer`, ручные пороги → кусочно-линейная модель |
| **Преобразование таргета** | таргет не линеаризуется (скошенный, мультипликативный) | $\log(1+y)$, $\sqrt[n]{y}$, Бокс–Кокс, Йео–Джонсон; `TransformedTargetRegressor` |

Из ДЗ (Ames Housing): лог-преобразование таргета подняло $R^2$ линейной регрессии с 0.874 до 0.916,
а дереву помогло меньше (0.803 → 0.842) — дереву важен лишь порядок, а линейной модели — форма
распределения (почему (см. раздел «9. Преобразование целевой переменной»)).

```python
from sklearn.compose import ColumnTransformer, TransformedTargetRegressor
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import OneHotEncoder, StandardScaler, PolynomialFeatures
from sklearn.linear_model import Ridge

pre = ColumnTransformer([
    ("num", Pipeline([("poly", PolynomialFeatures(2, include_bias=False)),
                      ("scale", StandardScaler())]), num_cols),
    ("cat", OneHotEncoder(handle_unknown="ignore"), cat_cols),
])
model = TransformedTargetRegressor(
    regressor=Pipeline([("pre", pre), ("ridge", Ridge(alpha=1.0))]),
    func=np.log1p, inverse_func=np.expm1)          # обучение на log1p(y) = оптимизация RMSLE
```

**Линейные модели для временных рядов**

Пройдём окном по ряду: признаки — $n$ прошлых значений $(y_{t-n}, \dots, y_{t-1})$, таргет — $y_t$.
Получаем авторегрессию — линейную модель на лагах. Пример задач: прогноз спроса (покупки, просмотры,
корзины за $k$ дней, дни без покупок, изменение цены, наличие акции), раскупаемости, дебита нефти.

<summary><b>7. Логистическая регрессия</b></summary>

Линейная модель для **классификации**: линейно моделируется **логарифм шансов**, вероятность — через сигмоиду:

$$
P(y = 1 \mid x) = \sigma(\langle w, x\rangle + w_0) = \frac{1}{1 + e^{-(\langle w, x\rangle + w_0)}} .
$$

- Обучение — минимизация **log loss** (= максимум правдоподобия Бернулли); задача выпуклая, но
  аналитического решения нет → градиентные методы (L-BFGS, Ньютон, SGD).
- Градиент: $\nabla_w Q = \frac{1}{\ell}X^\top(\sigma(Xw) - y)$ — «признаки × (прогноз − ответ)».
- Разделяющая граница $\langle w, x\rangle + w_0 = 0$ — **гиперплоскость** (при пороге 0.5).
- Интерпретация: $e^{w_j}$ — во сколько раз растут **шансы** класса 1 при росте $x^j$ на 1.
- Многоклассовая версия — **softmax-регрессия** (multinomial).
- На линейно разделимых данных без регуляризации веса уходят в бесконечность → в sklearn по умолчанию
  L2 с `C=1.0` ($C = 1/\lambda$, **меньше C — сильнее регуляризация**).

Реализация с нуля (по мотивам ДЗ «Логистическая регрессия и SVM»):

```python
class LogReg:
    def __init__(self, lr=0.1, n_iter=1000):
        self.lr, self.n_iter = lr, n_iter

    @staticmethod
    def _sigmoid(z):
        return 1 / (1 + np.exp(-np.clip(z, -500, 500)))

    def fit(self, X, y):
        n, d = X.shape
        self.w, self.b, self.losses = np.zeros(d), 0.0, []
        for _ in range(self.n_iter):
            p = self._sigmoid(X @ self.w + self.b)
            p_ = np.clip(p, 1e-15, 1 - 1e-15)
            self.losses.append(-np.mean(y * np.log(p_) + (1 - y) * np.log(1 - p_)))
            self.w -= self.lr * X.T @ (p - y) / n            # полностью векторизованно
            self.b -= self.lr * np.mean(p - y)
        return self

    def predict_proba(self, X):
        p = self._sigmoid(X @ self.w + self.b)
        return np.c_[1 - p, p]

    def predict(self, X, threshold=0.5):
        return (self.predict_proba(X)[:, 1] >= threshold).astype(int)
```

<summary><b>8. SVM (метод опорных векторов)</b></summary>

**Идея:** среди всех разделяющих гиперплоскостей выбрать ту, что **максимизирует зазор** (margin) —
расстояние до ближайших объектов классов. Ширина полосы $= 2/\|w\|$.

**Soft-margin SVM** = **hinge loss** + L2-регуляризация (вывод (см. раздел «7. SVM»)):

$$
\sum_i \max\big(0,\; 1 - y_i(\langle w, x_i\rangle + b)\big) + \frac{1}{2C}\|w\|^2 \to \min_{w, b}, \qquad y_i \in \lbrace -1, +1\rbrace .
$$

- **Опорные векторы** — объекты на границе полосы или нарушители; решение зависит только от них.
- **$C$** — штраф за нарушения: большое $C$ → узкий зазор, меньше ошибок на обучении (переобучение);
  маленькое → широкий зазор, сильнее регуляризация.
- **Kernel trick**: в двойственной задаче данные входят через $\langle x_i, x_j\rangle$; замена на ядро
  $K(x_i, x_j)$ даёт **нелинейную** границу. RBF: $K = e^{-\gamma\|x - x'\|^2}$ — $\gamma$ задаёт «радиус влияния»
  объекта (большое $\gamma$ → переобучение).
- SVM не выдаёт вероятности — нужна **калибровка** (Платт).

```python
from sklearn.svm import LinearSVC, SVC
LinearSVC(C=1.0)                                   # линейный, быстрый, для больших данных
SVC(kernel="rbf", C=1.0, gamma="scale", probability=True)   # ядровой; probability=True → Платт внутри
```

| | Логистическая регрессия | SVM |
|---|---|---|
| Loss | log loss $\ln(1 + e^{-M})$ | hinge $\max(0, 1 - M)$ |
| Вероятности | да (обычно хорошо откалиброваны) | нет, нужна калибровка |
| Влияние объектов | все объекты | только опорные векторы |
| Нелинейность | через признаки | через ядра |
| Масштабирование | желательно | **обязательно** |

</details>

<details>
<summary><b>9. Калибровка вероятностей</b></summary>

Модель **откалибрована**, если среди объектов с прогнозом 0.8 положительных действительно ≈ 80%.
Нужна, когда вероятность используется как число (ожидаемая прибыль, ставки, риск), а не только для ранжирования.

- **Метод Платта** — поверх скоров обучаем одномерную логрег $\sigma(As + B)$ на отложенной выборке.
- **Изотоническая регрессия** — монотонная кусочно-постоянная функция; гибче, но нужно больше данных.
- Диагностика — **калибровочная кривая** и **Brier score** $\frac{1}{\ell}\sum (p_i - y_i)^2$.
- Калибровка монотонна и **не меняет ROC-AUC**.

```python
from sklearn.calibration import CalibratedClassifierCV, CalibrationDisplay
cal = CalibratedClassifierCV(SVC(), method="sigmoid", cv=5).fit(X_train, y_train)   # 'isotonic'
CalibrationDisplay.from_estimator(cal, X_test, y_test, n_bins=10)
```

Подробно — см. раздел «8. Калибровка вероятностей».

</details>

**Математика и выводы**

<details>
<summary><b>Введение</b></summary>

Обозначения: $X \in \mathbb{R}^{\ell \times d}$ — матрица «объект–признак» (с фиктивным столбцом единиц, если
нужен свободный член), $y \in \mathbb{R}^\ell$, $w \in \mathbb{R}^d$, $a(x) = \langle w, x\rangle$.

</details>

<details>
<summary><b>1. МНК: нормальное уравнение</b></summary>

$$
Q(w) = \|Xw - y\|^2 = (Xw - y)^\top(Xw - y) = w^\top X^\top X w - 2 y^\top X w + y^\top y .
$$

Градиент (используем $\nabla_w (w^\top A w) = 2Aw$ для симметричной $A$ и $\nabla_w(b^\top w) = b$):

$$
\nabla_w Q = 2X^\top X w - 2X^\top y = 2X^\top(Xw - y) = 0
\;\Longrightarrow\; X^\top X\, w = X^\top y \;\Longrightarrow\; w^* = (X^\top X)^{-1}X^\top y .
$$

Гессиан $2X^\top X \succeq 0$ ⇒ $Q$ выпукла; если столбцы $X$ линейно независимы, $X^\top X \succ 0$ и минимум
единственный. Матрица $X^+ = (X^\top X)^{-1}X^\top$ — **псевдообратная Мура–Пенроуза**.

**Геометрия**

Прогноз $\hat y = Xw^* = \underbrace{X(X^\top X)^{-1}X^\top}_{H} y$. Матрица $H$ («hat matrix») —
**ортогональный проектор** на линейную оболочку столбцов $X$: $H^2 = H$, $H^\top = H$.
Остаток $e = y - \hat y = (I - H)y$ ортогонален всем столбцам: $X^\top e = 0$ — это и есть нормальное
уравнение. МНК = опустить перпендикуляр из $y$ на подпространство признаков (слайд «ищем перпендикуляр
к проекции»).

Следствие: если есть столбец единиц, $\sum_i e_i = 0$, т.е. **прямая проходит через центр масс**
$(\bar x, \bar y)$.

**Парная регрессия**

$a(x) = w_0 + w_1 x$. Из $\partial Q/\partial w_0 = 0$: $w_0 = \bar y - w_1\bar x$. Подставляя в $\partial Q/\partial w_1 = 0$:

$$
w_1 = \frac{\sum_i (x_i - \bar x)(y_i - \bar y)}{\sum_i (x_i - \bar x)^2} = \frac{\operatorname{cov}(x, y)}{\operatorname{var}(x)} = r_{xy}\frac{s_y}{s_x} .
$$

Отсюда «регрессия к среднему» (Гальтон): так как $|r_{xy}| \le 1$, в стандартизованных единицах прогноз
по модулю не больше аргумента — дети очень высоких родителей в среднем ниже родителей.

</details>

<details>
<summary><b>2. Теорема Гаусса–Маркова</b></summary>

**Условия:** $y = Xw + e$; $X$ неслучайна и полного ранга; $\mathbb{E}e = 0$; $\operatorname{Var}(e_i) = \sigma^2$
(гомоскедастичность); $\operatorname{cov}(e_i, e_j) = 0$ при $i \ne j$.
**Утверждение:** $\hat w = X^+ y$ — **BLUE** (Best Linear Unbiased Estimator): среди всех линейных по $y$
несмещённых оценок у неё минимальная ковариационная матрица.

*Несмещённость:* $\mathbb{E}\hat w = X^+\mathbb{E}y = (X^\top X)^{-1}X^\top X w = w$.
*Ковариация:* $\operatorname{Var}\hat w = X^+ \sigma^2 I (X^+)^\top = \sigma^2 (X^\top X)^{-1}$.

*Оптимальность.* Пусть $\tilde w = Cy$ — другая линейная несмещённая оценка, $C = X^+ + D$.
Несмещённость для любого $w$ требует $CX = I$, откуда $DX = 0$. Тогда

$$
\operatorname{Var}\tilde w = \sigma^2 CC^\top = \sigma^2\big(X^+ X^{+\top} + X^+D^\top + DX^{+\top} + DD^\top\big) = \sigma^2(X^\top X)^{-1} + \sigma^2 DD^\top ,
$$

так как $DX^{+\top} = DX(X^\top X)^{-1} = 0$. Матрица $DD^\top \succeq 0$, значит $\operatorname{Var}\tilde w \succeq \operatorname{Var}\hat w$. ∎

**Мультиколлинеарность.** $\operatorname{Var}\hat w = \sigma^2(X^\top X)^{-1}$: если признаки почти линейно зависимы,
у $X^\top X$ есть собственные значения $\approx 0$, и дисперсия весов взрывается — веса огромные и
неустойчивые (слайды «проблема вырожденности»). Мера — **число обусловленности**
$\kappa = \sigma_{\max}/\sigma_{\min}$ сингулярных чисел $X$.

</details>

<details>
<summary><b>3. Ridge (L2): решение, SVD-взгляд, байесовский смысл</b></summary>

$$
Q(w) = \|Xw - y\|^2 + \lambda\|w\|^2 \;\Rightarrow\; 2X^\top(Xw - y) + 2\lambda w = 0 \;\Rightarrow\; w^* = (X^\top X + \lambda I)^{-1}X^\top y .
$$

$X^\top X \succeq 0$, $\lambda I \succ 0$ ⇒ сумма **положительно определена** и всегда обратима
(«складываем неотрицательно определённую и положительно определённую матрицы Грама»).

**SVD-взгляд.** Пусть $X = U\Sigma V^\top$, сингулярные числа $\sigma_j$. Тогда

$$
\hat y_{\text{OLS}} = \sum_j u_j\, u_j^\top y, \qquad
\hat y_{\text{ridge}} = \sum_j u_j \frac{\sigma_j^2}{\sigma_j^2 + \lambda} u_j^\top y .
$$

Ridge **сжимает** компоненты вдоль направлений с малой дисперсией признаков (малые $\sigma_j$) сильнее всего —
именно там OLS неустойчив. Эффективное число параметров: $\text{df}(\lambda) = \sum_j \frac{\sigma_j^2}{\sigma_j^2 + \lambda}$
(от $d$ при $\lambda = 0$ до 0 при $\lambda \to \infty$).

**Байесовский смысл.** Пусть $y \mid w \sim \mathcal{N}(Xw, \sigma^2 I)$ и априорно $w \sim \mathcal{N}(0, \tau^2 I)$. MAP-оценка:

$$
\arg\max_w \big[\ln p(y\mid w) + \ln p(w)\big] = \arg\min_w \Big[\frac{1}{2\sigma^2}\|Xw - y\|^2 + \frac{1}{2\tau^2}\|w\|^2\Big],
$$

т.е. Ridge с $\lambda = \sigma^2/\tau^2$. Lasso — MAP с априорным **распределением Лапласа**.

**Формы Иванова и Тихонова.** Задача $\min \|Xw - y\|^2$ при $\|w\|^2 \le t$ (Иванов) и
$\min \|Xw - y\|^2 + \lambda\|w\|^2$ (Тихонов) эквивалентны: для каждого $t$ существует $\lambda \ge 0$
(множитель Лагранжа из условий ККТ) с тем же решением, и наоборот.

</details>

<details>
<summary><b>4. Lasso (L1): почему зануляет веса</b></summary>

$$
Q(w) = \frac12\|Xw - y\|^2 + \lambda\|w\|_1 .
$$

**Ортонормированный случай** $X^\top X = I$. Тогда $Q$ распадается по координатам:
$\frac12 (w_j - z_j)^2 + \lambda|w_j| + \text{const}$, где $z_j = (X^\top y)_j$ — OLS-решение. Условие оптимальности
с субградиентом $\partial|w| = \operatorname{sign}(w)$ при $w \ne 0$ и $[-1, 1]$ при $w = 0$:

$$
0 \in w_j - z_j + \lambda\,\partial|w_j| \;\Longrightarrow\; w_j^* = \operatorname{sign}(z_j)\big(|z_j| - \lambda\big)_+ .
$$

Это **мягкий порог** (soft thresholding): все коэффициенты с $|z_j| \le \lambda$ становятся **ровно нулём**,
остальные сдвигаются к нулю на $\lambda$. Для сравнения, Ridge в том же случае даёт $w_j^* = \frac{z_j}{1 + \lambda}$ —
пропорциональное сжатие, ровно в ноль не попадает никогда.

**Геометрия.** Форма Иванова: линии уровня квадратичной ошибки (эллипсы) впервые касаются области
$\|w\|_1 \le t$ (ромб с вершинами на осях) чаще всего **в вершине**, где часть координат равна 0;
шар $\|w\|_2 \le t$ гладкий, и касание в точке с нулевой координатой — событие меры ноль.
$L_1$ — ближайшая к $L_0 = |\lbrace j: w_j \ne 0\rbrace|$ **выпуклая** норма.

**Elastic Net:** $\lambda_1\|w\|_1 + \lambda_2\|w\|^2$. Lasso из группы сильно коррелированных признаков
выбирает один произвольно и нестабильно; добавка L2 делает задачу строго выпуклой и включает
коррелированные признаки группой.

**Почему не регуляризуют $w_0$.** Штраф за свободный член сделал бы модель зависимой от сдвига таргета:
прибавив константу ко всем $y_i$, мы ожидаем, что прогноз сдвинется на ту же константу, но со
штрафом на $w_0$ этого не произойдёт. Свободный член отвечает за средний уровень, а не за сложность
зависимости; аргумент «похожие объекты — похожие ответы» (слайд о смысле регуляризации) относится
только к весам при признаках.

**Почему нужна нормировка.** Решение OLS эквивариантно к масштабу: умножив признак на $c$, получим
вес $w_j/c$ и тот же прогноз. Штраф $\lambda w_j^2$ этим свойством не обладает: признак в «мелких»
единицах получает большой вес и штрафуется сильнее. Поэтому перед Ridge/Lasso признаки стандартизуют.

</details>

<details>
<summary><b>5. Градиентный спуск и SGD</b></summary>

Для $Q(w) = \frac{1}{\ell}\|Xw - y\|^2$: $\nabla Q = \frac{2}{\ell}X^\top(Xw - y)$, шаг $w \leftarrow w - \eta\nabla Q(w)$.

**Условие сходимости.** $Q$ — квадратичная функция с гессианом $H = \frac{2}{\ell}X^\top X$. Ошибка
$w_t - w^*$ умножается на $(I - \eta H)$ на каждом шаге, поэтому GD сходится, если все собственные значения
$|1 - \eta\lambda_i(H)| < 1$, т.е. $0 < \eta < 2/\lambda_{\max}(H)$. Скорость определяет число
обусловленности $\kappa = \lambda_{\max}/\lambda_{\min}$: число итераций $\sim\kappa\ln(1/\varepsilon)$. Ещё одна причина
масштабировать признаки — масштабирование уменьшает $\kappa$ («вытянутые» линии уровня становятся круглыми).

**SGD.** $Q(w) = \frac{1}{\ell}\sum_i L_i(w)$. Берём случайный $i$ и шагаем по $\nabla L_i(w)$ — это **несмещённая**
оценка полного градиента: $\mathbb{E}_i\nabla L_i = \nabla Q$. Шаг в $\ell$ раз дешевле. Для сходимости
к минимуму нужен убывающий шаг (условия Роббинса–Монро): $\sum_t \eta_t = \infty$, $\sum_t \eta_t^2 < \infty$
(например, $\eta_t \sim 1/t$). При постоянном шаге SGD «дрожит» в окрестности минимума с радиусом $\sim\eta\cdot$
дисперсия стохастического градиента. **Mini-batch** размера $B$ уменьшает эту дисперсию в $B$ раз.

**Сложность прямого решения.** $X^\top X$ — $O(\ell d^2)$, обращение/Холецкий — $O(d^3)$. Для $d \sim 10^5$
или $\ell \sim 10^8$ это дорого → градиентные методы.

**QR и SVD.** $X = QR$: $Rw = Q^\top y$, обратная подстановка; численно устойчивее, чем
нормальное уравнение (обусловленность $X^\top X$ — это $\kappa(X)^2$). SVD: $w = V\Sigma^+U^\top y$ —
самый устойчивый вариант, работает и для вырожденной $X$ (даёт решение с минимальной нормой).

</details>

<details>
<summary><b>6. Логистическая регрессия</b></summary>

**6.1. Откуда сигмоида**

Модель: **логарифм шансов линеен** по признакам: $\ln\frac{p}{1-p} = \langle w, x\rangle$. Решаем относительно $p$:

$$
p = \sigma(\langle w, x\rangle) = \frac{1}{1 + e^{-\langle w, x\rangle}} .
$$

Свойства: $\sigma(-z) = 1 - \sigma(z)$, $\sigma'(z) = \sigma(z)(1 - \sigma(z))$.
Интерпретация весов: увеличение $x^j$ на 1 умножает **шансы** $\frac{p}{1-p}$ на $e^{w_j}$.

**6.2. Функция потерь и градиент**

Правдоподобие Бернулли ⇒ log loss (вывод — тема [02](../02_classification_metrics/README.md)):

$$
Q(w) = -\frac{1}{\ell}\sum_i\big(y_i\ln\sigma(\langle w, x_i\rangle) + (1-y_i)\ln(1-\sigma(\langle w, x_i\rangle))\big),
\qquad \nabla Q = \frac{1}{\ell}X^\top\big(\sigma(Xw) - y\big).
$$

Сравните с линейной регрессией: $\frac{2}{\ell}X^\top(Xw - y)$ — та же форма «признаки × (прогноз − ответ)».

**Выпуклость.** Гессиан $\nabla^2 Q = \frac{1}{\ell}X^\top S X$, $S = \operatorname{diag}\big(p_i(1-p_i)\big)$, $p_i(1-p_i) > 0$ ⇒
$\nabla^2 Q \succeq 0$: задача выпукла, глобальный минимум один (если есть). Аналитического решения нет,
используют Ньютона (IRLS), L-BFGS, SGD.

**Запись через отступ.** Для $y \in \lbrace -1, +1\rbrace$ и отступа $M_i = y_i\langle w, x_i\rangle$:
$L = \ln(1 + e^{-M_i})$.

**Линейно разделимые данные.** Если существует $w$ с $M_i > 0$ для всех $i$, то $Q(cw) \to 0$ при $c \to \infty$:
минимума нет, веса уходят в бесконечность, вероятности становятся 0/1. **Регуляризация обязательна**
(в sklearn она включена по умолчанию: `C=1.0`, где $C = 1/\lambda$).

**6.3. Многоклассовая (softmax) регрессия**

$P(y = k \mid x) = \frac{e^{\langle w_k, x\rangle}}{\sum_j e^{\langle w_j, x\rangle}}$, loss — кросс-энтропия, градиент по $w_k$:
$\frac{1}{\ell}\sum_i (p_{ik} - [y_i = k])x_i$. При $K = 2$ сводится к сигмоиде с $w = w_1 - w_0$.

</details>

<details>
<summary><b>7. SVM</b></summary>

**7.1. Жёсткий зазор**

Классы $y_i \in \lbrace -1, +1\rbrace$ линейно разделимы. Расстояние от точки до гиперплоскости
$\langle w, x\rangle + b = 0$ равно $\frac{|\langle w, x\rangle + b|}{\|w\|}$. Нормируем $w, b$ так, чтобы
$\min_i y_i(\langle w, x_i\rangle + b) = 1$; тогда ширина полосы (зазор, margin) равна $\frac{2}{\|w\|}$. Максимизация зазора:

$$
\min_{w, b}\; \frac12\|w\|^2 \quad\text{s.t.}\quad y_i(\langle w, x_i\rangle + b) \ge 1,\; i = 1..\ell .
$$

**7.2. Мягкий зазор и hinge loss**

Разрешаем нарушения $\xi_i \ge 0$:

$$
\min_{w, b, \xi}\; \frac12\|w\|^2 + C\sum_i\xi_i \quad\text{s.t.}\quad y_i(\langle w, x_i\rangle + b) \ge 1 - \xi_i,\; \xi_i \ge 0 .
$$

В оптимуме $\xi_i = \max(0, 1 - M_i)$, поэтому задача эквивалентна безусловной:

$$
\min_{w, b}\; \sum_i \max\big(0,\; 1 - y_i(\langle w, x_i\rangle + b)\big) + \frac{1}{2C}\|w\|^2 ,
$$

**SVM = hinge loss + L2-регуляризация.** Большое $C$ — меньше нарушений, уже зазор (риск переобучения).

**7.3. Двойственная задача и ядра**

Лагранжиан и условия ККТ дают $w = \sum_i \alpha_i y_i x_i$, $0 \le \alpha_i \le C$, $\sum_i \alpha_i y_i = 0$, и двойственную задачу

$$
\max_\alpha \sum_i \alpha_i - \frac12\sum_{i,j}\alpha_i\alpha_j y_i y_j\langle x_i, x_j\rangle .
$$

- $\alpha_i > 0$ только у **опорных векторов** (объектов на границе полосы или внутри неё); остальные не влияют на решение.
- Данные входят только через скалярные произведения ⇒ **kernel trick**: заменяем $\langle x_i, x_j\rangle$ на
  $K(x_i, x_j) = \langle\varphi(x_i), \varphi(x_j)\rangle$ (RBF $e^{-\gamma\|x - x'\|^2}$, полиномиальное $(\langle x, x'\rangle + c)^p$) и
  получаем нелинейную границу без явного построения $\varphi$. Прогноз: $a(x) = \operatorname{sign}\big(\sum_i\alpha_i y_i K(x_i, x) + b\big)$.

**7.4. Функции потерь как оценки сверху для 0–1 loss**

| Loss от отступа $M$ | Модель | Свойства |
|---|---|---|
| $[M < 0]$ | — | то, что хотим минимизировать; разрывна, NP-трудна |
| $\max(0, 1 - M)$ | SVM | кусочно-линейная, разреженность по объектам (опорные векторы) |
| $\log_2(1 + e^{-M})$ | логистическая регрессия | гладкая, даёт вероятности |
| $e^{-M}$ | AdaBoost | сильно штрафует выбросы |
| $(1 - M)^2$ | линейная регрессия на $\pm1$ | штрафует и «слишком правильные» объекты |

Все выпуклые и мажорируют $[M < 0]$, поэтому минимизация их эмпирического риска ограничивает число ошибок.

</details>

<details>
<summary><b>8. Калибровка вероятностей</b></summary>

Классификатор **откалиброван**, если среди объектов с прогнозом $p$ доля положительных ≈ $p$.
Проверка — **калибровочная кривая** (reliability diagram): бьём прогнозы на бины и сравниваем средний
прогноз с долей положительных в бине. Логрег на log loss обычно откалиброван «из коробки»
(собственное правило), SVM / наивный Байес / деревья / бустинг — нет.

**Платт (sigmoid calibration).** Поверх скора $s(x)$ обучаем одномерную логрег на **отложенной** выборке:

$$
\hat p(x) = \frac{1}{1 + \exp\big(A\, s(x) + B\big)}, \qquad (A, B) = \arg\min \text{LogLoss}.
$$

Платт предлагал сглаженные метки $t_+ = \frac{N_+ + 1}{N_+ + 2}$, $t_- = \frac{1}{N_- + 2}$ против переобучения.
Метод хорош, когда искажение имеет сигмоидную форму (типично для SVM) и данных мало.

**Изотоническая регрессия** — монотонная кусочно-постоянная функция $s \mapsto p$ (алгоритм PAV);
гибче, но требует больше данных и может переобучиться. Обе калибровки сохраняют порядок (AUC не меняется).

```python
from sklearn.calibration import CalibratedClassifierCV, calibration_curve
from sklearn.svm import LinearSVC
clf = CalibratedClassifierCV(LinearSVC(), method="sigmoid", cv=5).fit(X_train, y_train)   # или "isotonic"
prob_true, prob_pred = calibration_curve(y_test, clf.predict_proba(X_test)[:, 1], n_bins=10)
```

<summary><b>9. Преобразование целевой переменной</b></summary>

**Бокс–Кокс** ($y > 0$): $y^{(\lambda)} = \frac{y^\lambda - 1}{\lambda}$ при $\lambda \ne 0$, $\ln y$ при $\lambda = 0$; $\lambda$ подбирают по
правдоподобию, чтобы распределение стало ближе к нормальному.
**Йео–Джонсон** — обобщение на $y \le 0$ (`PowerTransformer(method="yeo-johnson")`).

**Смещение обратного преобразования.** Обучив модель на $\ln y$ и вернув $\exp(\hat z)$, получаем оценку
**медианы**, а не среднего: если $\ln y \mid x \sim \mathcal{N}(\mu, s^2)$, то
$\mathbb{E}[y \mid x] = e^{\mu + s^2/2} > e^\mu$. Если нужна оценка среднего (MSE в исходной шкале), прогноз
домножают на поправку (smearing Дуана: $\frac{1}{\ell}\sum_i e^{\hat\varepsilon_i}$ по остаткам).

Почему лог-преобразование помогает линейной модели сильнее, чем дереву (вывод из ДЗ): линейная модель
предполагает аддитивную структуру и однородный шум, а логарифм превращает мультипликативные эффекты
в аддитивные и стабилизирует дисперсию. Дереву важен лишь порядок значений признаков, а таргет
усредняется внутри листа — монотонное преобразование таргета меняет только критерий разбиения.

<summary><b>Дополнительно: детали</b></summary>

- **Гаусс–Марков**: при некоррелированных гомоскедастичных ошибках OLS — BLUE; $\operatorname{Var}\hat w=\sigma^2(X^\top X)^{-1}$.
- **Ridge = MAP** с гауссовским априорным распределением весов, Lasso — с лапласовским.
- GD сходится при $\eta<2/\lambda_{\max}(H)$, скорость $\sim$ числу обусловленности → масштабируйте признаки.
- Target transform: обучение на $\log(1+y)$ ≡ оптимизация RMSLE; обратное $\exp$ даёт медиану, а не среднее.
- SVM: решение зависит только от **опорных векторов**; ядро RBF $e^{-\gamma\lVert x-x'\rVert^2}$.

Запустить их можно в ноутбуке [`cheatsheet.ipynb`](../../cheatsheet.ipynb).

```python
import numpy as np
from sklearn.linear_model import LinearRegression, Ridge, Lasso

rng = np.random.default_rng(0)
n = 100
x1 = rng.normal(size=n)
x2 = x1 + rng.normal(scale=0.01, size=n)          # почти копия x1 -> мультиколлинеарность
noise = rng.normal(size=(n, 8))                   # 8 бесполезных признаков
X = np.c_[x1, x2, noise]
y = 3 * x1 + rng.normal(scale=0.5, size=n)

# Нормальное уравнение = sklearn
Xb = np.c_[np.ones(n), X]
w_closed = np.linalg.solve(Xb.T @ Xb, Xb.T @ y)
print("closed form == sklearn:", np.allclose(w_closed[1:], LinearRegression().fit(X, y).coef_))
for model in (LinearRegression(), Ridge(alpha=1.0), Lasso(alpha=0.1, max_iter=10000)):
    print(f"{type(model).__name__:16}", np.round(model.fit(X, y).coef_, 2))
# OLS: огромные веса противоположных знаков у x1, x2; Ridge делит вес поровну; Lasso зануляет лишнее
```

```python
# Логистическая регрессия градиентным спуском с нуля vs sklearn
from sklearn.datasets import load_breast_cancer
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

X, y = load_breast_cancer(return_X_y=True)
X = StandardScaler().fit_transform(X)
w, b = np.zeros(X.shape[1]), 0.0
for _ in range(2000):
    p = 1 / (1 + np.exp(-(X @ w + b)))
    w -= 0.1 * X.T @ (p - y) / len(y)             # градиент log loss: X^T (p - y)
    b -= 0.1 * np.mean(p - y)
acc_ours = np.mean(((X @ w + b) > 0) == y)
acc_skl = LogisticRegression(max_iter=5000).fit(X, y).score(X, y)
print(f"train accuracy: с нуля {acc_ours:.3f}, sklearn {acc_skl:.3f}")
```
