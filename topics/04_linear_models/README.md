## 1. Линейная регрессия

**Гипотеза:** целевая переменная — линейная комбинация признаков:

$$
a(x) = w_0 + w_1x^1 + \dots + w_n x^n = \langle w, x\rangle + w_0 .
$$

Удобно ввести **фиктивный признак** $x^0 \equiv 1$, тогда $a(x) = \langle w, x\rangle$.

Где применяется: зависимости монотонны; много однородных признаков (тексты, счётчики); нужна
интерпретируемость. Пример из лекции — прогноз спроса:
`спрос = 1000 + 0.01·просмотры + 0.3·корзина + 0.05·поисковые_запросы + …`

### 1.1. Обучение: метод наименьших квадратов (МНК, OLS)

Минимизируем сумму квадратов невязок (residuals) — **RSS** (Residual Sum of Squares), это минимизация
эмпирического риска с квадратичной функцией потерь:

$$
\text{RSS}(w) = \sum_{i=1}^{\ell}\big(y_i - \langle w, x_i\rangle\big)^2 = \|Xw - y\|^2 \to \min_w .
$$

**Аналитическое решение** (нормальное уравнение, [вывод](deep.md#1-мнк-нормальное-уравнение)):

$$
w^* = (X^\top X)^{-1}X^\top y = X^+ y ,
$$

$X^+$ — псевдообратная Мура–Пенроуза. Решение существует и единственно, если столбцы $X$ линейно независимы.
Задача выпукла — глобальный минимум один.

**Геометрически** МНК опускает перпендикуляр из вектора $y$ на подпространство, натянутое на признаки
(ищем перпендикуляр к проекции, а не расстояние до поверхности). Прямая парной регрессии проходит
через «центр масс» $(\bar x, \bar y)$, а $w_1 = \operatorname{cov}(x, y)/\operatorname{var}(x)$.

Исторически «регрессия» — от работы Гальтона (1877) о «регрессии к посредственности при наследовании роста».

### 1.2. Теорема Гаусса–Маркова

Если модель правильно специфицирована (самая сложная, непроверяемая предпосылка), признаки неслучайны,
$\mathbb{E}e_i = 0$ (в среднем не ошибаемся), $\operatorname{Var}e_i = \sigma^2$ (гомоскедастичность),
$\operatorname{cov}(e_i, e_j) = 0$ (ошибки некоррелированы), то оценка МНК — **BLUE** (Best Linear Unbiased
Estimator): наилучшая среди линейных несмещённых ([доказательство](deep.md#2-теорема-гауссамаркова)).

### 1.3. Другие способы найти веса

| Метод | Идея | Плюсы |
|---|---|---|
| Нормальное уравнение | $w = (X^\top X)^{-1}X^\top y$ | просто; $O(\ell d^2 + d^3)$ |
| **QR-разложение** | $X = QR$ ⇒ $Rw = Q^\top y$, обратная подстановка | численно устойчивее |
| **SVD-разложение** | $X = U\Sigma V^\top$ ⇒ $w = V\Sigma^+U^\top y$ | самое устойчивое, работает при вырожденной $X$ |
| **Градиентный спуск** | $w \leftarrow w - \eta\nabla Q(w)$ | огромные данные, любая дифференцируемая функция потерь |
| **SGD** | градиент по одному случайному объекту (или мини-батчу) | дешёвые шаги, online-обучение |

## 2. Проблема вырожденности и мультиколлинеарность

Если признаки линейно зависимы (или почти зависимы), матрица $X^\top X$ вырождена или **плохо обусловлена**:
веса получаются огромными и неустойчивыми, дисперсия оценок $\sigma^2(X^\top X)^{-1}$ взрывается.

Пример из лекции: признаки $x_1$ и $x_2 \approx x_1$. Если $y = x_1$, подходит и $a = x_1$, и
$a = 1001x_1 - 1000x_2$ — ответы на обучении почти одинаковы, но второй вариант неустойчив: при
небольшом расхождении $x_1$ и $x_2$ на новых данных прогноз «улетает».

**Решения:**
1. **Регуляризация** — штраф за величину коэффициентов;
2. **Отбор признаков** — убрать избыточные, шумные, сильно зависимые (тема [12](../12_feature_engineering_selection/README.md));
3. **Снижение размерности** (PCA, тема [11](../11_clustering_dim_reduction/README.md));
4. **Увеличение выборки** — сбор данных, синтетика, псевдообъекты: зависимости между столбцами могут исчезнуть.

## 3. Регуляризация: Ridge, LASSO, Elastic Net

**Смысл:** похожие объекты должны получать похожие ответы. Если объекты отличаются в $j$-м признаке на
$\delta$, ответы отличаются на $w_j\delta$ — значит, веса не должны быть огромными. Добавляем к
функции потерь штраф:

| Метод | Функционал | Особенности |
|---|---|---|
| **Ridge** (L2, Тихонова) | $\lVert Xw - y\rVert^2 + \lambda\lVert w\rVert_2^2$ | решение $w = (X^\top X + \lambda I)^{-1}X^\top y$ всегда существует; веса уменьшаются, но не зануляются |
| **LASSO** (L1) | $\lVert Xw - y\rVert^2 + \lambda\lVert w\rVert_1$ | **зануляет** веса → автоматический отбор признаков; нет аналитического решения |
| **Elastic Net** | $\lVert Xw - y\rVert^2 + \lambda_1\lVert w\rVert_1 + \lambda_2\lVert w\rVert_2^2$ | отбор + устойчивость при коррелированных признаках |

- $\lambda = 0$ — классическое решение OLS; $\lambda \to \infty$ — веса → 0, сильная регуляризация.
- $\lambda$ подбирают на **скользящем контроле** (`RidgeCV`, `LassoCV`, `GridSearchCV`).
- Формы **Иванова** ($\min$ ошибки при $\|w\| \le t$) и **Тихонова** (штраф в функционале) эквивалентны;
  Тихонова удобнее — безусловная оптимизация.
- **Свободный член $w_0$ не регуляризуют**: он отвечает за средний уровень таргета, а не за сложность
  ([почему](deep.md#4-lasso-l1-почему-зануляет-веса)).

**Почему L1 даёт разреженность** (геометрия): линии уровня ошибки чаще касаются «ромба» $\|w\|_1 \le t$
в вершине, где часть координат равна нулю; $L_1$ ближе к $L_0$-«норме» (числу ненулевых весов), чем $L_2$.
Аналитически Lasso — это **мягкий порог** $\operatorname{sign}(z)(|z| - \lambda)_+$ ([вывод](deep.md#4-lasso-l1-почему-зануляет-веса)).

**Нормировка обязательна**: регуляризация не инвариантна к умножению признака на число
(в отличие от обычной линейной регрессии).

| Скейлер | Преобразование | Когда |
|---|---|---|
| `StandardScaler` | $(x - \mu)/\sigma$ | по умолчанию |
| `MinMaxScaler` | $(x - \min)/(\max - \min)$ | нужен диапазон $[0, 1]$; чувствителен к выбросам |
| `RobustScaler` | $(x - \text{медиана})/\text{IQR}$ | есть выбросы |

```python
from sklearn.linear_model import Ridge, Lasso, ElasticNet, RidgeCV
Ridge(alpha=1.0, fit_intercept=True, solver="auto", positive=False)   # solver: 'svd','cholesky','lsqr','sag','saga','lbfgs'
Lasso(alpha=0.1)
ElasticNet(alpha=0.1, l1_ratio=0.5)        # l1_ratio — доля L1 в штрафе
RidgeCV(alphas=np.logspace(-3, 3, 13))     # подбор alpha на CV
```

## 4. Градиентный спуск для линейной регрессии

$$
\nabla_w Q = \frac{2}{\ell}X^\top(Xw - y), \qquad w^{(t+1)} = w^{(t)} - \eta\,\nabla_w Q\big(w^{(t)}\big).
$$

- **GD** — градиент по всей выборке: стабильно, но каждый шаг $O(\ell d)$.
- **SGD** — по одному случайному объекту: $w \leftarrow w - \eta\cdot 2(\langle w, x_i\rangle - y_i)x_i$.
  Быстро, можно учиться **онлайн**, но траектория шумная; темп сходимости смотрят по графику ошибки.
- **Mini-batch** — компромисс (стандарт в нейросетях).
- Шаг $\eta$ слишком большой → расходимость; слишком маленький → медленно. Масштабирование признаков
  ускоряет сходимость ([почему](deep.md#5-градиентный-спуск-и-sgd)).

```python
import numpy as np

def fit_gd(X, y, lr=0.1, n_iter=1000, l2=0.0):
    X = np.c_[np.ones(len(X)), X]                       # фиктивный признак для w0
    w = np.zeros(X.shape[1])
    for _ in range(n_iter):
        grad = 2 / len(X) * X.T @ (X @ w - y)
        grad[1:] += 2 * l2 * w[1:]                      # L2 без свободного члена
        w -= lr * grad
    return w
```

## 5. Устойчивость к выбросам и интерпретация

**Выбросы** сильно тянут МНК (квадратичный штраф). Что делать:
- чистить данные (удалять выбросы);
- **устойчивая (робастная) регрессия** — по-разному штрафовать наблюдения: `HuberRegressor`, `RANSACRegressor`,
  `TheilSenRegressor`, `QuantileRegressor` (см. функции потерь в теме [01](../01_intro_regression_metrics/README.md)).

**Эконометрика:** линейная регрессия — основной инструмент, когда нужно не предсказать $y$, а **оценить
влияние** фактора при прочих равных. Коэффициент $\beta_j$ — изменение $y$ при росте $x_j$ на единицу
при фиксированных остальных. Значимость — t-тесты, p-value, доверительные интервалы.
Пример: $\text{earnings} = \beta_0 + \beta_1\,\text{education} + \beta_2\,\text{experience} + \beta_3\,\text{gender} + \varepsilon$
(«+1 год обучения ≈ +1.5 тыс. ₽»). Исследование *Moved to Opportunity* (влияние переезда из гетто на
судьбу детей) сделано на линейной регрессии.

```python
import statsmodels.api as sm
model = sm.OLS(y, sm.add_constant(X)).fit()
print(model.summary())      # коэффициенты, SE, t, p-value, R², AIC/BIC
```

> Осторожно: интерпретировать веса можно только при отсутствии мультиколлинеарности и при сравнимых
> масштабах признаков; корреляция ≠ причинность.

## 6. Предобработка признаков для линейных моделей

| Преобразование | Зачем | Как |
|---|---|---|
| **One-Hot Encoding** | категории → бинарные признаки; простая интерпретация | `OneHotEncoder(handle_unknown="ignore")`; одну категорию можно выкинуть (`drop="first"`), чтобы избежать точной коллинеарности со свободным членом |
| **Label Encoding** | категория → целое число | только если у категорий есть **порядок**, иначе портит линейную модель |
| **Target Encoding** | очень много категорий (OHE раздует размерность) | среднее таргета по категории; **только на кросс-валидации** (out-of-fold), иначе утечка |
| **Полиномы признаков** | нелинейные зависимости | `PolynomialFeatures(degree=2, include_bias=False)`; не перебарщивать — переобучение |
| **Бинаризация / дискретизация** | «точки перелома» — разные тренды до и после порога | `KBinsDiscretizer`, ручные пороги → кусочно-линейная модель |
| **Преобразование таргета** | таргет не линеаризуется (скошенный, мультипликативный) | $\log(1+y)$, $\sqrt[n]{y}$, Бокс–Кокс, Йео–Джонсон; `TransformedTargetRegressor` |

Из ДЗ (Ames Housing): лог-преобразование таргета подняло $R^2$ линейной регрессии с 0.874 до 0.916,
а дереву помогло меньше (0.803 → 0.842) — дереву важен лишь порядок, а линейной модели — форма
распределения ([почему](deep.md#9-преобразование-целевой-переменной)).

```python
from sklearn.compose import ColumnTransformer, TransformedTargetRegressor
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import OneHotEncoder, StandardScaler, PolynomialFeatures
from sklearn.linear_model import Ridge

pre = ColumnTransformer([
    ("num", Pipeline([("poly", PolynomialFeatures(2, include_bias=False)),
                      ("scale", StandardScaler())]), num_cols),
    ("cat", OneHotEncoder(handle_unknown="ignore"), cat_cols),
])
model = TransformedTargetRegressor(
    regressor=Pipeline([("pre", pre), ("ridge", Ridge(alpha=1.0))]),
    func=np.log1p, inverse_func=np.expm1)          # обучение на log1p(y) = оптимизация RMSLE
```

### Линейные модели для временных рядов

Пройдём окном по ряду: признаки — $n$ прошлых значений $(y_{t-n}, \dots, y_{t-1})$, таргет — $y_t$.
Получаем авторегрессию — линейную модель на лагах. Пример задач: прогноз спроса (покупки, просмотры,
корзины за $k$ дней, дни без покупок, изменение цены, наличие акции), раскупаемости, дебита нефти.

## 7. Логистическая регрессия

Линейная модель для **классификации**: линейно моделируется **логарифм шансов**, вероятность — через сигмоиду:

$$
P(y = 1 \mid x) = \sigma(\langle w, x\rangle + w_0) = \frac{1}{1 + e^{-(\langle w, x\rangle + w_0)}} .
$$

- Обучение — минимизация **log loss** (= максимум правдоподобия Бернулли); задача выпуклая, но
  аналитического решения нет → градиентные методы (L-BFGS, Ньютон, SGD).
- Градиент: $\nabla_w Q = \frac{1}{\ell}X^\top(\sigma(Xw) - y)$ — «признаки × (прогноз − ответ)».
- Разделяющая граница $\langle w, x\rangle + w_0 = 0$ — **гиперплоскость** (при пороге 0.5).
- Интерпретация: $e^{w_j}$ — во сколько раз растут **шансы** класса 1 при росте $x^j$ на 1.
- Многоклассовая версия — **softmax-регрессия** (multinomial).
- На линейно разделимых данных без регуляризации веса уходят в бесконечность → в sklearn по умолчанию
  L2 с `C=1.0` ($C = 1/\lambda$, **меньше C — сильнее регуляризация**).

Реализация с нуля (по мотивам ДЗ «Логистическая регрессия и SVM»):

```python
class LogReg:
    def __init__(self, lr=0.1, n_iter=1000):
        self.lr, self.n_iter = lr, n_iter

    @staticmethod
    def _sigmoid(z):
        return 1 / (1 + np.exp(-np.clip(z, -500, 500)))

    def fit(self, X, y):
        n, d = X.shape
        self.w, self.b, self.losses = np.zeros(d), 0.0, []
        for _ in range(self.n_iter):
            p = self._sigmoid(X @ self.w + self.b)
            p_ = np.clip(p, 1e-15, 1 - 1e-15)
            self.losses.append(-np.mean(y * np.log(p_) + (1 - y) * np.log(1 - p_)))
            self.w -= self.lr * X.T @ (p - y) / n            # полностью векторизованно
            self.b -= self.lr * np.mean(p - y)
        return self

    def predict_proba(self, X):
        p = self._sigmoid(X @ self.w + self.b)
        return np.c_[1 - p, p]

    def predict(self, X, threshold=0.5):
        return (self.predict_proba(X)[:, 1] >= threshold).astype(int)
```

## 8. SVM (метод опорных векторов)

**Идея:** среди всех разделяющих гиперплоскостей выбрать ту, что **максимизирует зазор** (margin) —
расстояние до ближайших объектов классов. Ширина полосы $= 2/\|w\|$.

**Soft-margin SVM** = **hinge loss** + L2-регуляризация ([вывод](deep.md#7-svm)):

$$
\sum_i \max\big(0,\; 1 - y_i(\langle w, x_i\rangle + b)\big) + \frac{1}{2C}\|w\|^2 \to \min_{w, b}, \qquad y_i \in \lbrace -1, +1\rbrace .
$$

- **Опорные векторы** — объекты на границе полосы или нарушители; решение зависит только от них.
- **$C$** — штраф за нарушения: большое $C$ → узкий зазор, меньше ошибок на обучении (переобучение);
  маленькое → широкий зазор, сильнее регуляризация.
- **Kernel trick**: в двойственной задаче данные входят через $\langle x_i, x_j\rangle$; замена на ядро
  $K(x_i, x_j)$ даёт **нелинейную** границу. RBF: $K = e^{-\gamma\|x - x'\|^2}$ — $\gamma$ задаёт «радиус влияния»
  объекта (большое $\gamma$ → переобучение).
- SVM не выдаёт вероятности — нужна **калибровка** (Платт).

```python
from sklearn.svm import LinearSVC, SVC
LinearSVC(C=1.0)                                   # линейный, быстрый, для больших данных
SVC(kernel="rbf", C=1.0, gamma="scale", probability=True)   # ядровой; probability=True → Платт внутри
```

| | Логистическая регрессия | SVM |
|---|---|---|
| Loss | log loss $\ln(1 + e^{-M})$ | hinge $\max(0, 1 - M)$ |
| Вероятности | да (обычно хорошо откалиброваны) | нет, нужна калибровка |
| Влияние объектов | все объекты | только опорные векторы |
| Нелинейность | через признаки | через ядра |
| Масштабирование | желательно | **обязательно** |

## 9. Калибровка вероятностей

Модель **откалибрована**, если среди объектов с прогнозом 0.8 положительных действительно ≈ 80%.
Нужна, когда вероятность используется как число (ожидаемая прибыль, ставки, риск), а не только для ранжирования.

- **Метод Платта** — поверх скоров обучаем одномерную логрег $\sigma(As + B)$ на отложенной выборке.
- **Изотоническая регрессия** — монотонная кусочно-постоянная функция; гибче, но нужно больше данных.
- Диагностика — **калибровочная кривая** и **Brier score** $\frac{1}{\ell}\sum (p_i - y_i)^2$.
- Калибровка монотонна и **не меняет ROC-AUC**.

```python
from sklearn.calibration import CalibratedClassifierCV, CalibrationDisplay
cal = CalibratedClassifierCV(SVC(), method="sigmoid", cv=5).fit(X_train, y_train)   # 'isotonic'
CalibrationDisplay.from_estimator(cal, X_test, y_test, n_bins=10)
```

## 10. Плюсы и минусы линейных моделей

| Плюсы | Минусы |
|---|---|
| быстрые, надёжные, популярные | линейная гипотеза редко верна |
| интерпретируемость (веса = влияние признаков) | теория опирается на нормальность ошибок |
| интерполяция **и экстраполяция** | страдают от выбросов |
| нелинейность через генерацию признаков | нужны однородные признаки в одной шкале |
| глобальный минимум (выпуклая задача) | коррелированные признаки → нужна регуляризация / отбор / PCA |
| асимптотически нормальные коэффициенты → проверка гипотез | |

## Типичные ошибки

- Регуляризация без масштабирования признаков.
- `LabelEncoder` для неупорядоченных категорий в линейной модели.
- Target encoding без out-of-fold схемы (утечка таргета).
- Интерпретация весов при сильной мультиколлинеарности.
- Отрицательные прогнозы для неотрицательного таргета (калории, цены) — нужна постобработка
  (`np.clip`) или обучение на $\log(1+y)$.
- Забыть, что `C` в `LogisticRegression`/`SVC` — **обратная** сила регуляризации.
