# 11. Кластеризация и снижение размерности

[Шпаргалка (ноутбук)](../../cheatsheet.ipynb) · [Оглавление курса](../../README.md)

**Суть.** Обучение без учителя. **Снижение размерности** переводит $d$ признаков в $k<d$, сохраняя структуру:
PCA — линейно, по максимуму дисперсии; t-SNE / UMAP / Isomap — нелинейно, для визуализации.
**Кластеризация** группирует похожие объекты: K-means (центры, выпуклые кластеры), иерархическая (дендрограмма),
DBSCAN (плотность, любая форма, шум). Качество — силуэт, инерция; при наличии разметки — ARI, BCubed.

| Термин | Определение |
|---|---|
| Главная компонента | собственный вектор ковариационной матрицы; дисперсия вдоль неё = собственное значение |
| Explained variance ratio | доля дисперсии, сохранённая первыми $k$ компонентами |
| Perplexity (t-SNE) | эффективное число соседей; 5–50 |
| Инерция (WCSS) | $\sum_k\sum_{x\in C_k}\lVert x-\mu_k\rVert^2$; всегда падает с ростом $K$ |
| k-means++ | умная инициализация центров ∝ $D(x)^2$ |
| Linkage | single / complete / average / ward — как мерить расстояние между кластерами |
| `eps`, `min_samples` | радиус окрестности и минимум соседей для ядровой точки DBSCAN |
| Силуэт | $s=\frac{b-a}{\max(a,b)}\in[-1,1]$ |

$$
\max_{\lVert w\rVert=1}w^\top Sw\;\Rightarrow\;Sw=\lambda w,\qquad
J_{\text{K-means}}=\sum_{k}\sum_{x_i\in C_k}\lVert x_i-\mu_k\rVert^2,\qquad
\Delta_{\text{Ward}}=\frac{n_An_B}{n_A+n_B}\lVert\mu_A-\mu_B\rVert^2
$$

**Часть A. Снижение размерности**

<details>
<summary><b>Снижение размерности</b></summary>

**Общий смысл:** перевести $d$ признаков в $k < d$ так, чтобы информация о различиях и зависимостях между
объектами сохранилась как можно лучше. Применения:
- визуализация: $d \to 2$ (реже 3);
- ускорение обучения моделей;
- повышение качества (меньше шума и мультиколлинеарности, тема [06](../06_bias_variance/README.md)).

</details>

<details>
<summary><b>A.1. PCA — метод главных компонент</b></summary>

**Идея:** при проекции в $k$-мерное пространство дисперсия вдоль каждой новой оси должна быть максимальной —
чтобы объекты оставались различимыми (плохой пример: две разные точки 2D проецируются в одну точку 1D).
Бонус: при максимальном разбросе проекций **сумма квадратов длин перпендикуляров** до подпространства
минимальна — это строгий факт (оба вывода — см. раздел «6. PCA: два эквивалентных вывода»).

- **Главные компоненты** — направления новых осей = собственные векторы ковариационной матрицы $S$;
  дисперсия вдоль компоненты = соответствующее собственное значение.
- **Объяснённая дисперсия** (`explained_variance_ratio_`): по накопленной кривой выбирают $k$ (например, ≥ 95%).
- **Обратное преобразование** (`inverse_transform`) — аппроксимация объекта $k$ компонентами. «Eigenfaces» на
  Olivetti faces: 4096 пикселей → 150 компонент сохраняют > 96% дисперсии; храним $400\times150$ + $150$ векторов
  по 4096 вместо $400\times4096$ — сжатие более чем в 2.5 раза.

> **Важно.** **Перед PCA признаки нормируют** — иначе дисперсия определяется единицами измерения. Исключение —
> разреженные признаки вроде tf-idf, они уже «нормированы». Выбросы искажают компоненты — анализировать/удалять.

| Плюсы PCA | Минусы PCA |
|---|---|
| уменьшает переобучение в многомерных данных | ловит только **линейные** зависимости |
| убирает скоррелированность признаков (компоненты ортогональны) | новые признаки плохо интерпретируются |
| быстрый на больших данных, детерминированный | чувствителен к масштабу и выбросам |
| почти не требует настройки (кроме `n_components`) | |

</details>

<details>
<summary><b>A.2. t-SNE</b></summary>

**Идея:** сохранить не глобальную дисперсию, а **локальную** структуру: похожие (близкие) объекты должны остаться
близкими. Считаем вероятности близости пар в исходном и новом пространстве и минимизируем расхождение
(KL) между распределениями (формулы — см. раздел «7. t-SNE»).

- **`perplexity`** — сколько точек считать «соседями»; рекомендуемый диапазон **5–50**; визуализация сильно от него зависит.
- Плюсы: сохраняет локальную структуру и нелинейные зависимости.
- Минусы: долго (для больших $d$ сначала PCA до ~50 признаков); **не сохраняет форму кластеров и расстояния между
  ними**; новые признаки неинтерпретируемы; недетерминирован; **нет `transform`** — нельзя «обучить» и применить к новым данным.

</details>

<details>
<summary><b>A.3. UMAP</b></summary>

Появился в 2018: скорость, близкая к PCA, сохранение локальной структуры как у t-SNE + старается сохранить и
**глобальную**. Больше других подходит как предобработка для кластеризации.
Минусы: не в sklearn (`umap-learn`), может требовать много RAM, недетерминирован, много гиперпараметров
(`n_neighbors` — локальное vs глобальное, `min_dist` — плотность упаковки).

</details>

<details>
<summary><b>A.4. Isomap</b></summary>

Строим граф ближайших соседей, считаем кратчайшие пути (**геодезические** расстояния — «вдоль многообразия»),
затем применяем **MDS** (Multidimensional Scaling). Хорошо передаёт взаимное расположение, сохраняет и локальную,
и глобальную структуру, учитывает нелинейность. Минусы: небыстрый, есть параметры; желательно очистить от шума.

| Метод | Линейный | Сохраняет | Новые данные (`transform`) | Скорость | Детерминирован |
|---|---|---|---|---|---|
| PCA | да | глобальную дисперсию | да | очень быстро | да |
| t-SNE | нет | локальную структуру | **нет** | медленно | нет |
| UMAP | нет | локальную + частично глобальную | да | быстро | нет |
| Isomap | нет | геодезические расстояния | да | медленно | да |

```python
from sklearn.decomposition import PCA
from sklearn.manifold import TSNE, Isomap
from sklearn.preprocessing import StandardScaler
# from umap import UMAP

X_s = StandardScaler().fit_transform(X)
pca = PCA(n_components=0.95).fit(X_s)            # столько компонент, чтобы объяснить 95% дисперсии
pca.n_components_, pca.explained_variance_ratio_.cumsum()
X_tsne = TSNE(n_components=2, perplexity=30, random_state=0).fit_transform(X_s)
X_iso = Isomap(n_neighbors=10, n_components=2).fit_transform(X_s)
# X_umap = UMAP(n_neighbors=15, min_dist=0.1).fit_transform(X_s)
```

</details>

**Часть B. Кластеризация**

<details>
<summary><b>Кластеризация</b></summary>

**Кластеризация** — разбиение объектов на группы (кластеры) похожих объектов **без разметки**. Нет «правильного»
ответа: результат зависит от метрики, алгоритма и масштаба признаков (масштабировать обязательно, если признаки в
разных шкалах; в ДЗ с бинарными признаками «животных» масштабирование некритично).

</details>

<details>
<summary><b>B.1. K-means</b></summary>

1. Выбрать $K$ начальных центров.
2. Отнести каждый объект к ближайшему центру.
3. Пересчитать центры как средние объектов кластеров.
4. Повторять 2–3 до стабилизации.

Минимизирует **инерцию** $\sum_k\sum_{x_i\in C_k}\|x_i - \mu_k\|^2$; сходится к локальному минимуму (почему — см. раздел «1. K-means: функционал и алгоритм Ллойда»).

- **Число кластеров $K$** задаётся заранее: перебор + метрика качества (силуэт), **метод локтя** по `inertia_`,
  визуальная оценка на 2D-проекции (t-SNE/PCA/Isomap), знание предметной области.
- **Инициализация** сильно влияет на результат (семинар: 20 запусков с `init='random'` дают заметно разную
  инерцию). **k-means++** — следующий центр выбирается с вероятностью $\propto$ квадрату расстояния до ближайшего
  выбранного; результат стабильнее. Плюс `n_init` — несколько запусков, лучший по инерции.
- Находит выпуклые «шарообразные» кластеры похожего размера; плохо — «луны», кольца, разные плотности; чувствителен к выбросам.

</details>

<details>
<summary><b>B.2. Агломеративная (иерархическая) кластеризация</b></summary>

Начинаем с кластеров из одного объекта, на каждом шаге **сливаем два ближайших**. Результат — **дендрограмма**;
разрезая её на нужной высоте (`distance_threshold` / `n_clusters`, в plotly — `color_threshold`), получаем разбиение.

| `linkage` | Расстояние между кластерами | Поведение |
|---|---|---|
| `single` | между ближайшими точками | «цепочки», вытянутые кластеры, чувствителен к шуму |
| `complete` | между самыми далёкими | компактные кластеры |
| `average` | среднее по всем парам | компромисс |
| `ward` | прирост внутрикластерной дисперсии | сбалансированные кластеры (обычно лучший по умолчанию; в ДЗ «животные» — лучший) |

Плюс: видна **иерархия** (виды → классы животных). Минус: $O(\ell^2)$ памяти — для небольших данных.

</details>

<details>
<summary><b>B.3. DBSCAN</b></summary>

Кластеры — области **высокой плотности**; точки, у которых в радиусе `eps` меньше `min_samples` соседей и которые
не прилегают к плотным областям, — **шум** (метка −1).
- не нужно задавать число кластеров; находит кластеры **любой формы**; выделяет выбросы (тема [10](../10_anomaly_detection/README.md));
- плохо работает, если кластеры разной плотности (решение — **HDBSCAN**); чувствителен к `eps` и масштабу.

Практика из семинара: на данных об общепите Москвы (координаты) DBSCAN находит **торговые центры** — гипотеза: в ТЦ
самое плотное скопление точек с едой. В ДЗ — места с наилучшим покрытием городского Wi-Fi (точки продублированы
по числу точек подключения; подобрано `eps ≈ 0.0002` в градусах, `min_samples = 8` → кластеры у метро, вокзалов,
ТЦ, парков). Порядок `eps` зависит от единиц: в градусах широты/долготы 0.001 ≈ 70–110 м.

</details>

<details>
<summary><b>B.4. Другие методы</b></summary>

- **GaussianMixture** (EM) — мягкая кластеризация, эллиптические кластеры, выбор $K$ по BIC (EM — см. раздел «5. Смесь гауссиан и EM (мягкая кластеризация)»);
- **MeanShift** — поиск мод плотности; **Spectral clustering** — кластеризация по графу похожести (невыпуклые кластеры);
- **HDBSCAN** — иерархический DBSCAN для кластеров разной плотности.

</details>

<details>
<summary><b>B.5. Оценка качества кластеризации</b></summary>

| Тип | Метрика | Смысл |
|---|---|---|
| Внутренняя | **Инерция** (WCSS) | компактность; монотонно падает с ростом $K$ → «локоть» |
| Внутренняя | **Силуэт** $\frac{b - a}{\max(a, b)}$ | $a$ — среднее расстояние до своих, $b$ — до ближайшего чужого кластера; от −1 до 1, больше — лучше |
| Внутренняя | Davies–Bouldin / Calinski–Harabasz | меньше / больше — лучше |
| Внешняя (есть разметка) | ARI, NMI | согласие с эталоном с поправкой на случайность |
| Внешняя | **BCubed** precision/recall/F | поэлементные: «склеивание» классов / «разрезание» класса (формулы и код — см. раздел «3. Внешние метрики (есть эталонная разметка)») |

В ДЗ (Zoo, 7 классов) разные критерии дали разные $K$: визуально и по локтю — 6, по BCubed — 8, по иерархии (Ward) — 7.
**Кластеризация — исследовательский инструмент**, итоговое $K$ выбирают с учётом задачи.

</details>

```python
import numpy as np
from sklearn.cluster import KMeans, AgglomerativeClustering, DBSCAN
from sklearn.metrics import silhouette_score, adjusted_rand_score
from scipy.cluster.hierarchy import dendrogram, linkage

# K-means: выбор K по силуэту и инерции
for k in range(2, 11):
    km = KMeans(n_clusters=k, init="k-means++", n_init=10, random_state=0).fit(X_s)
    print(k, round(km.inertia_, 1), round(silhouette_score(X_s, km.labels_), 3))

# Иерархическая
agg = AgglomerativeClustering(n_clusters=None, distance_threshold=0, linkage="ward").fit(X_s)
Z = linkage(X_s, method="ward")            # scipy: матрица слияний для dendrogram(Z)

# DBSCAN: eps по «локтю» расстояний до k-го соседа
from sklearn.neighbors import NearestNeighbors
k = 5
dist = np.sort(NearestNeighbors(n_neighbors=k).fit(X_s).kneighbors(X_s)[0][:, -1])   # смотрим излом графика
labels = DBSCAN(eps=0.5, min_samples=k).fit_predict(X_s)        # -1 — шум
```

<summary><b>Типичные ошибки</b></summary>

- Кластеризовать без масштабирования признаков разной природы.
- Интерпретировать расстояния между кластерами и размеры кластеров на карте t-SNE.
- Применять t-SNE как препроцессинг для модели (нет `transform`, результат нестабилен).
- Выбирать $K$ по минимуму инерции (она всегда убывает).
- Ждать от K-means невыпуклых кластеров.
- Подбирать `eps` DBSCAN без учёта единиц измерения (градусы vs метры).

**Математика и выводы**

<details>
<summary><b>1. K-means: функционал и алгоритм Ллойда</b></summary>

Ищем разбиение на $K$ кластеров $C_1, \dots, C_K$ и центры $\mu_1, \dots, \mu_K$, минимизируя **инерцию**
(внутрикластерную сумму квадратов, WCSS):

$$
J(C, \mu) = \sum_{k=1}^{K}\sum_{x_i \in C_k}\|x_i - \mu_k\|^2 .
$$

**Алгоритм Ллойда** чередует два шага:
1. **Присвоение:** при фиксированных $\mu$ каждый объект — в кластер ближайшего центра (минимизирует $J$ по $C$ поточечно);
2. **Обновление:** при фиксированных $C$ центр — среднее кластера (оптимальная константа под MSE, тема [01](../01_intro_regression_metrics/README.md)).

**Сходимость.** Каждый шаг не увеличивает $J$; разбиений конечное число, и одно разбиение не повторится при
строгом убывании ⇒ алгоритм останавливается за конечное число итераций. Но это **локальный** минимум:
глобальная задача NP-трудна даже при $K = 2$. Отсюда зависимость от инициализации и `n_init` (несколько запусков,
выбираем с минимальной инерцией).

**Геометрия.** Шаг присвоения разбивает пространство на **ячейки Вороного** центров — кластеры K-means выпуклы,
границы — гиперплоскости (как у ближайшего центроида, тема [03](../03_knn/README.md)).
Поэтому K-means плохо находит невыпуклые кластеры («луны», кольца) и кластеры разного размера/плотности.

**Вероятностная интерпретация.** K-means — предельный случай EM для смеси гауссиан с ковариациями $\sigma^2 I$ и
$\sigma \to 0$ (мягкие апостериорные вероятности превращаются в жёсткое присвоение к ближайшему центру).

**Инерция монотонно убывает с ростом $K$** (при $K = \ell$ она равна 0), поэтому её нельзя минимизировать по $K$
напрямую — используют «локоть» (точку, после которой убывание замедляется) или силуэт.

**k-means++**

Первый центр — случайный объект; каждый следующий выбирается с вероятностью, пропорциональной $D(x)^2$ —
квадрату расстояния до ближайшего уже выбранного центра. Теорема (Arthur & Vassilvitskii, 2007): ожидаемая инерция
после такой инициализации не более чем в $8(\ln K + 2)$ раз хуже оптимальной. На практике — заметно более
стабильный результат (семинар: разброс инерции по 20 запускам меньше, чем при `init='random'`).

**Мини-батч и сложность**

Одна итерация Ллойда — $O(\ell K d)$. MiniBatchKMeans обновляет центры по случайным подвыборкам — для больших данных.

</details>

<details>
<summary><b>2. Силуэт</b></summary>

Для объекта $i$ из кластера $C$: $a(i)$ — среднее расстояние до объектов своего кластера, $b(i)$ — минимальное по
другим кластерам среднее расстояние до объектов этого кластера. Тогда

$$
s(i) = \frac{b(i) - a(i)}{\max\big(a(i), b(i)\big)} \in [-1, 1], \qquad S = \frac{1}{\ell}\sum_i s(i) .
$$

$s \approx 1$ — объект близко к своим и далеко от чужих; $s \approx 0$ — на границе; $s < 0$ — скорее в чужом кластере.
Силуэт **не монотонен** по $K$ — его можно максимизировать. Сложность $O(\ell^2)$. Смещён в пользу выпуклых
кластеров (DBSCAN-кластеры сложной формы может оценить плохо).

**Davies–Bouldin**: среднее по кластерам $\max_{j\ne k}\frac{s_k + s_j}{d(\mu_k, \mu_j)}$ ($s_k$ — средний радиус) — чем меньше, тем лучше.
**Calinski–Harabasz**: отношение межкластерной дисперсии к внутрикластерной с поправками на $K$ и $\ell$ — чем больше, тем лучше.

</details>

<details>
<summary><b>3. Внешние метрики (есть эталонная разметка)</b></summary>

**ARI** (Adjusted Rand Index) — доля пар объектов, по которым кластеризация и разметка согласны («вместе/порознь»),
скорректированная на случайное согласие: 0 — как случайное разбиение, 1 — идеально.

**NMI** — взаимная информация разбиений, нормированная на их энтропии.

**BCubed** (из ДЗ) — поэлементные precision и recall. Для объекта $i$: $C(i)$ — его кластер, $L(i)$ — его истинный класс.

$$
\text{Precision} = \frac{1}{\ell}\sum_i\frac{|C(i) \cap L(i)|}{|C(i)|}, \qquad
\text{Recall} = \frac{1}{\ell}\sum_i\frac{|C(i) \cap L(i)|}{|L(i)|}, \qquad F = \frac{2PR}{P + R}.
$$

Precision штрафует «склеивание» разных классов в один кластер, Recall — «разрезание» класса по кластерам.
BCubed удовлетворяет набору интуитивных аксиом (однородность, полнота, «мешок мусора», малые кластеры),
которые нарушают многие другие внешние метрики (Amigó et al., 2009).

```python
import numpy as np
def bcubed(labels_true, labels_pred):
    labels_true, labels_pred = np.asarray(labels_true), np.asarray(labels_pred)
    same_c = labels_pred[:, None] == labels_pred[None, :]
    same_l = labels_true[:, None] == labels_true[None, :]
    both = (same_c & same_l).sum(1)
    p = np.mean(both / same_c.sum(1)); r = np.mean(both / same_l.sum(1))
    return p, r, 2 * p * r / (p + r)
```

</details>

<details>
<summary><b>4. Иерархическая кластеризация: связности и формула Ланса–Уильямса</b></summary>

Агломеративный алгоритм: каждый объект — отдельный кластер; на каждом шаге сливаем два **ближайших** кластера;
история слияний — **дендрограмма**. Разрез дендрограммы на высоте $h$ даёт разбиение.

| Связность (linkage) | $d(A, B)$ | Свойства |
|---|---|---|
| **single** | $\min_{a\in A, b\in B}\rho(a, b)$ | эквивалентна построению минимального остовного дерева; «цепочки», ловит вытянутые кластеры, чувствительна к шуму |
| **complete** | $\max\rho(a, b)$ | компактные кластеры примерно одного диаметра |
| **average** (UPGMA) | среднее $\rho(a, b)$ по всем парам | компромисс |
| **Ward** | прирост внутрикластерной суммы квадратов при слиянии | сбалансированные «шарообразные» кластеры, как у K-means |

**Критерий Уорда.** Прирост WCSS при слиянии $A$ и $B$ ($n_A, n_B$ — размеры, $\mu_A, \mu_B$ — центры):

$$
\Delta(A, B) = \sum_{x \in A\cup B}\|x - \mu_{A\cup B}\|^2 - \sum_{x\in A}\|x - \mu_A\|^2 - \sum_{x\in B}\|x - \mu_B\|^2 = \frac{n_A n_B}{n_A + n_B}\|\mu_A - \mu_B\|^2 .
$$

(Это то же выражение, что выигрыш сплита в дереве регрессии, тема [07](../07_decision_trees/README.md), только «наоборот».)

**Формула Ланса–Уильямса** позволяет пересчитывать расстояние от нового кластера $A\cup B$ до любого $C$ за $O(1)$:

$$
d(A\cup B, C) = \alpha_A d(A, C) + \alpha_B d(B, C) + \beta d(A, B) + \gamma|d(A, C) - d(B, C)| ,
$$

для single: $\alpha = \frac12, \beta = 0, \gamma = -\frac12$ (даёт $\min$); для complete: $\gamma = +\frac12$ (даёт $\max$); для Уорда (с
квадратами расстояний) $\alpha_A = \frac{n_A + n_C}{n_A + n_B + n_C}$, $\beta = -\frac{n_C}{n_A + n_B + n_C}$, $\gamma = 0$.
Сложность наивной реализации — $O(\ell^2)$ памяти и $O(\ell^2\log\ell)$–$O(\ell^3)$ времени — только для небольших данных.

</details>

<summary><b>5. Смесь гауссиан и EM (мягкая кластеризация)</b></summary>

$p(x) = \sum_k \pi_k\,\mathcal{N}(x \mid \mu_k, \Sigma_k)$. EM-алгоритм:
- **E-шаг:** $\gamma_{ik} = \dfrac{\pi_k\mathcal{N}(x_i\mid\mu_k,\Sigma_k)}{\sum_j\pi_j\mathcal{N}(x_i\mid\mu_j,\Sigma_j)}$ — вероятность принадлежности;
- **M-шаг:** $N_k = \sum_i\gamma_{ik}$, $\pi_k = N_k/\ell$, $\mu_k = \frac{1}{N_k}\sum_i\gamma_{ik}x_i$, $\Sigma_k = \frac{1}{N_k}\sum_i\gamma_{ik}(x_i - \mu_k)(x_i - \mu_k)^\top$.

Каждая итерация не уменьшает правдоподобие. В отличие от K-means — эллиптические кластеры разного размера и
вероятности принадлежности. Число компонент выбирают по BIC.

</details>

<details>
<summary><b>6. PCA: два эквивалентных вывода</b></summary>

Данные центрированы, $S = \frac{1}{\ell}X^\top X$ — ковариационная матрица.

**(а) Максимум дисперсии проекции.** Ищем единичное направление $w$ с максимальной дисперсией проекций $Xw$:

$$
\max_{w}\; w^\top S w \quad\text{s.t.}\quad \|w\| = 1 .
$$

Лагранжиан $w^\top S w - \lambda(w^\top w - 1)$, производная: $Sw = \lambda w$ — $w$ **собственный вектор** $S$, а значение функционала
$w^\top S w = \lambda$ — собственное значение. Максимум — у наибольшего собственного значения. Следующие компоненты —
следующие собственные векторы (ортогональные предыдущим). Дисперсия вдоль $j$-й компоненты равна $\lambda_j$
(«Pro tip» семинара).

**(б) Минимум ошибки реконструкции.** Проецируем на подпространство с ортонормированным базисом $W \in \mathbb{R}^{d\times k}$:
$\hat x = WW^\top x$. Тогда $\|x\|^2 = \|W^\top x\|^2 + \|x - \hat x\|^2$ (Пифагор), значит

$$
\min_W\sum_i\|x_i - WW^\top x_i\|^2 \iff \max_W\sum_i\|W^\top x_i\|^2 = \max_W \ell\operatorname{tr}(W^\top S W),
$$

что опять решается первыми $k$ собственными векторами. Это и есть наблюдение семинара: «когда точки на линии
распределены максимально широко, сумма длин перпендикуляров минимальна».

**Через SVD.** $X = U\Sigma V^\top$ ⇒ $S = \frac{1}{\ell}V\Sigma^2V^\top$: главные компоненты — столбцы $V$, $\lambda_j = \sigma_j^2/\ell$,
координаты объектов в новом пространстве — $U\Sigma$. sklearn считает PCA именно через SVD (численно устойчивее).

**Доля объяснённой дисперсии:** $\frac{\lambda_1 + \dots + \lambda_k}{\sum_j\lambda_j}$; $k$ выбирают по порогу (например, 95%) или
«локтю». Ошибка реконструкции равна сумме отброшенных $\lambda_j$ (теорема Эккарта–Янга: это наилучшее
приближение ранга $k$).

**Почему нормировать.** Дисперсия зависит от единиц измерения: признак «доход в рублях» займёт первую компоненту
только из-за масштаба. PCA на стандартизированных признаках = PCA корреляционной матрицы.

</details>

<details>
<summary><b>7. t-SNE</b></summary>

**Сходства в исходном пространстве** — условные вероятности с гауссовским ядром:

$$
p_{j\mid i} = \frac{\exp(-\|x_i - x_j\|^2/2\sigma_i^2)}{\sum_{k\ne i}\exp(-\|x_i - x_k\|^2/2\sigma_i^2)},
\qquad p_{ij} = \frac{p_{j\mid i} + p_{i\mid j}}{2\ell} .
$$

$\sigma_i$ подбирается бинарным поиском так, чтобы **перплексия** $2^{H(P_i)}$ (где $H(P_i) = -\sum_j p_{j\mid i}\log_2 p_{j\mid i}$) равнялась
заданной — это «эффективное число соседей». Поэтому в плотных областях $\sigma_i$ меньше.

**Сходства в низкоразмерном пространстве** — распределение Стьюдента с одной степенью свободы:

$$
q_{ij} = \frac{(1 + \|y_i - y_j\|^2)^{-1}}{\sum_{k\ne l}(1 + \|y_k - y_l\|^2)^{-1}} .
$$

**Функционал** — $\mathrm{KL}(P\|Q) = \sum_{i\ne j}p_{ij}\log\frac{p_{ij}}{q_{ij}}$, минимизируется градиентным спуском:

$$
\frac{\partial\,\mathrm{KL}}{\partial y_i} = 4\sum_j (p_{ij} - q_{ij})(y_i - y_j)\big(1 + \|y_i - y_j\|^2\big)^{-1} .
$$

Пары с $p_{ij} > q_{ij}$ притягиваются, с $p_{ij} < q_{ij}$ — отталкиваются.

**Зачем распределение Стьюдента (проблема скученности).** В высокой размерности у точки много «средне далёких»
соседей, а в 2D для них не хватает места. Тяжёлые хвосты $t$-распределения позволяют умеренно далёким точкам
оказаться **далеко** на карте при той же $q_{ij}$ — кластеры разделяются. Следствия (минусы со слайда): размеры
кластеров и расстояния **между** кластерами на карте t-SNE не имеют смысла; результат недетерминирован; нет
`transform` для новых точек. Асимметрия KL: штраф за то, что близкие точки оказались далеко ($p$ большое, $q$ малое),
велик, а обратное почти не штрафуется — t-SNE сохраняет **локальную** структуру.

</details>

<details>
<summary><b>8. UMAP</b></summary>

Строит взвешенный граф $k$ ближайших соседей (`n_neighbors`) с локально адаптивными расстояниями (нечёткое
симплициальное множество), затем ищет низкоразмерное вложение, минимизируя **кросс-энтропию** между весами рёбер
графа в исходном и новом пространстве; притяжение по рёбрам и отталкивание через negative sampling. В отличие от
KL в t-SNE, кросс-энтропия штрафует и за то, что далёкие точки оказались близко → лучше сохраняется глобальная
структура. `n_neighbors` — баланс локальное/глобальное, `min_dist` — насколько плотно упаковывать точки. Есть `transform`.

</details>

<details>
<summary><b>9. Isomap и классический MDS</b></summary>

1. Граф $k$ ближайших соседей с длинами рёбер = евклидовым расстояниям.
2. **Геодезические расстояния** $D_{ij}$ — кратчайшие пути в графе (Дейкстра / Флойд) — приближают расстояния
   вдоль многообразия («по поверхности», а не напрямую через пустоту).
3. **Классический MDS:** двойное центрирование $B = -\frac12 J D^{(2)} J$, $J = I - \frac{1}{\ell}\mathbf{1}\mathbf{1}^\top$, $D^{(2)}$ — матрица
   квадратов расстояний. Если расстояния евклидовы, $B = YY^\top$ — матрица Грама; берём $Y = V_k\Lambda_k^{1/2}$ по $k$
   наибольшим собственным значениям $B$.

Классический MDS на евклидовых расстояниях совпадает с PCA. Isomap «разворачивает» многообразие (например,
«швейцарский рулет»), но чувствителен к выбору $k$ («короткие замыкания» через пустоты при большом $k$) и
шуму.

</details>

- PCA = максимум дисперсии проекции = минимум ошибки реконструкции; через SVD $X=U\Sigma V^\top$: компоненты — столбцы $V$.

<summary><b>Примеры кода (с результатами запуска)</b></summary>

Запустить их можно в ноутбуке [`cheatsheet.ipynb`](../../cheatsheet.ipynb).

```python
import numpy as np
from sklearn.datasets import load_digits, make_moons
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans, AgglomerativeClustering, DBSCAN
from sklearn.metrics import silhouette_score, adjusted_rand_score

X, y = load_digits(return_X_y=True)
X_s = StandardScaler().fit_transform(X)
pca = PCA().fit(X_s)
cum = pca.explained_variance_ratio_.cumsum()
print(f"digits: 64 признака; для 90% дисперсии нужно {np.argmax(cum >= 0.9) + 1} компонент; 2 компоненты дают {cum[1]:.1%}")
X_20 = PCA(n_components=20).fit_transform(X_s)
for k in (5, 10, 15):
    km = KMeans(n_clusters=k, n_init=10, random_state=0).fit(X_20)
    print(f"K={k:2d}: inertia={km.inertia_:9.0f}  silhouette={silhouette_score(X_20, km.labels_):.3f}  "
          f"ARI с цифрами={adjusted_rand_score(y, km.labels_):.3f}")
```

Результат запуска:

```text
K=10: inertia=    47520  silhouette=0.198  ARI с цифрами=0.549
K=15: inertia=    38966  silhouette=0.201  ARI с цифрами=0.578
```

```python
# Невыпуклые кластеры: K-means и Ward «режут» луны пополам, DBSCAN и single linkage — находят
Xm, ym = make_moons(n_samples=500, noise=0.06, random_state=0)
for name, model in [("KMeans", KMeans(2, n_init=10, random_state=0)),
                    ("Agglomerative ward", AgglomerativeClustering(2, linkage="ward")),
                    ("Agglomerative single", AgglomerativeClustering(2, linkage="single")),
                    ("DBSCAN", DBSCAN(eps=0.2, min_samples=5))]:
    labels = model.fit_predict(Xm)
    print(f"{name:22} ARI={adjusted_rand_score(ym, labels):.3f}  кластеров={len(set(labels) - {-1})}")
```
