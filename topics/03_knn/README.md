# 03. Метрические алгоритмы и kNN

[Шпаргалка (ноутбук)](../../cheatsheet.ipynb) · [Оглавление курса](../../README.md)

**Суть.** Новый объект получает ответ по **похожим** объектам выборки (гипотеза компактности).
**kNN**: найти $k$ ближайших соседей и проголосовать (классификация) или усреднить (регрессия).
Модель = сама выборка (непараметрический, «ленивый» метод). Всё решают **метрика**, **масштаб признаков** и $k$.

| Термин | Определение |
|---|---|
| Метрика | функция расстояния: $\rho\ge0$, $\rho(x,y)=0\iff x=y$, симметрия, неравенство треугольника |
| $L_1$ / $L_2$ / $L_\infty$ | манхэттенское / евклидово / Чебышёва — частные случаи Минковского $L_p$ |
| Косинусное расстояние | $1-\cos(x,y)$ — сравнивает направления (тексты, эмбеддинги) |
| Ближайший центроид | класс с ближайшим средним объектом; по сути линейный классификатор |
| Взвешенный kNN | ближние соседи весят больше: $w=1/\rho$ или ядро $K(\rho/h)$ |
| Надарая–Ватсон | ядерно-взвешенное среднее по **всем** точкам; $h$ — ширина окна |
| Проклятие размерности | в высокой размерности все точки почти равноудалены |
| ANN | приближённый поиск соседей: KD-tree, LSH, HNSW |

**Ключевые формулы**

$$
\rho_p(x,y)=\Big(\sum_j|x^j-y^j|^p\Big)^{1/p},\qquad
a_{\text{clf}}(u)=\arg\max_y\sum_{i=1}^{k}w_i[y_u^{(i)}=y],\qquad
a_{\text{NW}}(u)=\frac{\sum_i y_i K\big(\rho(u,x_i)/h\big)}{\sum_i K\big(\rho(u,x_i)/h\big)}
$$

<details>
<summary><b>1. Идея</b></summary>

Чтобы определить свойства нового объекта, сравниваем его с теми, что уже видели.
**Метрические алгоритмы** находят в выборке наиболее близкие объекты и переносят их свойства на новый.
Основа — **гипотеза компактности**: близкие объекты, как правило, принадлежат одному классу / имеют близкие ответы.

Два основных подхода:
1. **Ближайший центроид** (nearest centroid) — сравниваем со «средним объектом» каждого класса;
2. **k ближайших соседей** (kNN, k-nearest neighbors) — сравниваем с самими объектами выборки.

Метрические алгоритмы — **непараметрические**: не предполагают форму зависимости, «модель» — это сама выборка
(lazy learning: обучение = запоминание).

</details>

<details>
<summary><b>2. Расстояние</b></summary>

**Расстояние (метрика)** $\rho(x, y)$ измеряет близость объектов в признаковом пространстве и удовлетворяет:
неотрицательности, тождеству неразличимых ($\rho = 0 \iff x = y$), симметричности, неравенству треугольника.

| Расстояние | Формула | Когда |
|---|---|---|
| **Минковского** $L_p$ | $\big(\sum_j \lvert x^j - y^j\rvert^p\big)^{1/p}$ | общее семейство |
| **Манхэттенское** $L_1$ | $\sum_j \lvert x^j - y^j\rvert$ | выбросы, высокая размерность; «движение по городским кварталам» |
| **Евклидово** $L_2$ | $\sqrt{\sum_j (x^j - y^j)^2}$ | по умолчанию для числовых признаков |
| **Чебышёва** $L_\infty$ | $\max_j \lvert x^j - y^j\rvert$ | максимальное отличие по одной координате |
| **Косинусное** | $1 - \frac{\langle x, y\rangle}{\lVert x\rVert\,\lVert y\rVert}$ | важны пропорции, а не абсолютные значения: тексты, эмбеддинги, предпочтения пользователей |
| **Хэмминга** | число несовпадающих позиций | категориальные признаки, строки одной длины |
| Махаланобиса | $\sqrt{(x-y)^\top\Sigma^{-1}(x-y)}$ | коррелированные признаки разного масштаба |
| Жаккара | $1 - \frac{\lvert A\cap B\rvert}{\lvert A\cup B\rvert}$ | множества (корзины, теги) |
| Левенштейна | число правок строки | опечатки, строки разной длины |
| DTW | расстояние с выравниванием по времени | временные ряды |
| Canberra | $\sum_j \frac{\lvert x^j - y^j\rvert}{\lvert x^j\rvert + \lvert y^j\rvert}$ | признаки около нуля |

> **Важно.** Расстояние Минковского **чувствительно к масштабу признаков**: признак «доход в рублях» задавит
> «возраст в годах». **Масштабирование обязательно** (`StandardScaler`, `MinMaxScaler`).

Метрика подбирается эмпирически, но вдумчиво — по типу данных (см. таблицу) и на кросс-валидации.

</details>

<summary><b>3. Метод ближайшего центроида</b></summary>

1. Для каждого класса считаем **центроид** — среднее его объектов: $\mu_k = \frac{1}{n_k}\sum_{i:\,y_i = k} x_i$.
2. Новый объект относим к классу, чей центроид ближе: $a(x) = \arg\min_k \rho(x, \mu_k)$.

| Плюсы | Минусы |
|---|---|
| храним только $K$ центроидов, их можно адаптивно обновлять | годится только для (почти) линейно разделимых классов |
| быстрое предсказание — $K$ расстояний | плохо работает со сложной структурой и разным разбросом классов |
| крошечная модель | |

С евклидовой метрикой это **линейный классификатор** (вывод (см. раздел «2. Ближайший центроид — это линейный классификатор»)).

```python
from sklearn.neighbors import NearestCentroid
NearestCentroid(metric="euclidean").fit(X_train, y_train).predict(X_test)
```

<details>
<summary><b>4. kNN</b></summary>

**4.1. Алгоритм**

Для нового объекта $u$:
1. Считаем расстояния до всех объектов выборки и упорядочиваем: $\rho(u, x_u^{(1)}) \le \rho(u, x_u^{(2)}) \le \dots$
2. Окрестность $N_k(u)$ — $k$ ближайших соседей (окрестность фиксированного радиуса подбирать неудобно — плотность данных разная).
3. Предсказание:
   - **классификация** — голосование большинства (majority vote): $a(u) = \arg\max_y \sum_{i=1}^{k}[y_u^{(i)} = y]$;
   - **регрессия** — среднее ответов соседей: $a(u) = \frac{1}{k}\sum_{i=1}^{k} y_u^{(i)}$ (можно медиану — устойчивее к выбросам).

**4.2. Гиперпараметр $k$**

$k$ отвечает за **локальность** алгоритма. Аналитически не выбирается — только **кросс-валидацией**.

| Маленький $k$ | Большой $k$ |
|---|---|
| чувствительность к шуму | устойчивость к шуму |
| сложная граница, подстраивается под каждый объект | гладкая граница |
| риск **переобучения** | потеря локальных паттернов, риск **недообучения** |

$k = 1$ даёт нулевую ошибку на обучении (каждый объект — сам себе сосед) — это ничего не говорит о качестве.
В бинарной классификации $k$ берут **нечётным**, чтобы не было ничьих.

**4.3. Взвешенный kNN**

Чем ближе сосед, тем больше его вес $w_i$:

$$
a(u) = \arg\max_y \sum_{i=1}^{k} w_i\,[y_u^{(i)} = y] \quad\text{(классификация)},\qquad
a(u) = \frac{\sum_{i=1}^{k} w_i\, y_u^{(i)}}{\sum_{i=1}^{k} w_i} \quad\text{(регрессия)}.
$$

Схемы весов:
- **по рангу**: $w_i = q^i$, $0 < q < 1$, или $w_i = \frac{k + 1 - i}{k}$;
- **обратное расстояние** (`weights="distance"` в sklearn): $w_i = \frac{1}{\rho(u, x_u^{(i)}) + \varepsilon}$;
- **ядро** $K$ от расстояния, делённого на ширину окна $h$: $w_i = K\big(\rho(u, x_u^{(i)}) / h\big)$ —
  гауссовское, Епанечникова, треугольное, прямоугольное, квартическое, косинусное
  (таблица ядер (см. раздел «5. Регрессия Надарая–Ватсона как локальная константа»)).

**4.4. Регрессия Надарая–Ватсона**

Обобщение взвешенного kNN: используем **все** точки выборки с ядерными весами:

$$
a(u) = \frac{\sum_{i=1}^{\ell} y_i\, K\big(\frac{\rho(u, x_i)}{h}\big)}{\sum_{i=1}^{\ell} K\big(\frac{\rho(u, x_i)}{h}\big)} .
$$

- **Ширина окна** $h$ (bandwidth) — аналог $k$: маленькое $h$ → переобучение, большое → недообучение.
- **Не экстраполирует**: прогноз — взвешенное среднее имеющихся $y_i$, вне диапазона данных он «застывает».

**4.5. Особенности kNN**

| Плюсы | Минусы |
|---|---|
| прост в понимании и реализации | вычислительно дорогой: $O(\ell d)$ на каждый запрос |
| непараметрический — нет предположений о форме зависимости | требователен к памяти: хранит всю выборку |
| улавливает локальные паттерны, сложные границы | чувствителен к выбору метрики и масштабированию |
| легко добавлять новые данные (без переобучения) | нет универсального $k$ — каждый раз подбирать |
| работает и для классификации, и для регрессии, и для поиска похожих | страдает от проклятия размерности |

**4.6. Проклятие размерности**

В пространстве с большим числом признаков данные сильно разрежены, а **все точки становятся примерно
равноудалены** — «ближайший сосед» теряет смысл. Теоретически эффективность kNN падает.
Но реальные данные обычно лежат на **низкоразмерном многообразии**, и kNN работает с его внутренней
размерностью (детали и числа (см. раздел «6. Проклятие размерности»)). Помогают: отбор признаков,
снижение размерности (PCA), обученные эмбеддинги.

**4.7. Быстрый поиск соседей (ANN)**

В продакшене используют **приближённый поиск ближайших соседей** (ANN, approximate nearest neighbors) —
почти без потери качества, но на порядки быстрее:
- **KD-деревья**, Ball tree — точный поиск, эффективны при малой размерности;
- **LSH** (locality-sensitive hashing) — хеши, совпадающие у близких объектов;
- **HNSW** (hierarchical navigable small worlds) — графовый поиск, **SoTA**;
- библиотеки: **Annoy** (Spotify), **FAISS** (Meta), **hnswlib**.

Подробно HNSW и поиск по эмбеддингам — в теме [19](../19_contrastive_embeddings/README.md).

**kNN с нуля (по мотивам ДЗ «Метрические и линейные алгоритмы»)**

```python
import numpy as np
from collections import Counter

class KNN:
    KERNELS = {
        "uniform":      lambda d: 0.5 * (np.abs(d) <= 1),
        "triangular":   lambda d: (1 - np.abs(d)) * (np.abs(d) <= 1),
        "epanechnikov": lambda d: 0.75 * (1 - d ** 2) * (np.abs(d) <= 1),
        "gaussian":     lambda d: np.exp(-0.5 * d ** 2) / np.sqrt(2 * np.pi),
    }

    def __init__(self, k=5, weights="uniform", kernel="gaussian", bandwidth=1.0, task="clf", eps=1e-6):
        self.k, self.weights, self.kernel, self.h, self.task, self.eps = k, weights, kernel, bandwidth, task, eps

    def fit(self, X, y):
        self.X, self.y = np.asarray(X, float), np.asarray(y)   # «обучение» = запоминание
        return self

    def _neighbors(self, x):
        d = np.linalg.norm(self.X - x, axis=1)
        idx = np.argsort(d, kind="stable")[: self.k]
        return idx, d[idx]

    def _weights(self, d):
        if self.weights == "uniform":
            return np.ones_like(d)
        if self.weights == "distance":
            return 1.0 / (d + self.eps)
        return self.KERNELS[self.kernel](d / self.h)              # ядерные веса

    def predict(self, X):
        out = []
        for x in np.asarray(X, float):
            idx, d = self._neighbors(x)
            w, t = self._weights(d), self.y[idx]
            if self.task == "reg":
                out.append(np.sum(w * t) / (np.sum(w) + self.eps))
            else:
                votes = Counter()
                for wi, ti in zip(w, t):
                    votes[ti] += wi
                out.append(votes.most_common(1)[0][0])
        return np.array(out)
```

<details>
<summary><b>1. Аксиомы метрики и какие «расстояния» ими не являются</b></summary>

Функция $\rho: \mathbb{X} \times \mathbb{X} \to \mathbb{R}$ — **метрика**, если для всех $x, y, z$:

1. $\rho(x, y) \ge 0$ — неотрицательность;
2. $\rho(x, y) = 0 \iff x = y$ — тождество неразличимых;
3. $\rho(x, y) = \rho(y, x)$ — симметричность;
4. $\rho(x, z) \le \rho(x, y) + \rho(y, z)$ — неравенство треугольника.

**Минковского** $\rho_p(x, y) = \big(\sum_j |x^j - y^j|^p\big)^{1/p}$ — метрика при $p \ge 1$
(неравенство треугольника = неравенство Минковского). При $p < 1$ — **не** метрика: для $p = \frac12$,
$x = (0,0)$, $y = (1,0)$, $z = (1,1)$: $\rho(x,z) = (1 + 1)^2 = 4 > \rho(x,y) + \rho(y,z) = 2$.

Частные случаи: $p = 1$ — манхэттенское, $p = 2$ — евклидово, $p \to \infty$ — Чебышёва:
$\lim_{p\to\infty}\big(\sum_j |d_j|^p\big)^{1/p} = \max_j |d_j|$ (самое большое слагаемое доминирует).
«Единичные шары»: ромб ($L_1$), круг ($L_2$), квадрат ($L_\infty$).

**Косинусное расстояние** $1 - \cos(x, y)$ **не метрика**: нарушается неравенство треугольника.
Пример: $x = (1, 0)$, $y = (1, 1)$, $z = (0, 1)$: $d(x,z) = 1$, а $d(x,y) + d(y,z) = 2(1 - \frac{1}{\sqrt 2}) \approx 0.586$.
Метрикой является **угловое** расстояние $\arccos(\cos(x,y))/\pi$. Для нормированных векторов
$\|x - y\|_2^2 = 2 - 2\cos(x, y)$, т.е. kNN по косинусу ≡ kNN по евклиду на $L_2$-нормированных векторах.

**Махаланобиса** $\rho(x, y) = \sqrt{(x - y)^\top \Sigma^{-1}(x - y)}$ — евклидово расстояние после
«выбеливания» $z = \Sigma^{-1/2}x$: учитывает масштаб и корреляции признаков.

**Жаккара** для множеств: $1 - \frac{|A \cap B|}{|A \cup B|}$. **Хэмминга** — число несовпадающих позиций.
**Левенштейна** — минимальное число вставок/удалений/замен символов (динамическое программирование
за $O(nm)$). **DTW** — расстояние между временными рядами разной длины с оптимальным
«выравниванием» по времени (тоже ДП, $O(nm)$; не метрика — нарушает неравенство треугольника).

</details>

<details>
<summary><b>2. Ближайший центроид — это линейный классификатор</b></summary>

Центроид класса $k$: $\mu_k = \frac{1}{n_k}\sum_{i: y_i = k} x_i$. Правило: $a(x) = \arg\min_k \|x - \mu_k\|^2$. Раскроем:

$$
\|x - \mu_k\|^2 = \|x\|^2 - 2\langle x, \mu_k\rangle + \|\mu_k\|^2 .
$$

$\|x\|^2$ одинаков для всех $k$, поэтому

$$
a(x) = \arg\max_k \Big( \langle \mu_k, x\rangle - \tfrac12\|\mu_k\|^2 \Big) = \arg\max_k \big(\langle w_k, x\rangle + b_k\big),
\quad w_k = \mu_k,\; b_k = -\tfrac12\|\mu_k\|^2 .
$$

Граница между двумя классами — гиперплоскость, перпендикулярная отрезку $\mu_1\mu_2$ и проходящая через
его середину. Отсюда тезис лекции: метод подходит только для (почти) линейно разделимых классов
с похожим разбросом. Это частный случай LDA с единичной ковариационной матрицей.

</details>

<details>
<summary><b>3. kNN как оценка апостериорной вероятности</b></summary>

Байесовский классификатор: $a^*(x) = \arg\max_y P(y \mid x)$. kNN оценивает
$P(y \mid x)$ долей класса среди $k$ соседей:

$$
\hat P(y = c \mid x) = \frac{1}{k}\sum_{x_i \in N_k(x)} [y_i = c] .
$$

Обоснование через плотности: пусть шар радиуса $r_k(x)$ до $k$-го соседа имеет объём $V$ и содержит
$k_c$ точек класса $c$ из $n_c$. Оценки плотностей: $\hat p(x \mid c) = \frac{k_c}{n_c V}$, $\hat p(x) = \frac{k}{n V}$,
$\hat P(c) = \frac{n_c}{n}$. По формуле Байеса

$$
\hat P(c \mid x) = \frac{\hat p(x \mid c)\hat P(c)}{\hat p(x)} = \frac{k_c}{k}.
$$

При $k \to \infty$, $k/n \to 0$ оценка состоятельна (теорема Стоуна), и kNN сходится к байесовскому
классификатору.

**Теорема Ковера–Харта (1967) для 1NN**

При $n \to \infty$ ошибка 1NN $R_{1NN}$ ограничена через байесовскую ошибку $R^*$:

$$
R^* \le R_{1NN} \le 2R^*(1 - R^*) \le 2R^* .
$$

*Набросок для двух классов.* Пусть $\eta(x) = P(y = 1 \mid x)$. При $n \to \infty$ ближайший сосед $x'$
сколь угодно близок к $x$, и его метка независима от метки $x$ с той же $\eta(x)$. Ошибка — метки различны:
$P(y \ne y') = 2\eta(x)(1 - \eta(x))$. Байесовская ошибка в точке $r(x) = \min(\eta, 1-\eta)$, и
$2\eta(1-\eta) = 2r(x)(1 - r(x))$. Усредняя и пользуясь вогнутостью $t(1-t)$ (неравенство Йенсена):
$R_{1NN} = \mathbb{E}\,2r(1-r) \le 2R^*(1 - R^*)$. ∎

Смысл: «даже самый простой» 1NN в пределе ошибается не более чем вдвое чаще оптимального классификатора.

</details>

<details>
<summary><b>4. Bias–variance для kNN-регрессии</b></summary>

Модель $y = f(x) + \varepsilon$, $\mathbb{E}\varepsilon = 0$, $\operatorname{Var}\varepsilon = \sigma^2$, точки обучения фиксированы.
Прогноз $\hat f(x_0) = \frac{1}{k}\sum_{l=1}^{k} y_{(l)}$ по $k$ соседям $x_{(1)}, \dots, x_{(k)}$. Тогда

$$
\mathbb{E}\big(y_0 - \hat f(x_0)\big)^2 = \sigma^2 + \Big(f(x_0) - \frac{1}{k}\sum_{l=1}^{k} f(x_{(l)})\Big)^2 + \frac{\sigma^2}{k} .
$$

*Вывод:* $\hat f(x_0) = \frac1k\sum f(x_{(l)}) + \frac1k\sum \varepsilon_{(l)}$; среднее шумов имеет дисперсию $\sigma^2/k$
(шумы независимы), а детерминированная часть даёт смещение. Шум нового наблюдения $y_0$ независим — ещё $\sigma^2$.

- **малое $k$**: дисперсия $\sigma^2/k$ велика → переобучение, рваная граница;
- **большое $k$**: соседи далеко, $\frac1k\sum f(x_{(l)})$ «размывает» $f(x_0)$ → смещение, недообучение.

Это и есть строгая форма тезиса лекции «$k$ отвечает за баланс локальности и обобщения» (подробнее о
разложении — тема [06](../06_bias_variance/README.md)).

</details>

<details>
<summary><b>5. Регрессия Надарая–Ватсона как локальная константа</b></summary>

Найдём константу $c$, оптимальную **в окрестности** $x$ с весами $K\big(\frac{\rho(x, x_i)}{h}\big)$:

$$
c(x) = \arg\min_c \sum_{i=1}^{\ell} K\Big(\frac{\rho(x, x_i)}{h}\Big)(y_i - c)^2 .
$$

Приравниваем производную к нулю:

$$
\hat y(x) = \frac{\sum_{i=1}^{\ell} y_i\, K\big(\frac{\rho(x, x_i)}{h}\big)}{\sum_{i=1}^{\ell} K\big(\frac{\rho(x, x_i)}{h}\big)} .
$$

Это и есть формула Надарая–Ватсона: взвешенное среднее **по всем** точкам выборки. Взвешенный kNN —
частный случай, где веса вне $k$ соседей равны 0. Если вместо константы подбирать в окрестности линейную
функцию, получим **локально-линейную регрессию** (LOESS), у которой меньше смещение на краях.

**Почему «не экстраполирует»:** прогноз — выпуклая комбинация $y_i$, поэтому
$\min_i y_i \le \hat y(x) \le \max_i y_i$. Вне области данных прогноз стремится к значению ближайших
краевых точек.

**Ядра** (аргумент $d = \rho/h$):

| Ядро | $K(d)$ |
|---|---|
| Прямоугольное (top-hat) | $\frac12[\lvert d\rvert \le 1]$ |
| Треугольное | $(1 - \lvert d\rvert)[\lvert d\rvert \le 1]$ |
| Епанечникова | $\frac34(1 - d^2)[\lvert d\rvert \le 1]$ |
| Квартическое | $\frac{15}{16}(1 - d^2)^2[\lvert d\rvert \le 1]$ |
| Гауссовское | $\frac{1}{\sqrt{2\pi}}e^{-d^2/2}$ |

Ядро Епанечникова оптимально по асимптотической MISE при оценке плотности, но на практике выбор
ядра влияет гораздо слабее, чем выбор ширины окна $h$. Переменная ширина $h(x) = \rho(x, x_{(k+1)})$
делает окно адаптивным к плотности данных (широкое в разреженных областях).

</details>

<details>
<summary><b>6. Проклятие размерности</b></summary>

**(а) Нужная «окрестность» перестаёт быть локальной.** Пусть точки равномерны в $[0,1]^d$. Чтобы
захватить долю $r$ выборки кубом-окрестностью, его ребро должно быть $e_d(r) = r^{1/d}$.
При $d = 10$ и $r = 1\%$: $e = 0.01^{0.1} \approx 0.63$ — «соседи» в 1% выборки занимают 63% диапазона
каждого признака. Это уже не локальная окрестность.

**(б) Концентрация расстояний.** Для i.i.d. признаков расстояние $\|x - x'\|^2 = \sum_j (x^j - x'^j)^2$ —
сумма $d$ независимых слагаемых; её среднее растёт как $d$, а стандартное отклонение — как $\sqrt d$.
Относительный разброс $\frac{\text{std}}{\text{mean}} \sim \frac{1}{\sqrt d} \to 0$: все точки примерно
равноудалены, и понятие «ближайший» теряет смысл.

```python
import numpy as np
rng = np.random.default_rng(0)
for d in (2, 10, 100, 1000):
    X = rng.uniform(size=(1000, d)); q = rng.uniform(size=d)
    dist = np.linalg.norm(X - q, axis=1)
    print(d, round((dist.max() - dist.min()) / dist.min(), 3))   # контраст падает с ростом d
```

**(в) Почему kNN всё же работает** (тезис лекции): реальные данные лежат на многообразии **низкой
внутренней размерности** (изображения, тексты), и важна именно она, а не формальное число признаков.

</details>

<details>
<summary><b>7. Быстрый поиск соседей</b></summary>

| Метод | Идея | Запрос | Когда |
|---|---|---|---|
| Полный перебор | все расстояния | $O(\ell d)$ | маленькие данные, GPU |
| KD-дерево | рекурсивно делим пространство по медиане одного признака | $\approx O(\log \ell)$ при малом $d$, деградирует к $O(\ell)$ при $d \gtrsim 20$ | низкая размерность |
| Ball tree | вложенные шары, неравенство треугольника для отсечения | лучше KD при средней $d$, любые метрики | |
| LSH | хеши, совпадающие для близких точек с большой вероятностью | сублинейно, приближённо | огромные данные |
| HNSW | многоуровневый граф «тесного мира», жадный спуск | $\approx O(\log \ell)$, приближённо | SoTA для эмбеддингов (тема [19](../19_contrastive_embeddings/README.md)) |

**LSH для косинуса (random hyperplanes).** Выберем случайный $r \sim \mathcal{N}(0, I)$, хеш
$h_r(x) = \operatorname{sign}(\langle r, x\rangle)$. Тогда

$$
P\big(h_r(x) = h_r(y)\big) = 1 - \frac{\theta(x, y)}{\pi},
$$

где $\theta$ — угол между векторами. *Почему:* знаки различаются ровно тогда, когда случайная
гиперплоскость (с нормалью $r$) проходит между $x$ и $y$; в плоскости $(x, y)$ её след — случайная прямая
через начало координат с равномерным углом, и она разделяет векторы с вероятностью $\theta/\pi$.
Склеивая $b$ хешей в ключ и используя $L$ таблиц, получаем компромисс точность/скорость.

</details>

<summary><b>Дополнительно: детали</b></summary>

- **Cover–Hart**: асимптотически ошибка 1NN $\le 2R^*$ (удвоенная байесовская).
- kNN-регрессия: $\text{Err}=\sigma^2+\text{bias}^2(k)+\sigma^2/k$ — явный bias-variance tradeoff.
- Ближайший центроид с $L_2$ = линейный классификатор: $w_k=\mu_k$, $b_k=-\frac12\|\mu_k\|^2$.
- Надарая–Ватсон = локальная оптимальная константа под MSE с весами-ядром; не экстраполирует.

</details>

<summary><b>Примеры кода (с результатами запуска)</b></summary>

Запустить их можно в ноутбуке [`cheatsheet.ipynb`](../../cheatsheet.ipynb).

```python
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier

X, y = load_breast_cancer(return_X_y=True)
for scale in (False, True):
    for k in (1, 5, 15, 51):
        knn = KNeighborsClassifier(n_neighbors=k)
        model = make_pipeline(StandardScaler(), knn) if scale else knn
        acc = cross_val_score(model, X, y, cv=5).mean()
        print(f"scale={scale!s:5}  k={k:2d}  CV accuracy={acc:.3f}")
# масштабирование даёт больше, чем подбор k: признаки в разных шкалах «ломают» расстояние
```

