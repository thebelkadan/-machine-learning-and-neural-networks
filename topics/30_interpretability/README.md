# 30. Интерпретируемость моделей: важность признаков, PDP, SHAP, LIME

[Шпаргалка (ноутбук)](../../cheatsheet.ipynb) · [Оглавление курса](../../README.md)

**Суть.** Интерпретируемость отвечает на вопросы «на что смотрит модель в целом» (**глобальные** объяснения: важность
признаков, зависимость прогноза от признака) и «почему такой ответ для этого объекта» (**локальные**: SHAP, LIME,
контрфакты). Простые модели (линейные, неглубокие деревья) интерпретируемы сами; для сложных строят объяснения поверх.
Встроенная важность деревьев (**MDI**) смещена в пользу признаков со многими значениями — надёжнее **permutation importance**
на отложенной выборке. **Значения Шепли** честно делят прогноз между признаками и складываются в него точно. Главное правило:
объяснение показывает, что использует **модель**, а не причинно-следственные связи в **мире**.

| Термин | Определение |
|---|---|
| Глобальное / локальное объяснение | поведение модели в целом / для конкретного объекта |
| MDI (impurity importance) | суммарное уменьшение неопределённости по разбиениям на признаке; считается на train |
| Permutation importance | насколько падает качество, если перемешать значения признака (на валидации) |
| PDP / ICE | средний прогноз при фиксированном значении признака / то же для каждого объекта отдельно |
| Значение Шепли $\varphi_j$ | средний вклад признака по всем порядкам «добавления» признаков |
| SHAP | значения Шепли для объяснения прогнозов; $f(x)=\mathbb E f+\sum_j\varphi_j$ |
| LIME | локальная линейная модель, подогнанная к ответам на возмущениях вокруг объекта |
| Контрфакт | минимальное изменение объекта, которое меняет ответ модели |

**Ключевые формулы**

$$
\varphi_j=\sum_{S\subseteq F\setminus\lbrace j\rbrace}\frac{\lvert S\rvert!\,(\lvert F\rvert-\lvert S\rvert-1)!}{\lvert F\rvert!}\Big(v(S\cup\lbrace j\rbrace)-v(S)\Big),\qquad
f(x)=\mathbb E f(X)+\sum_{j}\varphi_j,\qquad
\mathrm{PI}_j=\mathcal L\big(f(X^{\pi_j}),y\big)-\mathcal L\big(f(X),y\big)
$$

<summary><b>1. Зачем и какие бывают объяснения</b></summary>

**Зачем:** отладка (модель смотрит на утечку или артефакт — «умный Ганс», тема 19), доверие пользователей и экспертов,
требования регуляторов (кредитный скоринг, медицина: право на объяснение решения), поиск новых закономерностей в данных,
выбор признаков (тема 12).

| Ось | Варианты |
|---|---|
| Охват | **глобальные** (вся модель) / **локальные** (один прогноз) |
| Способ | **внутренне интерпретируемые** модели / **post-hoc** объяснения готовой модели |
| Применимость | **модельно-специфичные** (MDI деревьев, градиенты сетей) / **модельно-агностические** (permutation, SHAP, LIME) |

**Интерпретируемые модели:** линейная и логистическая регрессия (коэффициенты при стандартизированных признаках), неглубокие
деревья и списки правил, **GAM** (сумма одномерных функций $f(x)=\sum_jg_j(x_j)$, каждую можно нарисовать), **EBM** (бустинг GAM
с попарными взаимодействиями — часто почти не уступает бустингу на таблицах). Если интерпретируемая модель даёт сопоставимое
качество — лучше выбрать её, чем объяснять чёрный ящик.

<details>
<summary><b>2. Важность признаков</b></summary>

- **Коэффициенты линейной модели:** сравнимы только при стандартизированных признаках; при мультиколлинеарности нестабильны (тема 04).
- **MDI** (встроенная `feature_importances_` деревьев и лесов, тема 07): сумма уменьшений неопределённости по всем разбиениям на
  признаке. Минусы: считается на **обучающих** данных; **смещена** к непрерывным и высококардинальным признакам (у них больше
  возможных порогов, переобучение на них засчитывается как важность). Пример кода этой темы: случайный шум и номер строки
  получают MDI ~0.035 — на уровне настоящих признаков `age`, `s2`, тогда как permutation importance для них ≈ 0.
- **Permutation importance:** перемешать столбец признака на **валидации** и посмотреть, насколько упало качество. Модельно-
  агностична, честно учитывает переобучение. Минусы: при **коррелированных** признаках перемешивание создаёт нереалистичные
  объекты, а важность делится между «близнецами» (каждый по отдельности кажется неважным).
- **Drop-column importance:** переобучить модель без признака — самая честная, но дорогая.
- Для бустинга — `gain` (аналог MDI) и `split` (число разбиений); оба с теми же оговорками.

</details>

<details>
<summary><b>3. Зависимость прогноза от признака: PDP, ICE, ALE</b></summary>

- **PDP** (partial dependence): $\mathrm{PD}_j(v)=\frac1n\sum_if(x_i^{(j\leftarrow v)})$ — подставить значение $v$ всем объектам и усреднить
  прогноз. Показывает форму зависимости (монотонность, пороги, насыщение).
- **ICE**: те же кривые для каждого объекта отдельно; разнонаправленные кривые выдают **взаимодействия**, которые PDP усредняет.
- **ALE** (accumulated local effects): усредняет локальные изменения прогноза внутри узких интервалов признака — не выходит за
  пределы реалистичных объектов при коррелированных признаках, в отличие от PDP.

```python
from sklearn.inspection import PartialDependenceDisplay, permutation_importance
PartialDependenceDisplay.from_estimator(model, X_val, ["bmi", "s5"], kind="both")   # PDP + ICE
r = permutation_importance(model, X_val, y_val, n_repeats=20, random_state=0)
```

</details>

<details>
<summary><b>4. Значения Шепли и SHAP</b></summary>

Идея из теории кооперативных игр (Шепли, 1953): как честно разделить выигрыш коалиции между игроками. В ML игроки — признаки,
выигрыш — прогноз $f(x)$ минус средний прогноз. **Вклад признака** — средний прирост «ценности» $v(S)$ при его добавлении к
коалиции $S$, усреднённый по всем порядкам добавления признаков.

**Ценность коалиции** $v(S)$ — ожидаемый прогноз, если известны только признаки из $S$, а остальные «неизвестны»:
- **интервенционный** вариант: остальные признаки берутся из фоновой выборки независимо (стандарт KernelSHAP, TreeSHAP с background);
- **условный (наблюдательный)**: из условного распределения при известных $S$ — честнее к корреляциям, но сложно оценить.

**Свойства** (и единственность при них): **эффективность** — $\sum_j\varphi_j=f(x)-\mathbb Ef$; **симметрия** — одинаково влияющие
признаки получают одинаковый вклад; **болван** — признак, ни на что не влияющий, получает 0; **аддитивность** — для суммы моделей
вклады складываются.

**Как считать:** точно — перебор $2^M$ коалиций (реально до ~15 признаков); **KernelSHAP** — взвешенная линейная регрессия по
сэмплированным коалициям (агностичен, медленный); **TreeSHAP** — точный полиномиальный алгоритм для деревьев и бустинга (быстрый,
стандарт для табличных моделей); **DeepSHAP/GradientSHAP** — для нейросетей. Для линейной модели с независимыми признаками
$\varphi_j=w_j(x_j-\mathbb Ex_j)$ — пример кода этой темы сверяет перебор с этой формулой.

**Графики** (`shap`): waterfall (разложение одного прогноза), beeswarm/summary (вклады по всем объектам: важность и направление),
dependence (вклад от значения признака, цвет — взаимодействующий признак).

```python
import shap
explainer = shap.TreeExplainer(model)           # для деревьев и бустинга
sv = explainer(X_val)                           # Explanation: values, base_values, data
shap.plots.waterfall(sv[0]); shap.plots.beeswarm(sv)
```

</details>

<details>
<summary><b>5. LIME и другие локальные методы</b></summary>

**LIME** (Ribeiro et al., 2016): насэмплировать объекты вокруг $x$ (возмутить признаки, для текста — выкинуть слова, для картинок —
суперпиксели), получить ответы модели, обучить на них **простую** модель (линейную с L1), взвешивая объекты по близости к $x$.
Её коэффициенты — локальное объяснение. Минусы: результат зависит от способа возмущений и ширины ядра близости, нестабилен
между запусками.

- **Anchors**: правило «если признаки такие-то, ответ почти наверняка не изменится» с оценкой точности и покрытия.
- **Контрфактические объяснения**: «кредит дали бы, если бы доход был на 15 тыс. выше» — минимальное **реалистичное и
  выполнимое** изменение, меняющее ответ (DiCE). Полезно пользователю, но нужно запрещать неизменяемые признаки (возраст, пол).
- **Объяснения по примерам**: ближайшие обучающие объекты, прототипы, влияние обучающих объектов (influence functions).

</details>

<details>
<summary><b>6. Объяснения нейросетей</b></summary>

- **Градиентные карты** (saliency $\partial f/\partial x$), **SmoothGrad**, **Integrated Gradients** (интеграл градиента по пути от
  нейтрального входа — удовлетворяет аксиоме полноты), **Grad-CAM** для CNN (тема 19).
- **Веса внимания** — не объяснение сами по себе: состояния уже смешивают контекст (тема 22), альтернативные распределения внимания
  дают те же ответы. Лучше attention rollout или градиентные методы.
- **Probing**: обучить линейный классификатор на скрытых состояниях, чтобы проверить, закодировано ли там свойство (часть речи,
  синтаксис). Закодировано ≠ используется моделью.

</details>

<details>
<summary><b>7. Механистическая интерпретируемость LLM</b></summary>

Цель — понять **алгоритмы** внутри модели, а не только атрибуции:
- **Logit lens**: проецировать скрытое состояние промежуточного слоя через выходную матрицу — видно, как «созревает» ответ по слоям.
- **Activation patching** (causal tracing): подменить активацию из прогона на другом входе и посмотреть, изменился ли ответ —
  находит слои и головы, где хранится факт или выполняется шаг (ROME — редактирование фактов в MLP-слоях).
- **Схемы (circuits)**: найденные механизмы — индукционные головы (копирование из контекста, основа in-context learning),
  головы для косвенного дополнения (IOI).
- **Разреженные автокодировщики (SAE)**: раскладывают активации на большой словарь разреженных «признаков», многие из которых
  интерпретируемы (конкретные понятия, языки, типы кода); ими можно управлять, усиливая или подавляя.
- **Суперпозиция**: модель хранит больше признаков, чем у неё измерений, — поэтому отдельные нейроны редко однозначны.

</details>

<details>
<summary><b>8. Ловушки</b></summary>

- **Объяснение модели ≠ причинность в мире.** Высокий вклад признака значит, что модель на него опирается, а не что изменение
  признака изменит исход (для этого нужен causal inference).
- **Коррелированные признаки** делят важность, PDP выходит в нереалистичные области, интервенционный SHAP оценивает модель на
  невозможных объектах.
- **Утечки** обнаруживаются как неправдоподобно важные признаки — это одна из главных практических польз объяснений (темы 05, 21).
- **Нестабильность**: разные методы и даже разные запуски дают разные ранжирования; проверяйте устойчивость.
- **Sanity checks** (Adebayo et al., 2018): карта объяснения должна меняться при рандомизации весов модели; некоторые
  saliency-методы этот тест не проходят — они показывают края изображения, а не то, что использует модель.
- Объяснения можно подделать: модель может вести себя иначе на объектах вне распределения, которые генерируют LIME и KernelSHAP.

</details>

- Неправдоподобно важный признак — первым делом проверить на утечку.
- Не делать причинных выводов из важностей.

<details>
<summary><b>1. Значения Шепли: формула и единственность</b></summary>

Для множества признаков $F$, $\lvert F\rvert=M$, и функции ценности $v:2^F\to\mathbb R$:

$$
\varphi_j=\sum_{S\subseteq F\setminus\lbrace j\rbrace}\frac{\lvert S\rvert!\,(M-\lvert S\rvert-1)!}{M!}\big(v(S\cup\lbrace j\rbrace)-v(S)\big).
$$

Интерпретация весов: перебрать все $M!$ порядков, в которых признаки «входят в коалицию»; вклад $j$ в данном порядке —
прирост ценности при его входе; $\varphi_j$ — среднее по порядкам. Число порядков, где перед $j$ стоит ровно множество $S$:
$\lvert S\rvert!\,(M-\lvert S\rvert-1)!$ — отсюда веса.

**Эффективность:** в каждом порядке сумма приростов телескопируется в $v(F)-v(\varnothing)$; среднее тоже. При
$v(S)=\mathbb E[f(X)\mid X_S=x_S]$ получаем $\sum_j\varphi_j=f(x)-\mathbb Ef(X)$.

**Единственность** (Шепли, 1953): значения Шепли — единственное распределение, удовлетворяющее эффективности, симметрии,
свойству болвана и аддитивности. Поэтому SHAP называют «единственно согласованным» разложением в этом классе.

</details>

<details>
<summary><b>2. SHAP линейной модели</b></summary>

$f(x)=b+\sum_kw_kx_k$, интервенционная ценность $v(S)=\mathbb E_{X'}\big[f(x_S,X'_{\bar S})\big]=b+\sum_{k\in S}w_kx_k+\sum_{k\notin S}w_k\mathbb Ex_k$.
Прирост при добавлении $j$ к любому $S$ один и тот же: $v(S\cup\lbrace j\rbrace)-v(S)=w_j(x_j-\mathbb Ex_j)$. Сумма весов по $S$ равна 1, поэтому

$$
\varphi_j=w_j\,(x_j-\mathbb Ex_j).
$$

Это «вклад относительно среднего». Пример кода этой темы получает те же числа перебором коалиций. Для логистической
регрессии такое разложение верно в пространстве **логитов**, не вероятностей.

</details>

<details>
<summary><b>3. Permutation importance и корреляции</b></summary>

$\mathrm{PI}_j=\mathbb E_\pi\,\mathcal L\big(f(X^{\pi_j}),y\big)-\mathcal L\big(f(X),y\big)$, где $X^{\pi_j}$ — данные с перемешанным $j$-м столбцом. Перемешивание
разрывает связь $X_j$ и с $y$, и с **другими признаками**: если $X_j\approx X_k$, перемешанный объект с $X_j\ne X_k$ лежит вне
распределения обучения, и модель на нём может вести себя произвольно. Отсюда два эффекта: важность коррелированной группы
делится (модель может опираться на любого «близнеца»), а на нереалистичных объектах она бывает и завышена. Условная permutation
importance перемешивает $X_j$ внутри групп похожих по $X_{-j}$ объектов — отвечает на вопрос «что признак добавляет сверх остальных».

</details>

<details>
<summary><b>4. PDP и его смещение</b></summary>

$\mathrm{PD}_j(v)=\mathbb E_{X_{-j}}\big[f(v,X_{-j})\big]$ — **маргинальное** среднее. Если признаки зависимы, это не то же, что условное
$\mathbb E[f(X)\mid X_j=v]$: PDP усредняет по всем $X_{-j}$, включая невозможные при $X_j=v$. Условное среднее (M-plot) наоборот
смешивает эффект $X_j$ с эффектами коррелированных признаков. **ALE** решает обе проблемы: $\mathrm{ALE}_j(v)=\int_{v_0}^{v}\mathbb E\big[\partial f/\partial x_j\,\big|\,X_j=u\big]du$
— интегрирует **локальные** изменения прогноза, оцененные только на реальных объектах вблизи $u$.

</details>

<details>
<summary><b>5. Integrated Gradients и полнота</b></summary>

$\mathrm{IG}_j(x)=(x_j-x'_j)\int_0^1\frac{\partial f\big(x'+\alpha(x-x')\big)}{\partial x_j}d\alpha$, $x'$ — нейтральный вход (чёрная картинка, нулевые
эмбеддинги). По теореме о градиенте вдоль пути $\sum_j\mathrm{IG}_j(x)=f(x)-f(x')$ — **полнота**, аналог эффективности Шепли.
Интеграл считают суммой по 20–300 точкам пути. Простой градиент полнотой не обладает: в области насыщения (ReLU, сигмоида)
он нулевой, хотя признак важен.

</details>

<details>
<summary>Почему не доверять `feature_importances_` случайного леса?</summary>

MDI считается на train и завышает непрерывные и высококардинальные признаки (в примере шум получил важность наравне с настоящими признаками).

</details>

<details>
<summary>Почему permutation importance считают на валидации?</summary>

на train модель могла запомнить шум, и его перемешивание «ухудшит» качество — важность переобучения.

</details>

<details>
<summary>Два сильно коррелированных признака: что покажет permutation importance?</summary>

каждый по отдельности окажется неважным — модель восстанавливает информацию из «близнеца».

</details>

<details>
<summary>Что гарантирует SHAP, чего нет у LIME?</summary>

сумма вкладов точно равна прогнозу минус среднее, и единственность при аксиомах; LIME — приближение, зависящее от возмущений.

</details>

<details>
<summary>SHAP-значение признака большое — значит, изменение признака изменит исход?</summary>

нет: это вклад в прогноз модели, а не причинный эффект в мире.

</details>

import itertools, math, warnings

# Точные значения Шепли перебором всех коалиций; проверка эффективности и формулы для линейной модели; PDP
cols = ["bmi", "s5", "bp", "s1", "age", "sex"]
lin = LinearRegression().fit(Xtr[cols], ytr)
forest = RandomForestRegressor(200, min_samples_leaf=3, random_state=0).fit(Xtr[cols], ytr)
background = Xtr[cols].sample(100, random_state=0).to_numpy()
x = Xte[cols].iloc[0].to_numpy(); M = len(cols)

def value(S, predict):                                   # интервенционная ценность коалиции S
    Z = background.copy(); Z[:, list(S)] = x[list(S)]
    return predict(pd.DataFrame(Z, columns=cols)).mean()
def shapley(predict):
    cache = {}; v = lambda S: cache.setdefault(S, value(S, predict)); phi = np.zeros(M)
    for j in range(M):
        others = [k for k in range(M) if k != j]
        for r in range(M):
            for S in itertools.combinations(others, r):
                w = math.factorial(r) * math.factorial(M - r - 1) / math.factorial(M)
                phi[j] += w * (v(tuple(sorted(S + (j,)))) - v(S))
    return phi, v(tuple(range(M))) - v(())
for name, model in (("линейная регрессия", lin), ("случайный лес", forest)):
    phi, total = shapley(model.predict)
    print(f"{name:18s} φ = {dict(zip(cols, phi.round(1).tolist()))}; Σφ = {phi.sum():.1f}, f(x) − E f = {total:.1f}")
print("формула w·(x − E x):  ", dict(zip(cols, (lin.coef_ * (x - background.mean(0))).round(1).tolist())))

pdp = partial_dependence(rf, Xte, ["bmi"], grid_resolution=6)
print("PDP по bmi: значения признака", pdp["grid_values"][0].round(3).tolist(), "→ средний прогноз", pdp["average"][0].round(0).tolist())
