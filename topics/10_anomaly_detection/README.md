# 10. Обнаружение аномалий

[Шпаргалка (ноутбук)](../../cheatsheet.ipynb) · [Оглавление курса](../../README.md)

**Суть.** Аномалия — объект, сильно отличающийся от большинства (числово, поведенчески или в контексте).
Постановки: **outlier detection** (аномалии есть в обучении) и **novelty detection** (учимся только на норме).
Методы: статистические (IQR, z-score), модельные (большие остатки регрессии), метрические (kNN, LOF, DBSCAN),
ML (One-Class SVM, **Isolation Forest**), нейросетевые (ошибка реконструкции автоэнкодера). Решение — порог на скор.

| Термин | Определение |
|---|---|
| Шум / новизна | ошибочные данные без информации / то, чего не было в обучении |
| IQR-правило | выброс вне $[Q_1-1.5\,\text{IQR},\;Q_3+1.5\,\text{IQR}]$ |
| MAD | $\operatorname{median}\lvert x-\operatorname{median}(x)\rvert$ — робастная мера разброса |
| LOF | отношение плотности соседей к плотности точки; $\gg1$ — выброс |
| One-Class SVM | граница вокруг нормы; `nu` — верхняя граница доли выбросов |
| Isolation Forest | случайные деревья; аномалия изолируется за малое число разбиений |
| `contamination` | ожидаемая доля аномалий → порог на скор |
| PR-AUC, Precision@k | метрики при сильном дисбалансе |

$$
z_i=\frac{x_i-\mu}{\sigma},\qquad \text{порог}=\operatorname{median}(e)+3\cdot\text{MAD},\qquad
s_{\text{IF}}(x)=2^{-\mathbb{E}h(x)/c(n)},\quad c(n)=2H(n-1)-\tfrac{2(n-1)}{n}
$$

<details>
<summary><b>1. Аномалия, шум и новизна</b></summary>

| Понятие | Определение | Цель работы с ним |
|---|---|---|
| **Аномалия** | объект, который **существенно отличается** от большинства других | выявить, интерпретировать, найти закономерности |
| **Шум** | случайные/ошибочные данные без полезной информации; в сильном смысле — способен имитировать аномалии | исключить, очистить данные |
| **Новизна** (novelty) | объект или поведение, которых **не было в обучающей выборке** (новый вид кибератаки) | построить модель, адаптирующуюся к непредсказуемому будущему |

**Типы отличий аномалии:**
- **числовое** — перевод 3 млн ₽ у клиента, который обычно переводит до 50 000;
- **поведенческое** — сотрудник вдруг скачивает всю клиентскую базу;
- **контекстуальное** — нормально для одного, странно для другого (вход из другой страны).

**Контекст критичен.** Пример из лекции: 1000 банковских транзакций. Вариант 1 — считать подозрительными все
переводы > 3000 ₽: перевод 6000 ₽ от предпринимателя из Москвы и от рабочего из деревни попадут в одну кучу.
Вариант 2 — сравнивать транзакцию со средней суммой **этого клиента**, его временными паттернами, доходом,
поведением похожих клиентов.

**Где встречаются:** производство (датчики: пики, несогласованные параметры, залипшие значения — брак партии
стоит миллионы), кибербезопасность (всплеск ночных входов, много запросов с одного IP), финансы (графы
транзакций: отмывание денег, инсайдерские схемы).

</details>

<details>
<summary><b>2. Постановки задачи</b></summary>

| | **Outlier detection** (детектирование выбросов) | **Novelty detection** (детектирование новизны) |
|---|---|---|
| Обучающая выборка | содержит аномалии | только «нормальные» объекты |
| Задача | найти объекты, не похожие на основную массу, **внутри** имеющихся данных | построить «образ нормы» и замечать отклонения в **новых** данных |
| Пример | чистка исторических данных | мониторинг в реальном времени |

По наличию разметки:
1. **Без разметки** (unsupervised outlier detection) — самый частый случай;
2. **Частичная разметка** (Positive-Unlabeled learning) — часть аномалий известна, в остальных данных они тоже могут быть;
3. **Полная разметка** — редкость; сводится к бинарной классификации с сильным дисбалансом.

</details>

<details>
<summary><b>3. Статистические методы</b></summary>

**IQR (межквартильный размах).** $\text{IQR} = Q_3 - Q_1$; границы $Q_1 - 1.5\,\text{IQR}$ и $Q_3 + 1.5\,\text{IQR}$ (усы
«ящика с усами»). Просто, не зависит от распределения, но **только одномерно**. Для нормальных данных граница
≈ $\mu \pm 2.7\sigma$ (вывод (см. раздел «2. IQR: какой порог он задаёт»)).

**Z-оценка.** $z_i = \frac{x_i - \mu}{\sigma}$; выброс, если $|z_i|$ больше порога (обычно 3). Минус — выбросы сами
раздувают $\mu$ и $\sigma$ (**маскировка**) → робастная версия с медианой и MAD (подробно (см. раздел «1. Z-оценка: сколько «трёх сигм» на самом деле»)).

**Тест Граббса** — статистический тест на наличие одного выброса в нормальной выборке.

**Выводы:** статистические методы — базовые инструменты предварительной диагностики; хорошо работают для
простых, одномерных и стационарных данных; не требуют разметки; основаны на предположениях о распределении;
выявляют статистически редкие случаи, но ориентированы на **известные** отклонения, а не на новизну.

</details>

<details>
<summary><b>4. Модельный подход: регрессия + анализ остатков</b></summary>

1. Обучаем модель (линейную регрессию, бустинг) предсказывать целевое значение по признакам.
2. Считаем остатки $e_i = |y_i - \hat y_i|$.
3. Объекты с **большими остатками** — потенциальные аномалии. Порог:
   - три сигмы;
   - верхний перцентиль (например, 5% точек с наибольшими ошибками);
   - **MAD**: $\text{MAD} = \operatorname{median}(|e_i - \operatorname{median}(e)|)$, порог $= \operatorname{median}(e) + k\cdot\text{MAD}$, $k = 3$ —
     робастный способ, устойчивый к выбросам.

**Выводы:** модельные методы учитывают структуру данных и целевую задачу, не требуют разметки, позволяют
самим задать «норму»; эффективны для новизны и мониторинга. Риск: модель может **встроить аномалию в норму**
(подогнаться под неё) и не выявить её.

</details>

<details>
<summary><b>5. Метрические методы</b></summary>

Идея: **нормальные точки находятся рядом с другими, аномалия — «далеко от всех»**. Нужна метрика: евклидова,
манхэттенская, Махаланобиса (с учётом корреляций и масштаба).

**kNN-детектор (PyOD)**

Чем больше расстояние до ближайших соседей, тем выше вероятность аномалии. Стратегии скора:
`method='largest'` — расстояние до самого дальнего из $k$ соседей; `'mean'` — среднее; `'median'` — медиана.

```python
from pyod.models.knn import KNN
X = np.array([[1], [2], [2.2], [2.1], [8]])        # 8 — выброс
model = KNN(contamination=0.1, method="mean").fit(X)
model.predict(X)               # 1 — выброс, 0 — норма
model.decision_function(X)     # чем выше, тем аномальнее
```

**PyOD** — специализированная библиотека для поиска аномалий: единый API для статистических, ML- и DL-методов,
совместимость со sklearn, ансамбли (SUOD), semi-supervised сценарии.

**Local Outlier Factor (LOF)**

Если точка в области **низкой плотности**, но окружена точками из **более плотной** области — вероятно, выброс;
если плотность как у соседей — норма. Формулы: достижимое расстояние $p'(x, z) = \max[p(x, z), p_k(z)]$,
локальная достижимая плотность (LRD) — обратная к среднему достижимому расстоянию до $k$ соседей,
LOF — среднее отношение LRD соседей к LRD точки (подробно (см. раздел «5. Local Outlier Factor»)).

```python
from sklearn.neighbors import LocalOutlierFactor
X = np.array([[1, 2], [2, 1], [1, 1], [10, 10], [10, 11], [11, 10]])
lof = LocalOutlierFactor(n_neighbors=2, contamination=0.2)   # novelty=False — выбросы в самом наборе
lof.fit_predict(X)                                            # -1 — выброс, 1 — норма
lof.negative_outlier_factor_                                  # чем ниже, тем аномальнее
LocalOutlierFactor(n_neighbors=20, novelty=True).fit(X_train).decision_function(X_new)   # новизна
```

**DBSCAN**

Группирует точки из областей высокой плотности; точки, у которых внутри радиуса `eps` меньше `min_samples`
соседей и которые не прилегают к плотным областям, получают метку **−1** (шум = выбросы).
`eps` подбирают по «локтю» графика расстояний до $k$-го соседа ($k$ = `min_samples`); `min_samples` ≈ размерность + 1 или чуть больше (3–5).

```python
from sklearn.cluster import DBSCAN
X = np.array([[1], [1.1], [1.2], [1.3], [6]])
DBSCAN(eps=0.3, min_samples=2).fit_predict(X)     # [0 0 0 0 -1]
```

**Выводы:** метрические методы не требуют обучения, легко интерпретируются, не зависят от распределения;
удобны для быстрого анализа. Ограничения: зависят от метрики, плохо работают в высокой размерности,
чувствительны к масштабу признаков. Чаще — для предварительного анализа, а не как финальное решение.

</details>

<details>
<summary><b>6. Методы машинного обучения</b></summary>

**One-Class SVM**

Модель отделяет данные от начала координат в (ядровом) пространстве признаков: «оборачивает» нормальные
объекты границей, всё снаружи — аномалии. Балансирует размер «нормальной» области и число выбросов за ней,
использует как можно меньше опорных векторов. Подходит для **novelty detection**: есть чистая выборка нормы.

```python
from sklearn.svm import OneClassSVM
model = OneClassSVM(kernel="rbf",   # 'rbf', 'linear', 'poly', 'sigmoid'
                    gamma="scale",  # параметр ядра: больше → граница сложнее
                    nu=0.1)         # верхняя граница доли выбросов (и нижняя — доли опорных векторов)
model.fit(X)
model.predict(X)              # +1 — норма, -1 — выброс
model.decision_function(X)    # чем ниже, тем аномальнее
```

ν-свойство и формулировка задачи (см. раздел «7. One-Class SVM»)

**Isolation Forest (изолирующий лес)**

Построен на идее случайного леса: деревья со **случайными** признаками и порогами разбивают данные, пока каждая
точка не изолируется. Мера нормальности объекта — **средняя глубина** листа, в котором он изолировался.
**Чем меньше глубина — тем подозрительнее объект**: нормальным объектам нужно больше расщеплений.
Порог задаётся гиперпараметром `contamination` (ожидаемая доля выбросов).

```python
from sklearn.ensemble import IsolationForest
model = IsolationForest(n_estimators=100,     # больше — точнее, но медленнее
                        max_samples="auto",   # 'auto' = min(256, n) объектов на дерево
                        contamination=0.1,    # ожидаемая доля выбросов → порог
                        max_features=1.0, bootstrap=False, random_state=42)
model.fit(X_train)
model.predict(X_test)             # -1 — выброс, 1 — норма
model.decision_function(X_test)   # чем ниже, тем аномальнее
```

Формула скора $s(x) = 2^{-\mathbb{E}h(x)/c(n)}$ — вывод (см. раздел «8. Isolation Forest: откуда формула скора»).
В семинаре по ансамблям Isolation Forest (`contamination=0.01`) использовали для чистки выбросов перед
обучением случайного леса; в ДЗ — для поиска ошибочных значений в Wine Quality (альтернатива винсоризации).

**Выводы:** ML-подходы, специально разработанные для аномалий, часто универсальнее и устойчивее адаптированных
методов классификации/кластеризации: работают без меток, учитывают природу новизны, не полагаются на
плотностные/эвристические оценки.

**Автоэнкодер (AE)**

Нейросеть учится **восстанавливать вход после сжатия** в скрытое представление (encoder → bottleneck → decoder).
Гипотеза: обученная только на «нормальных» данных, она плохо восстанавливает аномалии — у них **выше ошибка
реконструкции** $e(x) = \|x - \hat x\|^2$. Выброс, если $e(x) > \text{percentile}_{1 - \text{contamination}}(e)$.

```python
import torch.nn as nn

class Autoencoder(nn.Module):
    def __init__(self, input_dim=20, encoding_dim=10):
        super().__init__()
        self.encoder = nn.Sequential(nn.Linear(input_dim, 14), nn.ReLU(),
                                     nn.Linear(14, encoding_dim), nn.ReLU())
        self.decoder = nn.Sequential(nn.Linear(encoding_dim, 14), nn.ReLU(),
                                     nn.Linear(14, input_dim))

    def forward(self, x):
        return self.decoder(self.encoder(x))
# обучаем на норме по MSE; score = ((x - model(x))**2).mean(dim=1); порог — квантиль score
```

Преимущества: автоматическое выделение признаков, сложные нелинейные зависимости, высокоразмерные данные
(изображения, временные ряды, телеметрия).

</details>

<details>
<summary><b>7. Предобработка данных</b></summary>

1. **Удалить очевидный шум и ошибки сбора** — пропуски, бесконечности, значения из-за багов (иначе модель сочтёт их «характерными»).
2. **Удалить грубые выбросы** (например, по Z-оценке) — чтобы не мешали обучению «нормы» (AE, VAE).
3. **Масштабирование и нормализация** — метрические, кластерные и нейросетевые методы чувствительны к масштабу (`StandardScaler`, `RobustScaler`, `MinMaxScaler`).
4. **Трансформации признаков** — логарифмирование, PCA, агрегации, скользящие окна для рядов.

> Порядок важен: сначала чистим шум и сбои, **потом** удаляем выбросы, и только затем нормализуем и
> трансформируем. Иначе можно «размазать» выброс по всем данным или испортить масштаб признаков.

</details>

<summary><b>9. Метрики и принятие решения</b></summary>

| Есть (частичная) разметка | Нет разметки |
|---|---|
| Precision, Recall, F1 | unsupervised-метрики: статистики распределения скоров, качество кластеризации |
| ROC-AUC | ручная проверка выборки найденных аномалий экспертами |
| **PR-AUC** — лучше при сильном дисбалансе (типично для аномалий) | косвенная оценка через бизнес-метрики (снижение потерь, инцидентов) |

Критерии из реальных систем: время реакции (inference time), **MTTD** (среднее время до обнаружения),
процент ручных проверок / ложных срабатываний, интерпретируемость.

**От скора к решению:**
1. **Порог**: фиксированный; по квантилю (топ-5%, топ-1% скоров); по статистике скоров ($\text{score} > \mu + 3\sigma$);
   по ROC/PR-кривой при наличии разметки. В PyOD и sklearn — `decision_function` + `threshold_`/`contamination`.
2. **Ранжирование**: отдать на проверку топ-$N$ самых подозрительных (топ-10, топ-50, 1%).

</details>

<details>
<summary><b>Типичные ошибки</b></summary>

- Глобальный порог без учёта контекста (сумма перевода без профиля клиента).
- Z-оценка на данных с сильными выбросами (маскировка) — используйте медиану/MAD.
- Метрические методы без масштабирования признаков.
- Обучение «нормы» (AE, OCSVM) на данных с аномалиями.
- Оценка только ROC-AUC при доле аномалий 0.1%.
- `contamination` «с потолка» — это фактически порог; согласуйте с бизнесом и проверяйте выборочно.

</details>

**Математика и выводы**

<details>
<summary><b>1. Z-оценка: сколько «трёх сигм» на самом деле</b></summary>

$$
z_i = \frac{x_i - \mu}{\sigma} .
$$

- **Без предположений о распределении** (неравенство Чебышёва): $P(|Z| \ge k) \le \frac{1}{k^2}$. Порог $k = 3$ гарантирует
  лишь ≤ 11% «выбросов» — слабая гарантия.
- **Для нормального распределения**: $P(|Z| > 3) \approx 0.27\%$, $P(|Z| > 2) \approx 4.6\%$. На выборке из
  $10^6$ нормальных точек «три сигмы» пометят ≈ 2700 совершенно нормальных объектов.

**Эффект маскировки.** $\mu$ и $\sigma$ сами оцениваются по данным, включая выбросы. Большой выброс раздувает
$\hat\sigma$ и сдвигает $\hat\mu$, и его собственная $z$-оценка уменьшается. Предельный случай: в выборке из $n$ точек
максимальная возможная $|z_i| \le \frac{n-1}{\sqrt n}$ (при $n = 10$ — не больше 2.85, т.е. «3σ» не сработает никогда!).

**Робастная версия** — медиана и MAD:

$$
\text{MAD} = \operatorname{median}\big(|x_i - \operatorname{median}(x)|\big), \qquad
z_i^{\text{rob}} = \frac{x_i - \operatorname{median}(x)}{1.4826\cdot\text{MAD}} .
$$

Константа $1.4826 = 1/\Phi^{-1}(0.75)$ делает $1.4826\cdot\text{MAD}$ состоятельной оценкой $\sigma$ для нормального
распределения. Медиана и MAD имеют **точку срыва 50%** (можно испортить почти половину данных, и оценки
останутся ограниченными), у среднего и стандартного отклонения — 0%. Порог Иглевича–Хоглина:
модифицированная оценка $0.6745\frac{x_i - \operatorname{med}}{\text{MAD}} > 3.5$. Это ровно правило со слайда
«порог = median(e) + k·MAD, k = 3» для анализа остатков.

</details>

<details>
<summary><b>2. IQR: какой порог он задаёт</b></summary>

Границы $Q_1 - 1.5\,\text{IQR}$ и $Q_3 + 1.5\,\text{IQR}$. Для $\mathcal{N}(\mu, \sigma^2)$: $Q_{1,3} = \mu \mp 0.6745\sigma$,
$\text{IQR} = 1.349\sigma$, значит верхняя граница $\mu + 0.6745\sigma + 2.0235\sigma = \mu + 2.698\sigma$. Доля нормальных
точек за границами ≈ **0.7%**. Квартили робастны (точка срыва 25%), правило не требует предположений о
распределении, но **одномерно**: не видит объекты, аномальные только по комбинации признаков.

</details>

<details>
<summary><b>3. Критерий Граббса</b></summary>

Проверяет гипотезу «в выборке нет выбросов» для нормальных данных: $G = \frac{\max_i|x_i - \bar x|}{s}$.
Критическое значение при уровне $\alpha$:

$$
G > \frac{n-1}{\sqrt n}\sqrt{\frac{t^2_{\alpha/(2n),\,n-2}}{n - 2 + t^2_{\alpha/(2n),\,n-2}}} ,
$$

$t$ — квантиль распределения Стьюдента. Проверяет **один** выброс за раз (итеративно — с риском маскировки).

</details>

<details>
<summary><b>4. Многомерный случай: расстояние Махаланобиса</b></summary>

$$
d_M^2(x) = (x - \mu)^\top\Sigma^{-1}(x - \mu) .
$$

Если $x \sim \mathcal{N}(\mu, \Sigma)$ в $\mathbb{R}^d$, то $d_M^2 \sim \chi^2_d$ (после «выбеливания» $z = \Sigma^{-1/2}(x - \mu) \sim \mathcal{N}(0, I)$, а
$\|z\|^2$ — сумма $d$ квадратов стандартных нормальных). Порог — квантиль $\chi^2_d$ (например, 0.975).
Учитывает корреляции: точка (рост 190, вес 50) может быть нормальной по каждому признаку отдельно, но
далёкой по Махаланобису.

Маскировка в многомерном случае ещё сильнее, поэтому $\mu, \Sigma$ оценивают **робастно** — Minimum Covariance
Determinant (MCD): ищем подмножество из $h \approx \ell/2$ точек с минимальным определителем ковариационной матрицы
(`sklearn.covariance.EllipticEnvelope`).

</details>

<details>
<summary><b>5. Local Outlier Factor</b></summary>

Обозначения: $N_k(x)$ — $k$ ближайших соседей $x$; $\rho_k(z)$ — расстояние от $z$ до его $k$-го соседа.

**Достижимое расстояние** (сглаживает расстояния до очень близких соседей):

$$
\text{reach-dist}_k(x, z) = \max\big(\rho(x, z),\; \rho_k(z)\big) .
$$

**Локальная достижимая плотность** (local reachability density) — обратное среднее достижимое расстояние:

$$
\text{lrd}_k(x) = \Big(\frac{1}{k}\sum_{z \in N_k(x)}\text{reach-dist}_k(x, z)\Big)^{-1} .
$$

**LOF** — средняя относительная плотность соседей:

$$
\text{LOF}_k(x) = \frac{1}{k}\sum_{z \in N_k(x)}\frac{\text{lrd}_k(z)}{\text{lrd}_k(x)} .
$$

- $\text{LOF} \approx 1$ — плотность точки как у соседей (норма);
- $\text{LOF} \gg 1$ — точка в области **более низкой плотности, чем её соседи** — выброс.

Ключевое отличие от глобальных методов (kNN-расстояние, $z$-оценка): LOF **локальный** — находит выбросы рядом с
плотным кластером, даже если по абсолютному расстоянию они ближе, чем точки разреженного, но нормального кластера.

</details>

<details>
<summary><b>6. DBSCAN: определения</b></summary>

Параметры $\varepsilon$, `min_samples` $= m$. $N_\varepsilon(x) = \lbrace z: \rho(x, z) \le \varepsilon\rbrace$.
- **Ядровая точка**: $|N_\varepsilon(x)| \ge m$ (сама точка считается);
- **граничная**: не ядровая, но лежит в $\varepsilon$-окрестности ядровой;
- **шум** (метка −1): ни то, ни другое — это и есть выбросы.

Кластер — максимальное множество точек, достижимых по плотности от ядровых точек. Выбор $\varepsilon$ — по «локтю»
графика отсортированных расстояний до $m$-го соседа. Подробно о DBSCAN как кластеризации — тема [11](../11_clustering_dim_reduction/README.md).

</details>

<details>
<summary><b>7. One-Class SVM</b></summary>

**Формулировка Шёлькопфа** (2001): отделить данные от начала координат в пространстве признаков $\varphi$ с
максимальным зазором:

$$
\min_{w, \xi, \rho}\;\frac12\|w\|^2 + \frac{1}{\nu\ell}\sum_{i=1}^{\ell}\xi_i - \rho
\quad\text{s.t.}\quad \langle w, \varphi(x_i)\rangle \ge \rho - \xi_i,\;\; \xi_i \ge 0 .
$$

Решающая функция $f(x) = \operatorname{sign}\big(\sum_i \alpha_i K(x_i, x) - \rho\big)$: $+1$ — норма, $-1$ — аномалия.

**ν-свойство:** $\nu \in (0, 1]$ — **верхняя граница доли выбросов** на обучении (объектов с $\xi_i > 0$) и **нижняя
граница доли опорных векторов**. Поэтому `nu` — это интерпретируемый аналог `contamination`.

*Почему.* Из двойственной задачи $0 \le \alpha_i \le \frac{1}{\nu\ell}$ и $\sum_i \alpha_i = 1$. Выбросы ($\xi_i > 0$) имеют
$\alpha_i = \frac{1}{\nu\ell}$ — максимальное значение; их не может быть больше $\nu\ell$, иначе сумма превысит 1. Опорных
векторов ($\alpha_i > 0$) не меньше $\nu\ell$, так как каждое $\alpha_i \le \frac{1}{\nu\ell}$, а сумма равна 1.

С RBF-ядром ($K(x, x) = \text{const}$) задача эквивалентна **SVDD** — поиску шара минимального радиуса,
содержащего данные. $\gamma$ задаёт гладкость границы: большое $\gamma$ — граница «облегает» каждую точку
(переобучение, слайд с $\gamma = 0.01, 0.1, 0.5$).

</details>

<details>
<summary><b>8. Isolation Forest: откуда формула скора</b></summary>

**Идея** (Liu, Ting, Zhou, 2008): строим случайные деревья — признак и порог выбираются **случайно** (порог
равномерно между min и max признака в вершине) — до изоляции каждой точки. Аномалии немногочисленны и
отличаются значениями, поэтому изолируются **за меньшее число разбиений**.

**Нормировка.** Средняя длина пути до изоляции в двоичном дереве из $n$ точек равна средней длине
неуспешного поиска в двоичном дереве поиска:

$$
c(n) = 2H(n-1) - \frac{2(n-1)}{n}, \qquad H(i) \approx \ln i + 0.5772 .
$$

**Скор аномальности** ($h(x)$ — длина пути $x$ в дереве, усреднённая по деревьям):

$$
s(x, n) = 2^{-\frac{\mathbb{E}\,h(x)}{c(n)}} .
$$

- $\mathbb{E}h(x) \to 0$ ⇒ $s \to 1$ — точно аномалия;
- $\mathbb{E}h(x) = c(n)$ ⇒ $s = 0.5$ — «как все»;
- $\mathbb{E}h(x) \to n - 1$ ⇒ $s \to 0$ — глубоко внутри данных.

В sklearn `score_samples` возвращает $-s$, а `decision_function = score_samples - offset_`, где `offset_` подобран
так, чтобы доля `contamination` объектов получила отрицательные значения (отсюда «чем ниже, тем аномальнее»).

**Почему подвыборки маленькие** (`max_samples=256`): на малой подвыборке аномалии реже маскируют друг друга
(masking) и нормальные точки реже «прилипают» к аномалиям (swamping); деревья строятся быстро, глубина
ограничивается $\lceil\log_2 256\rceil = 8$ — нам важны только короткие пути. Сложность — $O(t\psi\log\psi)$ на обучение,
линейная по данным на предсказание.

**Недостаток:** разбиения параллельны осям → «артефакты» вдоль осей (видно на слайде с границами при разном
числе деревьев); Extended Isolation Forest использует случайные гиперплоскости.

</details>

<details>
<summary><b>9. Автоэнкодер и PCA</b></summary>

Ошибка реконструкции $e(x) = \|x - \hat x\|^2$, порог — верхний процентиль: $x$ — выброс, если
$e(x) > \text{percentile}_{1 - \text{contamination}}(e)$.

**Линейный автоэнкодер = PCA.** Если энкодер и декодер линейны и лосс — MSE, оптимальный декодер проецирует
на подпространство первых $k$ главных компонент (теорема Эккарта–Янга). Тогда ошибка реконструкции —
квадрат расстояния до этого подпространства (в статистическом контроле процессов — **Q-статистика / SPE**).
Нелинейный AE обобщает идею на нелинейные многообразия. Подробнее об автоэнкодерах — тема
[27](../27_generative_models/README.md).

Почему это работает: модель, обученная на «норме», хорошо сжимает и восстанавливает только типичные
закономерности; аномалия не лежит на выученном многообразии → большая ошибка. Риск: слишком мощный AE
научится восстанавливать всё, включая аномалии (нужен узкий bottleneck, регуляризация, обучение на чистых данных).

</details>

<details>
<summary><b>10. Оценка качества при сильном дисбалансе</b></summary>

Доля аномалий $\pi$ обычно 0.1–1%. Тогда:
- ROC-AUC может быть высоким при бесполезной Precision (тема [02](../02_classification_metrics/README.md));
- **PR-AUC** (базовый уровень — $\pi$) и **Precision@k** (доля аномалий среди $k$ самых подозрительных — то, что
  реально увидит эксперт) информативнее;
- без разметки — устойчивость скоров к подвыборкам, согласованность методов, ручная проверка выборки
  найденного экспертами, бизнес-метрики.

</details>

ручная проверка топ-$N$ экспертами, стабильность скоров, бизнес-метрики; с разметкой — PR-AUC, Precision@k.

</details>

<details>
<summary><b>Дополнительно: детали</b></summary>

- Для $\mathcal N$: IQR-забор $\approx\mu\pm2.7\sigma$ (0.7% точек); $|z|>3$ — 0.27%. Максимум $|z|$ в выборке из $n$ точек $\le(n-1)/\sqrt n$ — маскировка.
- Махаланобис: $d_M^2\sim\chi^2_d$ для нормальных данных; робастная ковариация — MCD (`EllipticEnvelope`).
- ν-свойство OCSVM: доля выбросов $\le\nu\le$ доля опорных векторов.
- Линейный автоэнкодер = PCA; ошибка реконструкции = расстояние до главного подпространства.

</details>

<details>
<summary><b>Примеры кода (с результатами запуска)</b></summary>

Запустить их можно в ноутбуке [`cheatsheet.ipynb`](../../cheatsheet.ipynb).

```python
import numpy as np
from sklearn.ensemble import IsolationForest
from sklearn.neighbors import LocalOutlierFactor
from sklearn.svm import OneClassSVM
from sklearn.metrics import average_precision_score, roc_auc_score

rng = np.random.default_rng(0)
X_norm = np.r_[rng.normal(0, 1, (480, 2)), rng.normal(5, 0.3, (480, 2))]   # два кластера разной плотности
X_out = rng.uniform(-4, 8, (40, 2))                                         # 4% аномалий
X = np.r_[X_norm, X_out]; y = np.r_[np.zeros(960), np.ones(40)]

scores = {
    "IsolationForest": -IsolationForest(contamination=0.04, random_state=0).fit(X).score_samples(X),
    "LOF":             -LocalOutlierFactor(n_neighbors=20).fit(X).negative_outlier_factor_,
    "OneClassSVM":     -OneClassSVM(nu=0.05, gamma="scale").fit(X).decision_function(X),
    "z-score (max |z|)": np.abs((X - X.mean(0)) / X.std(0)).max(1),
}
for name, s in scores.items():
    print(f"{name:18} ROC-AUC={roc_auc_score(y, s):.3f}  PR-AUC={average_precision_score(y, s):.3f}")
```

Результат запуска:

```text
IsolationForest    ROC-AUC=0.926  PR-AUC=0.784
LOF                ROC-AUC=0.919  PR-AUC=0.783
OneClassSVM        ROC-AUC=0.879  PR-AUC=0.714
z-score (max |z|)  ROC-AUC=0.775  PR-AUC=0.452
```

```python
# Маскировка: выбросы раздувают std, и правило «3 сигмы» их не видит; медиана + MAD — видит
x = np.r_[rng.normal(10, 1, 50), [30, 32, 35, 40, 45]]
z = (x - x.mean()) / x.std()
mad = np.median(np.abs(x - np.median(x)))
z_rob = (x - np.median(x)) / (1.4826 * mad)
print("3σ нашло:", np.sort(x[np.abs(z) > 3]).round(1), "| robust MAD нашло:", np.sort(x[np.abs(z_rob) > 3]).round(1))
```

Результат запуска:

```text
3σ нашло: [40. 45.] | robust MAD нашло: [30. 32. 35. 40. 45.]
```
