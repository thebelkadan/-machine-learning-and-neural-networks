## 1. Аномалия, шум и новизна

| Понятие | Определение | Цель работы с ним |
|---|---|---|
| **Аномалия** | объект, который **существенно отличается** от большинства других | выявить, интерпретировать, найти закономерности |
| **Шум** | случайные/ошибочные данные без полезной информации; в сильном смысле — способен имитировать аномалии | исключить, очистить данные |
| **Новизна** (novelty) | объект или поведение, которых **не было в обучающей выборке** (новый вид кибератаки) | построить модель, адаптирующуюся к непредсказуемому будущему |

**Типы отличий аномалии:**
- **числовое** — перевод 3 млн ₽ у клиента, который обычно переводит до 50 000;
- **поведенческое** — сотрудник вдруг скачивает всю клиентскую базу;
- **контекстуальное** — нормально для одного, странно для другого (вход из другой страны).

**Контекст критичен.** Пример из лекции: 1000 банковских транзакций. Вариант 1 — считать подозрительными все
переводы > 3000 ₽: перевод 6000 ₽ от предпринимателя из Москвы и от рабочего из деревни попадут в одну кучу.
Вариант 2 — сравнивать транзакцию со средней суммой **этого клиента**, его временными паттернами, доходом,
поведением похожих клиентов.

**Где встречаются:** производство (датчики: пики, несогласованные параметры, залипшие значения — брак партии
стоит миллионы), кибербезопасность (всплеск ночных входов, много запросов с одного IP), финансы (графы
транзакций: отмывание денег, инсайдерские схемы).

## 2. Постановки задачи

| | **Outlier detection** (детектирование выбросов) | **Novelty detection** (детектирование новизны) |
|---|---|---|
| Обучающая выборка | содержит аномалии | только «нормальные» объекты |
| Задача | найти объекты, не похожие на основную массу, **внутри** имеющихся данных | построить «образ нормы» и замечать отклонения в **новых** данных |
| Пример | чистка исторических данных | мониторинг в реальном времени |

По наличию разметки:
1. **Без разметки** (unsupervised outlier detection) — самый частый случай;
2. **Частичная разметка** (Positive-Unlabeled learning) — часть аномалий известна, в остальных данных они тоже могут быть;
3. **Полная разметка** — редкость; сводится к бинарной классификации с сильным дисбалансом.

## 3. Статистические методы

**IQR (межквартильный размах).** $\text{IQR} = Q_3 - Q_1$; границы $Q_1 - 1.5\,\text{IQR}$ и $Q_3 + 1.5\,\text{IQR}$ (усы
«ящика с усами»). Просто, не зависит от распределения, но **только одномерно**. Для нормальных данных граница
≈ $\mu \pm 2.7\sigma$ ([вывод](deep.md#2-iqr-какой-порог-он-задаёт)).

**Z-оценка.** $z_i = \frac{x_i - \mu}{\sigma}$; выброс, если $|z_i|$ больше порога (обычно 3). Минус — выбросы сами
раздувают $\mu$ и $\sigma$ (**маскировка**) → робастная версия с медианой и MAD ([подробно](deep.md#1-z-оценка-сколько-трёх-сигм-на-самом-деле)).

**Тест Граббса** — статистический тест на наличие одного выброса в нормальной выборке.

**Выводы:** статистические методы — базовые инструменты предварительной диагностики; хорошо работают для
простых, одномерных и стационарных данных; не требуют разметки; основаны на предположениях о распределении;
выявляют статистически редкие случаи, но ориентированы на **известные** отклонения, а не на новизну.

## 4. Модельный подход: регрессия + анализ остатков

1. Обучаем модель (линейную регрессию, бустинг) предсказывать целевое значение по признакам.
2. Считаем остатки $e_i = |y_i - \hat y_i|$.
3. Объекты с **большими остатками** — потенциальные аномалии. Порог:
   - три сигмы;
   - верхний перцентиль (например, 5% точек с наибольшими ошибками);
   - **MAD**: $\text{MAD} = \operatorname{median}(|e_i - \operatorname{median}(e)|)$, порог $= \operatorname{median}(e) + k\cdot\text{MAD}$, $k = 3$ —
     робастный способ, устойчивый к выбросам.

**Выводы:** модельные методы учитывают структуру данных и целевую задачу, не требуют разметки, позволяют
самим задать «норму»; эффективны для новизны и мониторинга. Риск: модель может **встроить аномалию в норму**
(подогнаться под неё) и не выявить её.

## 5. Метрические методы

Идея: **нормальные точки находятся рядом с другими, аномалия — «далеко от всех»**. Нужна метрика: евклидова,
манхэттенская, Махаланобиса (с учётом корреляций и масштаба).

### kNN-детектор (PyOD)

Чем больше расстояние до ближайших соседей, тем выше вероятность аномалии. Стратегии скора:
`method='largest'` — расстояние до самого дальнего из $k$ соседей; `'mean'` — среднее; `'median'` — медиана.

```python
from pyod.models.knn import KNN
X = np.array([[1], [2], [2.2], [2.1], [8]])        # 8 — выброс
model = KNN(contamination=0.1, method="mean").fit(X)
model.predict(X)               # 1 — выброс, 0 — норма
model.decision_function(X)     # чем выше, тем аномальнее
```

**PyOD** — специализированная библиотека для поиска аномалий: единый API для статистических, ML- и DL-методов,
совместимость со sklearn, ансамбли (SUOD), semi-supervised сценарии.

### Local Outlier Factor (LOF)

Если точка в области **низкой плотности**, но окружена точками из **более плотной** области — вероятно, выброс;
если плотность как у соседей — норма. Формулы: достижимое расстояние $p'(x, z) = \max[p(x, z), p_k(z)]$,
локальная достижимая плотность (LRD) — обратная к среднему достижимому расстоянию до $k$ соседей,
LOF — среднее отношение LRD соседей к LRD точки ([подробно](deep.md#5-local-outlier-factor)).

```python
from sklearn.neighbors import LocalOutlierFactor
X = np.array([[1, 2], [2, 1], [1, 1], [10, 10], [10, 11], [11, 10]])
lof = LocalOutlierFactor(n_neighbors=2, contamination=0.2)   # novelty=False — выбросы в самом наборе
lof.fit_predict(X)                                            # -1 — выброс, 1 — норма
lof.negative_outlier_factor_                                  # чем ниже, тем аномальнее
LocalOutlierFactor(n_neighbors=20, novelty=True).fit(X_train).decision_function(X_new)   # новизна
```

### DBSCAN

Группирует точки из областей высокой плотности; точки, у которых внутри радиуса `eps` меньше `min_samples`
соседей и которые не прилегают к плотным областям, получают метку **−1** (шум = выбросы).
`eps` подбирают по «локтю» графика расстояний до $k$-го соседа ($k$ = `min_samples`); `min_samples` ≈ размерность + 1 или чуть больше (3–5).

```python
from sklearn.cluster import DBSCAN
X = np.array([[1], [1.1], [1.2], [1.3], [6]])
DBSCAN(eps=0.3, min_samples=2).fit_predict(X)     # [0 0 0 0 -1]
```

**Выводы:** метрические методы не требуют обучения, легко интерпретируются, не зависят от распределения;
удобны для быстрого анализа. Ограничения: зависят от метрики, плохо работают в высокой размерности,
чувствительны к масштабу признаков. Чаще — для предварительного анализа, а не как финальное решение.

## 6. Методы машинного обучения

### One-Class SVM

Модель отделяет данные от начала координат в (ядровом) пространстве признаков: «оборачивает» нормальные
объекты границей, всё снаружи — аномалии. Балансирует размер «нормальной» области и число выбросов за ней,
использует как можно меньше опорных векторов. Подходит для **novelty detection**: есть чистая выборка нормы.

```python
from sklearn.svm import OneClassSVM
model = OneClassSVM(kernel="rbf",   # 'rbf', 'linear', 'poly', 'sigmoid'
                    gamma="scale",  # параметр ядра: больше → граница сложнее
                    nu=0.1)         # верхняя граница доли выбросов (и нижняя — доли опорных векторов)
model.fit(X)
model.predict(X)              # +1 — норма, -1 — выброс
model.decision_function(X)    # чем ниже, тем аномальнее
```

[ν-свойство и формулировка задачи](deep.md#7-one-class-svm)

### Isolation Forest (изолирующий лес)

Построен на идее случайного леса: деревья со **случайными** признаками и порогами разбивают данные, пока каждая
точка не изолируется. Мера нормальности объекта — **средняя глубина** листа, в котором он изолировался.
**Чем меньше глубина — тем подозрительнее объект**: нормальным объектам нужно больше расщеплений.
Порог задаётся гиперпараметром `contamination` (ожидаемая доля выбросов).

```python
from sklearn.ensemble import IsolationForest
model = IsolationForest(n_estimators=100,     # больше — точнее, но медленнее
                        max_samples="auto",   # 'auto' = min(256, n) объектов на дерево
                        contamination=0.1,    # ожидаемая доля выбросов → порог
                        max_features=1.0, bootstrap=False, random_state=42)
model.fit(X_train)
model.predict(X_test)             # -1 — выброс, 1 — норма
model.decision_function(X_test)   # чем ниже, тем аномальнее
```

Формула скора $s(x) = 2^{-\mathbb{E}h(x)/c(n)}$ — [вывод](deep.md#8-isolation-forest-откуда-формула-скора).
В семинаре по ансамблям Isolation Forest (`contamination=0.01`) использовали для чистки выбросов перед
обучением случайного леса; в ДЗ — для поиска ошибочных значений в Wine Quality (альтернатива винсоризации).

**Выводы:** ML-подходы, специально разработанные для аномалий, часто универсальнее и устойчивее адаптированных
методов классификации/кластеризации: работают без меток, учитывают природу новизны, не полагаются на
плотностные/эвристические оценки.

### Автоэнкодер (AE)

Нейросеть учится **восстанавливать вход после сжатия** в скрытое представление (encoder → bottleneck → decoder).
Гипотеза: обученная только на «нормальных» данных, она плохо восстанавливает аномалии — у них **выше ошибка
реконструкции** $e(x) = \|x - \hat x\|^2$. Выброс, если $e(x) > \text{percentile}_{1 - \text{contamination}}(e)$.

```python
import torch.nn as nn

class Autoencoder(nn.Module):
    def __init__(self, input_dim=20, encoding_dim=10):
        super().__init__()
        self.encoder = nn.Sequential(nn.Linear(input_dim, 14), nn.ReLU(),
                                     nn.Linear(14, encoding_dim), nn.ReLU())
        self.decoder = nn.Sequential(nn.Linear(encoding_dim, 14), nn.ReLU(),
                                     nn.Linear(14, input_dim))

    def forward(self, x):
        return self.decoder(self.encoder(x))
# обучаем на норме по MSE; score = ((x - model(x))**2).mean(dim=1); порог — квантиль score
```

Преимущества: автоматическое выделение признаков, сложные нелинейные зависимости, высокоразмерные данные
(изображения, временные ряды, телеметрия).

## 7. Предобработка данных

1. **Удалить очевидный шум и ошибки сбора** — пропуски, бесконечности, значения из-за багов (иначе модель сочтёт их «характерными»).
2. **Удалить грубые выбросы** (например, по Z-оценке) — чтобы не мешали обучению «нормы» (AE, VAE).
3. **Масштабирование и нормализация** — метрические, кластерные и нейросетевые методы чувствительны к масштабу (`StandardScaler`, `RobustScaler`, `MinMaxScaler`).
4. **Трансформации признаков** — логарифмирование, PCA, агрегации, скользящие окна для рядов.

> Порядок важен: сначала чистим шум и сбои, **потом** удаляем выбросы, и только затем нормализуем и
> трансформируем. Иначе можно «размазать» выброс по всем данным или испортить масштаб признаков.

## 8. Сравнение методов

| Подход | Метод | Важные гиперпараметры | Библиотеки | Когда применять | Масштабируемость (≥100k) | Интерпретируемость |
|---|---|---|---|---|---|---|
| Статистический | IQR / Z-score / тест Граббса | `z_threshold`, IQR factor | SciPy, Pandas, Statsmodels | быстрая фильтрация, sanity checks | высокая | высокая |
| Модельный | регрессия + остатки | тип регрессии, порог остатка | sklearn, Statsmodels | можно предсказать норму | средняя | высокая |
| Метрический | kNN | $k$, метрика | sklearn, PyOD | простой бейзлайн, локальные отклонения | средняя | средняя |
| Метрический | LOF | `n_neighbors`, метод локализации | sklearn, PyOD | локальная плотность, выбросы в плотных зонах | средняя | средняя |
| Метрический | DBSCAN | `eps`, `min_samples` | sklearn, HDBSCAN | кластеризация с шумом, пространственные задачи | средняя | средняя |
| ML | One-Class SVM | `kernel`, `nu`, `gamma` | sklearn, PyOD | строгая область нормы, новизна без выбросов в train | низкая | низкая |
| ML | Isolation Forest | `n_estimators`, `max_samples` | sklearn, PyOD | отлично масштабируется, прод и пайплайны | высокая | средняя |
| Нейросетевой | AutoEncoder | `latent_dim`, epochs, batch_size | PyTorch, Keras, PyOD | высокомерные данные, изображения, телеметрия | высокая | низкая |
| Ансамблевый | SUOD, LSCP, XGBOD… | выбор моделей и агрегации | PyOD, joblib | повышение качества | высокая | средняя |

**Если разметки нет или она неполная** — начинать со статистики, метрических или модельных методов, затем
ансамбли. **Не знаете, с чего начать** — SUOD или AutoEncoder + Isolation Forest. И не пропускать подготовку данных.

## 9. Метрики и принятие решения

| Есть (частичная) разметка | Нет разметки |
|---|---|
| Precision, Recall, F1 | unsupervised-метрики: статистики распределения скоров, качество кластеризации |
| ROC-AUC | ручная проверка выборки найденных аномалий экспертами |
| **PR-AUC** — лучше при сильном дисбалансе (типично для аномалий) | косвенная оценка через бизнес-метрики (снижение потерь, инцидентов) |

Критерии из реальных систем: время реакции (inference time), **MTTD** (среднее время до обнаружения),
процент ручных проверок / ложных срабатываний, интерпретируемость.

**От скора к решению:**
1. **Порог**: фиксированный; по квантилю (топ-5%, топ-1% скоров); по статистике скоров ($\text{score} > \mu + 3\sigma$);
   по ROC/PR-кривой при наличии разметки. В PyOD и sklearn — `decision_function` + `threshold_`/`contamination`.
2. **Ранжирование**: отдать на проверку топ-$N$ самых подозрительных (топ-10, топ-50, 1%).

---

## Типичные ошибки

- Глобальный порог без учёта контекста (сумма перевода без профиля клиента).
- Z-оценка на данных с сильными выбросами (маскировка) — используйте медиану/MAD.
- Метрические методы без масштабирования признаков.
- Обучение «нормы» (AE, OCSVM) на данных с аномалиями.
- Оценка только ROC-AUC при доле аномалий 0.1%.
- `contamination` «с потолка» — это фактически порог; согласуйте с бизнесом и проверяйте выборочно.
